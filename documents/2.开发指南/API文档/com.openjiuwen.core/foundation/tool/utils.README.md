# utils

`com.openjiuwen.core.foundation.tool.utils` contains reflection helpers that derive JSON Schema from Java methods and types.

## Core Types

| Type | Description |
| --- | --- |
| [`CallableSchemaExtractor`](utils/CallableSchemaExtractor.md) | Reflection-based extractor that turns Java method signatures into JSON Schema. |
| [`TypeSchemaExtractor`](utils/TypeSchemaExtractor.md) | Reflection-based schema extraction for Java types. |
