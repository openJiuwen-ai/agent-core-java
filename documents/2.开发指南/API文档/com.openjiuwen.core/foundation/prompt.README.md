# prompt

`com.openjiuwen.core.foundation.prompt` provides prompt-template containers and formatting helpers for string and message-based prompt content.

## Modules

| Module | Description |
| --- | --- |
| [`assemble`](prompt/assemble.README.md) | runtime prompt assembly helpers for placeholder substitution. |

## Core Types

| Type | Description |
| --- | --- |
| [`PromptTemplate`](prompt/PromptTemplate.md) | Interpolatable text prompt template with configurable placeholders. |

## Notes

- `PromptAssembleTest` covers placeholder discovery, partial substitution, and message-list prompt formatting for this package.
