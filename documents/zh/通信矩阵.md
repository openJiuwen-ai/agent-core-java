# 通信矩阵

本文档用于应对仲景安全扫描，说明产品对外通信的地址、用途和端口。

## Auto-Harness 创建 GitCode Pull Request

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | Auto-Harness 的“发布并创建 Pull Request”后置步骤（`PublishPrStage` / `GitOperations`） |
| 必要性 | 仅在用户配置 Git 远端和 Fork 所有者、任务已成功提交代码且需要自动创建 Pull Request 时使用；用于将自动化研发结果提交为可评审的 Pull Request。未配置该功能时不会发起此连接。 |
| 通信方向 | 产品实例主动向外发起的客户端出站连接；不监听本地端口。 |
| 目的地址 | `api.gitcode.com` |
| 协议/传输层端口 | HTTPS / TCP 443 |
| 调用方式 | `POST /api/v5/repos/{upstreamOwner}/{upstreamRepo}/pulls` |
| 传输数据 | Pull Request 标题、正文、源分支、目标分支，以及用于 GitCode 鉴权的访问令牌。 |
| 鉴权 | GitCode 访问令牌由 `gitcode.access_token` 或 `gitcode.access_token_env` 提供；令牌值不得写入配置模板、源码或日志。 |
| 传输安全 | 使用 HTTPS；Java 标准 `HttpClient` 的默认 TLS 证书校验生效，未配置跳过证书校验的信任策略。 |
| 失败行为 | 未配置访问令牌或 GitCode 返回非成功状态时，返回创建 Pull Request 失败结果，不会开放额外端口或降级为明文传输。 |

> 本连接属于可选研发辅助能力，不是产品每次启动或普通本地代码操作都会触发的连接。

## Auto-Harness Git 远程仓库操作

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | Auto-Harness 的工作区管理（`ProjectProfile`、`AutoHarnessConfig`、`WorktreeManager`）。 |
| 必要性 | 仅在 Auto-Harness 需要准备代码工作区、拉取基线代码、创建工作分支或推送修改时使用；常规启动不发起此连接。 |
| 通信方向 | 产品实例主动向 GitCode 发起客户端出站连接；不监听本地端口。 |
| 目的地址 | GitCode：`gitcode.com`。默认基线仓库为 `https://gitcode.com/openJiuwen/agent-core.git`；创建 Fork 远程仓库时使用 `https://gitcode.com/{forkOwner}/{upstreamRepo}.git`。若部署配置了 `repo_url`，则以该配置的仓库地址作为基线仓库。 |
| 协议/传输层端口 | Git over HTTPS / TCP 443。 |
| 调用方式 | 使用 Git 客户端执行 `clone`、`fetch`、`push` 等远程仓库操作；不是 GitCode REST API 调用。 |
| 传输数据 | 仓库源码、提交、分支等 Git 对象，以及完成远程操作所需的 Git 协议数据。 |
| 传输安全 | 使用 HTTPS；不在该组件中关闭 Git 客户端的 TLS 证书校验。 |
| 失败行为 | 远程仓库不可访问或 Git 操作失败时，当前 Auto-Harness 任务失败并返回错误；不回退到明文传输或其他地址。 |

## Agent Evolving 工具调用评估的默认 OpenAI 服务

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | Agent Evolving 的工具调用评估（`RitsUtils` / `SimpleEval`）。 |
| 必要性 | 仅在执行工具调用评估、调用方未传入 `api_base` 且已提供模型 API Key 时使用；用于调用默认 OpenAI 兼容模型服务生成或评估结果。 |
| 通信方向 | 产品实例主动向外发起的客户端出站连接；不监听本地端口。 |
| 目的地址 | `api.openai.com` |
| 协议/传输层端口 | HTTPS / TCP 443 |
| 调用方式 | `POST /v1/chat/completions` |
| 传输数据 | 评估提示词、工具定义或执行结果、模型标识，以及 OpenAI API Key。 |
| 鉴权 | 调用方提供的模型 API Key 通过 HTTPS 请求头传递；不得写入配置模板、源码或日志。 |
| 传输安全 | HTTPS；`verifySsl` 固定开启，使用标准 TLS 证书校验。 |
| 失败行为 | 未提供 API Key 或模型服务返回非成功状态时，返回评估失败结果，不会开放额外端口或降级为明文传输。 |

> 调用方传入 `api_base` 时，以该显式地址为准；对应的对外地址、端口和用途应由部署方纳入其产品通信矩阵。

## 本机出口 IPv4 地址探测

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | 公共工具 `IpUtils.getLocalIp()`。 |
| 必要性 | 仅在调用方需要获取“系统访问指定公网地址时会选用的本机出口 IPv4 地址”时使用；用于多网卡环境下选择对应的本机地址。 |
| 通信方向 | 产品实例创建 UDP 客户端 socket；不监听本地端口。 |
| 目的地址 | `8.8.8.8`。 |
| 协议/传输层端口 | UDP / 80。 |
| 调用方式 | `DatagramSocket.connect` 仅用于本机路由选择，再读取 socket 的本机地址；代码不调用 `send`，不发送业务请求或应用层数据。 |
| 传输数据 | 无业务数据、无认证凭据、无用户数据。 |
| 传输安全 | 不传输敏感数据；不使用明文业务协议进行数据交换。 |
| 失败行为 | 路由选择或地址获取失败时返回 `127.0.0.1`，不重试、不开放额外端口。 |

> 当前仓库没有直接调用该工具；保留该已公开的工具方法及其既有语义，供外部调用方按需使用。

## Harness 本地/内网付费搜索代理

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | Harness 的 `paid_search` 工具（`WebPaidSearchTool`）。 |
| 必要性 | 仅在 Agent 调用 `paid_search`、Provider 为 `bocha`、`perplexity` 或 `serper`，且环境中至少存在一个付费搜索 API Key 时使用。未调用该工具时不会发起此连接。 |
| 通信方向 | 产品实例主动向本地/内网代理发起客户端出站连接；不监听本地端口。 |
| 目的地址 | `paid-search.local`；本地/内网代理服务名，属于 `.local` 特殊本地域名，不是公网服务地址。部署环境负责将其解析和路由到受控的本地/内网代理。 |
| 协议/传输层端口 | HTTPS / TCP 443。 |
| 调用方式 | `GET /{provider}?q={query}`，其中 `{provider}` 为 `bocha`、`perplexity` 或 `serper`。 |
| 传输数据 | 搜索关键词和 Provider 名称；当前请求不携带 API Key，环境变量中的 API Key 仅用于决定是否启用该工具。 |
| 传输安全 | 使用 HTTPS；未配置自定义信任策略或跳过证书校验，使用 JDK 默认 TLS 证书与主机名校验。 |
| 失败行为 | 本地/内网代理不可解析、连接失败或返回非 200 时，返回付费搜索失败结果；不回退到公网地址或明文传输。 |

> 该条目用于说明本地/内网通信及端口，不代表产品内置或使用任何公网付费搜索服务。

## Mermaid 图表渲染

| 项目 | 说明 |
| --- | --- |
| 功能/组件 | 图与工作流的 Mermaid 图表导出（`MermaidRenderer`、`Drawable.toMermaidPng` / `Drawable.toMermaidSvg`、`Workflow.drawBytes`）。 |
| 必要性 | 仅在调用方请求将 Mermaid 图导出为 PNG 或 SVG 时使用；普通运行和仅生成 Mermaid 文本时不会发起此连接。 |
| 通信方向 | 产品实例主动向外发起的客户端出站连接；不监听本地端口。 |
| 目的地址 | `mermaid.ink`。 |
| 协议/传输层端口 | HTTPS / TCP 443。 |
| 调用方式 | `GET /img/{base64url-mermaid}` 或 `GET /svg/{base64url-mermaid}`。 |
| 传输数据 | Mermaid 图表文本经 Base64 URL 编码后置于请求路径；不携带认证凭据。调用方应避免将敏感信息写入待渲染的图表文本。 |
| 传输安全 | 使用 HTTPS；Java 标准 `HttpClient` 的默认 TLS 证书与主机名校验生效。 |
| 失败行为 | 最多重试 3 次；PNG 渲染失败返回空字节数组，SVG 渲染失败返回本地生成的兜底 SVG，不会降级为明文传输。 |
