本章节演示了如何基于openJiuwen快速开发自定义智能体。该示例构建的智能体能够调用大模型服务，并且识别大模型输出结果中可能包含的敏感词。通过示例，你将会了解到如下信息：

- 如何继承`AgentConfig`基类，实现自定义智能体的配置类。
- 如何重写`BaseAgent`基类的构造方法，实现自定义智能体的初始化。
- 如何实现`BaseAgent`基类定义的执行抽象接口`invoke`，同步执行自定义智能体的具体业务逻辑。

# 应用设计流程

本章节设计了一个自定义智能体，实现了一个更安全的智能体：能够基于预置敏感词校验输出答案。为了实现该智能体，开发者需要：

- 设计自定义智能体的配置类。
- 在智能体的构造方法中，向智能体配置预设的敏感词列表。
- 在自定义智能体的执行接口`invoke`中，实现智能体的业务逻辑：结合智能体的默认系统提示词和用户请求，构造调用大模型输入；进而调用大模型服务，并等待获取大模型的返回；最终基于智能体配置的敏感词列表，校验大模型输出，保障智能体不输出恶意信息。

# 前提条件

JDK 版本应高于或等于 JDK 17，建议使用 JDK 21。Maven 版本建议 3.9+。

# 添加 Maven 依赖

```xml
<dependency>
    <groupId>com.openjiuwen</groupId>
    <artifactId>openjiuwen-core</artifactId>
    <version>0.1.14</version>
</dependency>
```

# 实现自定义智能体的配置类

为了实现一个智能体能够调用大模型服务，并且识别大模型输出结果中可能包含的敏感词，除了`AgentConfig`中定义的基础配置项（如智能体的`id`、`version`、`description`等），还需要添加自定义配置（具体包括自定义调用大模型的配置信息`model`和自定义的敏感词列表`sensitive_words`）。示例代码如下：

```java
import com.openjiuwen.core.foundation.llm.schema.ModelConfig;
import com.openjiuwen.core.single_agent.schema.AgentCard;
import com.openjiuwen.core.single_agent.BaseAgent;
import java.util.List;

public class MyAgentCard extends AgentCard {
    private ModelConfig model;
    private List<String> sensitiveWords;

    public MyAgentCard() {
        this.sensitiveWords = List.of();
    }

    public ModelConfig getModel() { return model; }
    public void setModel(ModelConfig model) { this.model = model; }
    public List<String> getSensitiveWords() { return sensitiveWords; }
    public void setSensitiveWords(List<String> words) { this.sensitiveWords = words; }
}
```

```java
// 通过环境变量获取大模型相关的配置信息
ModelConfig createModelConfig() {
    return new ModelConfig()
        .setModelProvider(System.getenv().getOrDefault("MODEL_PROVIDER", "your provider"))
        .setModelName(System.getenv().getOrDefault("MODEL_NAME", "your model name"))
        .setApiBase(System.getenv().getOrDefault("API_BASE", "your api url"))
        .setApiKey(System.getenv().getOrDefault("API_KEY", "your api token"))
        .setTemperature(0.7)
        .setTopP(0.9)
        .setTimeout(30);
}

// 创建自定义智能体配置信息的对象
MyAgentCard card = new MyAgentCard();
card.setId("my_agent_id");
card.setName("my_agent");
card.setDescription("我的自定义智能体");
card.setModel(createModelConfig());
card.setSensitiveWords(List.of("自定义敏感词列表"));
```

# 实现构造方法

接下来，开发者需要实现自定义智能体的构造方法，支持创建自定义智能体的对象。`BaseAgent` 基类的构造方法为智能体提供了初始化 `Session`、配置管理 `Config` 的能力。除此之外，自定义智能体除了调用 `BaseAgent` 基类的构造方法，还需要根据大模型的配置信息创建大模型调用对象，并初始化配置的敏感词列表。具体示例如下：

```java
import com.openjiuwen.core.foundation.llm.Model;
import com.openjiuwen.core.foundation.llm.schema.ModelClientConfig;
import com.openjiuwen.core.foundation.llm.schema.ModelRequestConfig;
import com.openjiuwen.core.single_agent.schema.AgentCard;
import com.openjiuwen.core.single_agent.BaseAgent;

public class MyAgent extends BaseAgent {
    private ModelConfig modelConfig;
    private Model llm;
    private List<String> sensitiveWords;

    public MyAgent(MyAgentCard agentCard) {
        super(agentCard);
        this.modelConfig = agentCard.getModel();
        this.sensitiveWords = agentCard.getSensitiveWords();

        // 使用 Model + ModelClientConfig / ModelRequestConfig 创建大模型调用对象
        ModelClientConfig clientConfig = new ModelClientConfig()
            .setClientProvider(modelConfig.getModelProvider())
            .setApiKey(modelConfig.getApiKey())
            .setApiBase(modelConfig.getApiBase())
            .setTimeout(modelConfig.getTimeout());

        ModelRequestConfig requestConfig = new ModelRequestConfig()
            .setModel(modelConfig.getModelName())
            .setTemperature(modelConfig.getTemperature())
            .setTopP(modelConfig.getTopP());

        this.llm = new Model(clientConfig, requestConfig);
    }

    @Override
    public Object invoke(Map<String, Object> inputs, Session session) {
        // inputs是自定义智能体的输入，以llmInputs为键，用户输入信息作为用户提示词
        String userInput = (String) inputs.getOrDefault("llmInputs", "");

        // 构造大模型输入：系统提示词和用户提示词
        List<Map<String, String>> messages = List.of(
            Map.of("role", "system", "content", "你是一个AI助手"),
            Map.of("role", "user", "content", userInput)
        );

        // 调用模型获取输出
        Object res = llm.invoke(modelConfig.getModelName(), messages);
        String llmOutput = res.toString();

        // 敏感词校验
        for (String word : sensitiveWords) {
            if (llmOutput.contains(word)) {
                return "对不起，无法回答您的问题。";
            }
        }
        return llmOutput;
    }

    @Override
    public Object stream(Map<String, Object> inputs, Session session, List<StreamMode> modes) {
        return invoke(inputs, session);
    }
}
```

# 运行自定义智能体

```java
// 创建自定义智能体的对象
MyAgent agent = new MyAgent(card);

// 调用执行
Map<String, Object> inputs = Map.of("llmInputs", "写一个笑话");
Object result = agent.invoke(inputs, null);
System.out.println(result);
```

最终输出结果为：

```
为什么程序员不喜欢在夏天出门？

因为他们害怕"中暑"（中暑的拼音是 zhong shu，听起来像"中数"——他们整天都在处理"中数"问题，比如数组下标从0开始还是从1开始，已经够头疼了！）
```
