本章节演示了如何基于openJiuwen构建一个使用自定义组件的工作流样例，该样例支持通过用户输入，基于自定义分支组件选择不同的自定义组件分支，生成最终结果。通过本示例，你将会了解到如下信息：

* 如何创建自定义组件。
* 如何基于自定义组件创建工作流。

# 创建Workflow流程

创建Workflow的整体流程如下：首先通过`Workflow`初始化工作流，接着定义各组件并将组件注册到工作流，并设置组件间的连接，从而完成整个工作流的创建。本示例设计的Workflow如下：用户输入 → 意图识别 → 出行/就餐 → 返回结果。示例代码如下：

## 初始化工作流

初始化工作流：

```java
import com.openjiuwen.core.workflow.Workflow;

// 创建工作流
Workflow flow = new Workflow();
```

## 注册组件到工作流

根据任务需求创建核心组件实例，配置各组件的输入/输出规则，并将组件注册到工作流，实现流程的自动化与逻辑控制。本教程除了使用openJiuwen预置的开始与结束组件外，还自定义了分支组件和处理组件。

### 开始组件

通过`Start`创建开始组件对象，为工作流设置开始组件：

```java
import com.openjiuwen.core.workflow.component.Start;

flow.setStartComp("start", new Start(),
    Map.of("query", "${user_inputs.query}"));
```

### 自定义分支组件

创建自定义分支组件`CustomIntentComponent`，同时继承`WorkflowComponent`并实现`ComponentExecutable`，实现`addComponent`方法用于为本组件定制内置的条件边，并自定义实现了方法`addBranch`用于绑定内置条件边的目标节点：

```java
import com.openjiuwen.core.context_engine.ModelContext;
import com.openjiuwen.core.graph.Graph;
import com.openjiuwen.core.workflow.*;
import java.util.concurrent.ThreadLocalRandom;

public class CustomIntentComponent extends WorkflowComponent implements ComponentExecutable {
    private final List<String> intents;
    private final BranchRouter router;

    public CustomIntentComponent(List<String> defaultIntents) {
        this.intents = defaultIntents;
        this.router = new BranchRouter();
    }

    @Override
    public void addComponent(Graph graph, String nodeId, boolean waitForAll) {
        graph.addNode(nodeId, this.toExecutable(), waitForAll);
        graph.addConditionalEdges(nodeId, router);
    }

    public void addBranch(String condition, List<String> target, String branchId) {
        router.addBranch(condition, target, branchId);
    }

    @Override
    public Output invoke(Input inputs, Session session, ModelContext context) {
        router.setSession(session);
        int index = ThreadLocalRandom.current().nextInt(intents.size());
        return Output.of(Map.of("result", intents.get(index)));
    }
}
```

实例化自定义分支组件，分支包含`出行`和`餐饮`：

```java
CustomIntentComponent intentComponent = new CustomIntentComponent(List.of("出行", "餐饮"));
intentComponent.addBranch("${intent.result} == ''出行''", List.of("travel"), "1");
intentComponent.addBranch("${intent.result} == ''餐饮''", List.of("eat"), "2");
```

将自定义分支组件注册到工作流中：

```java
flow.addWorkflowComp("intent", intentComponent,
    Map.of("query", "${start.query}"));
```

### 自定义组件

创建自定义组件`TravelComponent`，用于`出行`分支：

```java
public class TravelComponent extends WorkflowComponent implements ComponentExecutable {
    private final String nodeId;

    public TravelComponent(String nodeId) {
        this.nodeId = nodeId;
    }

    @Override
    public Output invoke(Input inputs, Session session, ModelContext context) {
        System.out.printf("[%s] inputs = %s%n", nodeId, inputs);
        return Output.of(inputs);
    }
}
```

创建自定义组件`EatComponent`，用于`餐饮`分支：

```java
public class EatComponent extends WorkflowComponent implements ComponentExecutable {
    private final String nodeId;

    public EatComponent(String nodeId) {
        this.nodeId = nodeId;
    }

    @Override
    public Output invoke(Input inputs, Session session, ModelContext context) {
        System.out.printf("[%s] inputs = %s%n", nodeId, inputs);
        return Output.of(inputs);
    }
}
```

将自定义组件注册到工作流中：

```java
flow.addWorkflowComp("eat", new EatComponent("eat"),
    Map.of("intent", "${intent.result}"));
flow.addWorkflowComp("travel", new TravelComponent("travel"),
    Map.of("intent", "${intent.result}"));
```

### 结束组件

将`End`结束组件注册到工作流中：

```java
import com.openjiuwen.core.workflow.component.End;

flow.setEndComp("end", new End(),
    Map.of("eat", "${eat.intent}", "travel", "${travel.intent}"));
```

## 连接组件

通过调用 `flow.addConnection` 方法，可为工作流中的各个组件建立明确的连接关系，定义它们的执行顺序与逻辑流转：

```java
flow.addConnection("start", "intent");
flow.addConnection("eat", "end");
flow.addConnection("travel", "end");
```

## 运行工作流

基于以上搭建的工作流，调用`invoke`方法触发工作流执行：

```java
import com.openjiuwen.core.session.internal.WorkflowSession;

Session session = WorkflowSession.create();
Output output = flow.invoke(Map.of("user_inputs", Map.of("query", "去新疆")), session);
System.out.println(output.getResult());
```

选择`出行`分支时输出：

```
[travel] inputs = {intent=出行}
```

获取工作流输出结果：

```
{output: {travel: 出行}}
```
