本章节演示了如何基于openJiuwen构建一个使用自定义组件的工作流样例，该样例支持通过用户输入，基于自定义分支组件选择不同的自定义组件分支，生成最终结果。通过本示例，你将会了解到如下信息：

* 如何创建自定义组件。
* 如何基于自定义组件创建工作流。

# 创建Workflow流程

创建Workflow的整体流程如下：首先通过`Workflow`初始化工作流，接着定义各组件并将组件注册到工作流，并设置组件间的连接，从而完成整个工作流的创建。

## 初始化工作流

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowConfig;

WorkflowConfig config = WorkflowConfig.builder()
        .id("custom_workflow_demo")
        .name("Custom Workflow Demo")
        .build();
Workflow flow = new Workflow(config);
```

## 注册组件到工作流

根据任务需求创建核心组件实例，配置各组件的输入/输出规则，并将组件注册到工作流。本教程除了使用openJiuwen预置的开始与结束组件外，还自定义了分支组件和处理组件。

```java

### 自定义分支组件

创建自定义分支组件`CustomIntentComponent`，继承`WorkflowComponent`并实现条件路由逻辑：

```java
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.BranchRouter;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.context.ModelContext;
import java.util.Map;
import java.util.List;
import java.util.Random;

public class CustomIntentComponent extends WorkflowComponent {
    private final List<String> intents;
    private final BranchRouter router;
    private final Random random = new Random();
    
    public CustomIntentComponent(List<String> intents) {
        this.intents = intents;
        this.router = new BranchRouter();
    }
    
    public void addBranch(String condition, List<String> target, String branchId) {
        router.addBranch(condition, target, branchId);
    }
    
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        router.setSession(session);
        String selectedIntent = intents.get(random.nextInt(intents.size()));
        return Map.of("result", selectedIntent);
    }
}
```

# 什么是工作流组件

工作流组件是工作流图中的节点，每个组件负责执行特定的任务。openJiuwen提供了多种预置组件，同时也支持开发者创建自定义组件。

## 预置组件类型

- **Start**: 工作流入口，直接传递输入
- **End**: 工作流出口，可选响应模板渲染
- **LLMComponent**: 调用大模型
- **QuestionerComponent**: 提问用户
- **IntentDetectionComponent**: 意图识别
- **ToolComponent**: 调用工具

# 组件执行模式

WorkflowComponent支持四种执行模式：

| 方法 | 输入模式 | 输出模式 | 说明 |
|------|----------|----------|------|
| `invoke` | 批量 | 批量 | 同步执行，返回完整结果 |
| `stream` | 批量 | 流式 | 流式输出，返回Iterator |
| `collect` | 流式 | 批量 | 收集流式输入，返回完整结果 |
| `transform` | 流式 | 流式 | 流式输入和输出 |

# 创建自定义组件

## 步骤1: 继承WorkflowComponent

```java
package com.example.component;

import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.context.ModelContext;
import java.util.Map;
import java.util.Iterator;

/**
 * 自定义日志记录组件
 */
public class LoggingComponent extends WorkflowComponent {
    
    private String logLevel;
    private boolean includeTimestamp;
    
    public LoggingComponent(String logLevel, boolean includeTimestamp) {
        this.logLevel = logLevel;
        this.includeTimestamp = includeTimestamp;
    }
    
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 输入通常是Map类型
        Map<String, Object> inputMap = (inputs instanceof Map) 
                ? (Map<String, Object>) inputs 
                : Map.of("raw", inputs);
        
        String message = (String) inputMap.get("message");
        
        StringBuilder log = new StringBuilder();
        if (includeTimestamp) {
            log.append("[").append(System.currentTimeMillis()).append("] ");
        }
        log.append("[").append(logLevel.toUpperCase()).append("] ");
        log.append(message);
        
        System.out.println(log.toString());
        
        // 返回输出
        return Map.of(
            "logged", true,
            "logEntry", log.toString()
        );
    }
}
```

## 步骤2: 实现流式能力（可选）

```java
@Override
public Iterator<Object> stream(Object inputs, NodeSessionApi session, ModelContext context) {
    Map<String, Object> inputMap = (inputs instanceof Map) 
            ? (Map<String, Object>) inputs 
            : Map.of("raw", inputs);
    
    String message = (String) inputMap.get("message");
    
    // 返回流式Iterator
    return new Iterator<Object>() {
        private int index = 0;
        private final String[] chunks = message.split(" ");
        
        @Override
        public boolean hasNext() {
            return index < chunks.length;
        }
        
        @Override
        public Object next() {
            String chunk = chunks[index++];
            return Map.of("chunk", chunk, "index", index);
        }
    };
}
```

## 步骤3: 实现收集能力（可选）

收集模式用于处理流式输入并返回批量结果：

```java
@Override
public Object collect(Object inputs, NodeSessionApi session, ModelContext context) {
    // inputs可能是Iterator类型（流式输入）
    if (inputs instanceof Iterator<?> iterator) {
        StringBuilder collected = new StringBuilder();
        while (iterator.hasNext()) {
            Object item = iterator.next();
            if (item instanceof Map) {
                collected.append(((Map<?, ?>) item).get("chunk"));
            } else {
                collected.append(item);
            }
            collected.append(" ");
        }
        return Map.of("collected", collected.toString().trim());
    }
    // 批量输入直接处理
    return invoke(inputs, session, context);
}
```

## 步骤4: 实现转换能力（可选）

转换模式用于流式输入和流式输出：

```java
@Override
public Iterator<Object> transform(Object inputs, NodeSessionApi session, ModelContext context) {
    if (inputs instanceof Iterator<?> iterator) {
        return new Iterator<Object>() {
            @Override
            public boolean hasNext() {
                return iterator.hasNext();
            }
            
            @Override
            public Object next() {
                Object item = iterator.next();
                // 对每个流式项进行转换
                if (item instanceof Map) {
                    String chunk = (String) ((Map<?, ?>) item).get("chunk");
                    return Map.of("transformed", chunk.toUpperCase());
                }
                return Map.of("transformed", item.toString().toUpperCase());
            }
        };
    }
    return stream(inputs, session, context);
}
```

# 高级组件示例

## 数据转换组件

```java
package com.example.component;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.common.exception.ErrorHelper;
import com.openjiuwen.core.common.exception.StatusCode;
import java.util.Map;
import java.util.HashMap;

/**
 * JSON数据转换组件
 */
public class JsonTransformComponent extends WorkflowComponent {
    
    private final ObjectMapper mapper = new ObjectMapper();
    private TransformMode mode;
    
    public enum TransformMode {
        JSON_TO_MAP,
        MAP_TO_JSON,
        FLATTEN,
        UNFLATTEN
    }
    
    public JsonTransformComponent(TransformMode mode) {
        this.mode = mode;
    }
    
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (inputs instanceof Map) 
                ? (Map<String, Object>) inputs 
                : Map.of("data", inputs);
        
        try {
            switch (mode) {
                case JSON_TO_MAP:
                    return jsonToMap(inputMap);
                case MAP_TO_JSON:
                    return mapToJson(inputMap);
                case FLATTEN:
                    return flatten(inputMap);
                case UNFLATTEN:
                    return unflatten(inputMap);
                default:
                    throw ErrorHelper.buildError(StatusCode.COMPONENT_EXECUTION_ERROR,
                            "error_msg", "Unknown mode: " + mode);
            }
        } catch (Exception e) {
            throw ErrorHelper.buildError(StatusCode.COMPONENT_EXECUTION_ERROR,
                    "error_msg", "Transform failed: " + e.getMessage(),
                    "cause", e);
        }
    }
    
    private Object jsonToMap(Map<String, Object> inputs) throws Exception {
        String json = (String) inputs.get("data");
        return mapper.readValue(json, Map.class);
    }
    
    private Object mapToJson(Map<String, Object> inputs) throws Exception {
        Object data = inputs.get("data");
        return mapper.writeValueAsString(data);
    }
    
    @SuppressWarnings("unchecked")
    private Object flatten(Map<String, Object> inputs) {
        Map<String, Object> data = (Map<String, Object>) inputs.get("data");
        Map<String, Object> result = new HashMap<>();
        flattenHelper(data, "", result);
        return result;
    }
    
    @SuppressWarnings("unchecked")
    private void flattenHelper(Map<String, Object> data, String prefix, Map<String, Object> result) {
        for (Map.Entry<String, Object> entry : data.entrySet()) {
            String key = prefix.isEmpty() ? entry.getKey() : prefix + "." + entry.getKey();
            if (entry.getValue() instanceof Map) {
                flattenHelper((Map<String, Object>) entry.getValue(), key, result);
            } else {
                result.put(key, entry.getValue());
}
    }
}

# 条件路由组件（BranchRouter）

BranchRouter是一种特殊的组件类型，用于根据条件将工作流路由到不同的分支：

## 实现BranchRouter

```java
package com.example.component;

import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.common.exception.ErrorHelper;
import com.openjiuwen.core.common.exception.StatusCode;
import java.util.Map;
import java.util.List;
import java.util.function.Predicate;

/**
 * 条件路由组件 - 根据输入条件选择执行分支
 */
public class BranchRouter extends WorkflowComponent {
    
    private final List<Branch> branches;
    private final String defaultBranch;
    
    /**
     * 分支定义
     */
    public static class Branch {
        private final String name;
        private final Predicate<Map<String, Object>> condition;
        private final String targetComponent;
        
        public Branch(String name, Predicate<Map<String, Object>> condition, String targetComponent) {
            this.name = name;
            this.condition = condition;
            this.targetComponent = targetComponent;
        }
        
        public boolean matches(Map<String, Object> inputs) {
            return condition.test(inputs);
        }
        
        public String getTargetComponent() {
            return targetComponent;
        }
        
        public String getName() {
            return name;
        }
    }
    
    public BranchRouter(List<Branch> branches, String defaultBranch) {
        this.branches = branches;
        this.defaultBranch = defaultBranch;
    }
    
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (inputs instanceof Map) 
                ? (Map<String, Object>) inputs 
                : Map.of("raw", inputs);
        
        // 查找匹配的分支
        for (Branch branch : branches) {
            if (branch.matches(inputMap)) {
                // 设置路由目标
                session.updateNodeState(Map.of(
                    "route_target", branch.getTargetComponent(),
                    "route_branch", branch.getName()
                ));
                
                return Map.of(
                    "routed", true,
                    "branch", branch.getName(),
                    "target", branch.getTargetComponent(),
                    "inputs", inputMap
                );
            }
        }
        
        // 使用默认分支
        if (defaultBranch != null) {
            session.updateNodeState(Map.of(
                "route_target", defaultBranch,
                "route_branch", "default"
            ));
            
            return Map.of(
                "routed", true,
                "branch", "default",
                "target", defaultBranch,
                "inputs", inputMap
            );
        }
        
        // 无匹配分支
        throw ErrorHelper.buildError(StatusCode.COMPONENT_EXECUTION_ERROR,
                "error_msg", "No matching branch found for input");
    }
}
```

## 使用BranchRouter示例

```java
import com.example.component.BranchRouter;
import com.example.component.BranchRouter.Branch;
import java.util.List;

// 创建条件分支
List<Branch> branches = List.of(
    // 金额大于10000需要审批
    new Branch("high_amount", 
            inputs -> {
                Object amount = inputs.get("amount");
                return amount != null && Double.parseDouble(amount.toString()) > 10000;
            },
            "approval_node"),
    
    // 金额小于等于10000直接执行
    new Branch("normal_amount",
            inputs -> {
                Object amount = inputs.get("amount");
                return amount != null && Double.parseDouble(amount.toString()) <= 10000;
            },
            "execute_node"),
    
    // VIP用户直接执行
    new Branch("vip_user",
            inputs -> {
                Object vipLevel = inputs.get("vip_level");
                return vipLevel != null && vipLevel.toString().equals("gold");
            },
            "vip_execute_node")
);

// 创建路由组件
BranchRouter router = new BranchRouter(branches, "error_node");

// 添加到工作流
flow.add_workflow_comp("router", router, inputs_schema={
    "amount": "${questioner.amount}",
    "vip_level": "${user.vip_level}"
});

// 连接分支
flow.add_connection("router", "approval_node", condition="${router.branch} == 'high_amount'");
flow.add_connection("router", "execute_node", condition="${router.branch} == 'normal_amount'");
flow.add_connection("router", "vip_execute_node", condition="${router.branch} == 'vip_user'");
```

## 内置条件表达式

openJiuwen支持多种条件表达式格式：

| 表达式格式 | 示例 | 说明 |
|-----------|------|------|
| 字符串比较 | `${intent.classification_id} == 0` | 字符串相等判断 |
| 数值比较 | `${amount} > 10000` | 数值大小比较 |
| 布尔判断 | `${confirmed} == true` | 布尔值判断 |
| 包含判断 | `${tags} contains 'urgent'` | 集合包含判断 |
| 空值判断 | `${input} != null` | 非空判断 |

## 执行模式完整参考表

| 执行模式 | 方法 | 输入类型 | 输出类型 | 适用场景 |
|---------|------|---------|---------|---------|
| **invoke** | 同步批处理 | Map/Object | Map/Object | 简单任务、一次性操作 |
| **stream** | 流式输出 | Map/Object | Iterator | LLM响应、实时输出 |
| **collect** | 流式收集 | Iterator | Map/Object | 消息聚合、批量汇总 |
| **transform** | 流式转换 | Iterator | Iterator | 数据转换、管道处理 |

**选择指南**：
- 调用LLM生成回答 → 使用 `stream`
- 调用外部API获取数据 → 使用 `invoke`
- 处理上游流式输出并汇总 → 使用 `collect`
- 对流式数据进行逐项转换 → 使用 `transform`

# 在工作流中使用自定义组件

```java
package com.example;

import com.example.component.LoggingComponent;
import com.example.component.JsonTransformComponent;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowConfig;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.graph.Graph;
import java.util.Map;

public class CustomComponentExample {
    
    public static void main(String[] args) {
        // 创建工作流配置
        WorkflowConfig config = WorkflowConfig.builder()
                .id("custom_component_demo")
                .name("Custom Component Demo")
                .build();
        
        Workflow workflow = new Workflow(config);
        
        // 获取内部图
        Graph graph = workflow.getGraph();
        
        // 创建组件实例
        Start start = new Start();
        LoggingComponent logger = new LoggingComponent("INFO", true);
        JsonTransformComponent transform = new JsonTransformComponent(
                JsonTransformComponent.TransformMode.FLATTEN);
        End end = new End();
        
        // 添加组件到图
        start.addComponent(graph, "start", false);
        logger.addComponent(graph, "logger", false);
        transform.addComponent(graph, "transform", false);
        end.addComponent(graph, "end", false);
        
        // 添加连接（设置数据传递映射）
        graph.addConnection("start", "logger", 
                Map.of("message", "Processing started"));
        graph.addConnection("logger", "transform", 
                Map.of("data", "${start}"));
        graph.addConnection("transform", "end", 
                Map.of("result", "${transform}"));
        
        // 执行工作流
        Map<String, Object> result = workflow.invoke(Map.of(
            "input", Map.of("user", Map.of("name", "张三", "age", 30))
        ));
        
        System.out.println("Result: " + result);
    }
}
```
