# 概述

Java 版多智能体栏目以当前仓库里已经公开的 `BaseGroup + GroupCard + GroupConfig + MultiAgentSessions` 为主线。成员管理、会话、消息路由与共享资源等职责主要落在分组基类、会话门面、legacy controller 和 examples 层。

## 功能定位

本页先建立 Java 侧的整体心智模型：哪些类型属于推荐的新 API，哪些属于兼容层，哪些只是 examples 里的演示桥接代码。先把这个边界分清，再读后面的 [BaseGroup与组封装](BaseTeam.md) 和 [组运行时职责与通信协作](TeamRuntime与CommunicableAgent.md) 两页会更稳。

## 核心对象

| 对象 | 作用 | 当前定位 |
| --- | --- | --- |
| `BaseGroup` | 新版分组抽象基类，统一管理成员注册、配置和 `invoke/stream` 入口 | 推荐主线 |
| `GroupCard` | 分组身份卡片，描述名称、成员、topic、版本和标签 | 推荐主线 |
| `GroupConfig` | 分组运行参数，控制成员上限、并发和超时 | 推荐主线 |
| `Session` / `MultiAgentSessions` | 分组会话和静态工厂门面，承接状态、环境变量和流式输出 | 推荐主线 |
| `ControllerGroup` / `BaseGroupController` | 旧版控制器式分组与组内消息路由 | 兼容层 / 示例映射 |
| `examples/groups` | 用例层的 leader-worker 协作样例 | 示例层，不是稳定公共 API |

## 推荐主线

如果你要在 Java 中组织一组协作 Agent，推荐按下面这条路径理解：

1. 用 `GroupCard` 定义这个 group 是谁，要对外暴露哪些成员卡片。
2. 用 `GroupConfig` 定义运行时阈值，例如最大成员数、默认超时和并发消息上限。
3. 继承 `BaseGroup`，在子类里注册成员 Agent，并实现自己的 `invoke(...)` / `stream(...)`。
4. 用 `MultiAgentSessions.createAgentGroupSession(...)` 或 `Session.create(...)` 创建分组会话，把状态和环境变量带进一次 group 执行。

这条主线本身不单独拆出一个通信运行时类型；Java 更偏向“分组封装 + 会话门面”的写法。

## 兼容与示例路径

当前仓库仍保留一条 controller 驱动的兼容路径：

- `ControllerGroup` 负责把外部消息转换成 `GroupEvent`，再委托给 `BaseGroupController`。
- `BaseGroupController` 负责订阅关系、点对点转发、广播和消息队列消费。
- `examples/groups/hierarchical_group` 在 examples 层补了一层最小 bridge，用来演示 leader-worker 路由和中断恢复。

这条路径能帮助你理解当前消息路由、广播和恢复职责如何落到 controller / session 上，但它不是推荐的新主线，也不应该被误写成正式公共抽象。

## 最小心智模型

下面这段代码展示了 Java 当前推荐主线的最小外形：

```java
GroupCard card = GroupCard.builder()
        .id("review_group")
        .name("review_group")
        .description("负责协作评审")
        .build();

GroupConfig config = new GroupConfig()
        .configureMaxAgents(4)
        .configureTimeout(30.0)
        .configureConcurrency(20);

BaseGroup group = new ReviewGroup(card, config);
Session session = MultiAgentSessions.createAgentGroupSession("conversation-001");

Object result = group.invoke("请把任务分给合适的成员", session);
```

这里的重点不是 `ReviewGroup` 这个名字，而是“卡片定义身份、配置描述运行参数、分组子类承接执行入口、会话对象承接上下文”这条结构。

## 当前能力边界

- Java 当前的公开主线由 `BaseGroup`、`Session` 和 `MultiAgentSessions` 组成；消息路由能力主要位于 legacy controller。
- `examples/groups` 里的层级协作示例故意停留在 example 层，用于帮助理解 group/controller 的组合方式。
- `ControllerGroup` 与 `BaseGroupController` 都带有兼容层属性；如果你在写新文档或新代码，默认先看 `BaseGroup`、`GroupCard` 和 `GroupConfig`。
