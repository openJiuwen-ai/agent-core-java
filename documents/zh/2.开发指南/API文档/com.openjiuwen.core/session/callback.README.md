# callback

`com.openjiuwen.core.session.callback` 负责定义回调处理器基类、回调管理器以及事件触发注解。

## 类型

| 类型 | 说明 |
| --- | --- |
| [`BaseHandler`](./callback/BaseHandler.md) | 回调处理器抽象基类。 |
| [`CallbackManager`](./callback/CallbackManager.md) | 管理处理器注册与事件触发。 |
| [`TriggerEvent`](./callback/TriggerEvent.md) | 标记回调触发方法的运行时注解。 |
