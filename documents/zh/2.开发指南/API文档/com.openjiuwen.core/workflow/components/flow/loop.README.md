# loop

`com.openjiuwen.core.workflow.component.flow.loop` 提供旧版兼容的 loop 组件与循环体容器。

## 类型

| 类型 | 种类 | 说明 |
| --- | --- | --- |
| [LoopComponent](./loop/LoopComponent.md) | `class` | 旧版兼容循环组件类型，复用新版 `LoopComponentImpl` 的构造方式。 |
| [LoopGroup](./loop/LoopGroup.md) | `class` | 旧版兼容循环体容器，提供与历史包路径一致的 `addWorkflowComp` 重载。 |

## 说明

- 当前包收录 2 个类型页面。
