# tool

`com.openjiuwen.core.workflow.components.tool` 提供旧版兼容的 Tool 组件与配置包装类型。

## 类型

| 类型 | 种类 | 说明 |
| --- | --- | --- |
| [ToolComponent](./tool/ToolComponent.md) | `class` | 旧版兼容 Tool 组件包装类型，复用新版 `component.tool.ToolComponent`。 |
| [ToolComponentConfig](./tool/ToolComponentConfig.md) | `class` | 旧版兼容 Tool 配置包装类型，补充位置参数构造方法以兼容旧调用方式。 |

## 说明

- 当前包收录 2 个类型页面。
