# reasoner

`com.openjiuwen.core.controller.legacy.reasoner` 提供旧版意图检测器、Planner 和组合式 reasoner。

## Types

| 类型 | 说明 |
|---|---|
| [`AgentReasoner`](./reasoner/AgentReasoner.md) | 组合 `IntentDetector` 与 `Planner` 的轻量 reasoner。 |
| [`DefaultIntentDetector`](./reasoner/DefaultIntentDetector.md) | 默认意图检测实现。 |
| [`DefaultPlanner`](./reasoner/DefaultPlanner.md) | 默认 Planner 实现。 |
| [`IntentDetector`](./reasoner/IntentDetector.md) | 旧版意图检测接口。 |
| [`Planner`](./reasoner/Planner.md) | 旧版任务规划接口。 |
