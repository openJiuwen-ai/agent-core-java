# config

`com.openjiuwen.core.controller.legacy.config` 定义旧版意图检测与 reasoner 组合链路所需的配置对象。

## Types

| 类型 | 说明 |
|---|---|
| [`IntentDetectionConfig`](./config/IntentDetectionConfig.md) | 旧版意图检测配置。 |
| [`PlannerConfig`](./config/PlannerConfig.md) | 旧版 Planner 配置占位类型。 |
| [`ProactiveIdentifierConfig`](./config/ProactiveIdentifierConfig.md) | 旧版主动识别模块配置占位类型。 |
| [`ReasonerConfig`](./config/ReasonerConfig.md) | 组合 `IntentDetectionConfig`、`PlannerConfig`、`ReflectorConfig` 的总配置。 |
| [`ReflectorConfig`](./config/ReflectorConfig.md) | 旧版 Reflector 配置占位类型。 |
