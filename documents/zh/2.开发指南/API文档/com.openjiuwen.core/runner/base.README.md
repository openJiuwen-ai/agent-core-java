# base

`com.openjiuwen.core.runner.base` 定义运行器资源注册和标签系统共用的 Provider、结果和标签基础类型。

## 类型

| Type | Description |
| --- | --- |
| [`AgentGroupProvider`](base/AgentGroupProvider.md) | `AgentGroupProvider` 定义 `com.openjiuwen.core.runner.base` 下的扩展契约。 |
| [`AgentProvider`](base/AgentProvider.md) | `AgentProvider` 定义 `com.openjiuwen.core.runner.base` 下的扩展契约。 |
| [`Error`](base/Error.md) | Represents a failed operation result following the Result pattern. |
| [`ModelProvider`](base/ModelProvider.md) | `ModelProvider` 定义 `com.openjiuwen.core.runner.base` 下的扩展契约。 |
| [`Ok`](base/Ok.md) | Represents a successful operation result following the Result pattern. |
| [`Result`](base/Result.md) | Result type for type-safe error handling. |
| [`Tag`](base/Tag.md) | Tag type constants for categorizing and filtering resources. |
| [`TagMatchStrategy`](base/TagMatchStrategy.md) | Strategy for matching multiple tags when querying or filtering resources. |
| [`TagUpdateStrategy`](base/TagUpdateStrategy.md) | Strategy for updating resource tags. |
| [`WorkflowProvider`](base/WorkflowProvider.md) | `WorkflowProvider` 定义 `com.openjiuwen.core.runner.base` 下的扩展契约。 |
