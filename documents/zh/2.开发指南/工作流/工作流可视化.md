openJiuwen开发框架支持可视化展示构建完成的工作流，用户可在工作流构建完成后，通过调用工作流的可视化相关接口生成[mermaid](https://mermaid.js.org/)脚本或其渲染出的图片，方便工作流的直观展示与问题排查。

# 前提条件

默认的图片渲染需要联网访问`https://mermaid.ink`，若使用环境联网正常，则无需配置。若使用环境无法联网，需本地安装[mermaid.ink](https://github.com/jihchi/mermaid.ink)，并配置环境变量`MERMAID_INK_SERVER`为本地`mermaid.ink`的地址。

# 可视化简单工作流

首先，导入构造工作流需要的模块：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.component.ComponentAbility;
```

接着自定义一个组件类，用于接收输入并返回结果：

```java
WorkflowComponent nodeA = new WorkflowComponent() {
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        return inputs;
    }
};
```

然后基于自定义组件搭建一个简单的工作流：

```java
Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("value", "${value}"), null);
flow.addWorkflowComp("a", nodeA, Map.of("value", "${start.value}"), null);
flow.setEndComp("end", new End(), Map.of("result", "${a.value}"), null);
flow.addConnection("start", "a");
flow.addConnection("a", "end");
```

可视化工作流为PNG图片：

```java
import java.nio.file.Files;
import java.nio.file.Path;

String mermaid = flow.draw("simple workflow", "mermaid", 0, false);
System.out.println(mermaid);

byte[] png = flow.drawBytes("simple workflow", "png", 0);
if (png.length > 0) {
    Files.write(Path.of("simple_workflow.png"), png);
}
```

# 可视化带流式边的工作流

创建带流式边的工作流：

```java
WorkflowComponent streamNode = new WorkflowComponent() {
    @Override
    public Iterator<Object> stream(Object inputs, NodeSessionApi session, ModelContext context) {
        return List.of(Map.of("value", "frame1"), Map.of("value", "frame2")).iterator();
    }
};

Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("value", "${value}"), null);
flow.addWorkflowComp("a", streamNode, true,
    Map.of("value", "${start.value}"), null,
    null, null,
    List.of(ComponentAbility.STREAM));
flow.setEndComp("end", new End(), 
    null, null,
    Map.of("data", "${a.value}"), 
    null, "streaming");
    
flow.addConnection("start", "a");
flow.addStreamConnection("a", "end");
```

可视化为SVG图片（展示流式边动画效果）：

```java
byte[] svg = flow.drawBytes("workflow with stream edge", "svg", 0);
Files.write(Path.of("stream_workflow.svg"), svg);
```

# 可视化带分支的工作流

使用`BranchRouter`创建带分支的工作流：

```java
import com.openjiuwen.core.workflow.component.BranchRouter;

BranchRouter router = new BranchRouter();
router.addBranch("${start.a} > 0", "a", null);
router.addBranch("${start.b} > 0", "b", null);

Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), 
    Map.of("a", "${a}", "b", "${b}"), null);
flow.addWorkflowComp("a", nodeA, Map.of("value", "${start.a}"), null);
flow.addWorkflowComp("b", nodeA, Map.of("value", "${start.b}"), null);
flow.setEndComp("end", new End(), Map.of("result", "${a.value}"), null);

flow.addConditionalConnection("start", router);
flow.addConnection("a", "end");
flow.addConnection("b", "end");
```

可视化：

```java
byte[] png = flow.drawBytes("workflow with branch", "png", 0);
Files.write(Path.of("branch_workflow.png"), png);
```

# 可视化嵌套工作流

创建子工作流和主工作流：

```java
import com.openjiuwen.core.workflow.component.SubWorkflowComponentImpl;

// 创建子工作流
Workflow subFlow = new Workflow();
subFlow.setStartComp("sub_start", new Start(), Map.of("value", "${value}"), null);
subFlow.addWorkflowComp("sub_a", nodeA, Map.of("value", "${sub_start.value}"), null);
subFlow.setEndComp("sub_end", new End(), Map.of("result", "${sub_a.value}"), null);
subFlow.addConnection("sub_start", "sub_a");
subFlow.addConnection("sub_a", "sub_end");

// 创建主工作流
Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("value", "${value}"), null);
flow.addWorkflowComp("a", nodeA, Map.of("value", "${start.value}"), null);
flow.addWorkflowComp("sub_flow", new SubWorkflowComponentImpl(subFlow), 
    Map.of("value", "${a.value}"), null);
flow.setEndComp("end", new End(), Map.of("result", "${sub_flow.result}"), null);
flow.addConnection("start", "a");
flow.addConnection("a", "sub_flow");
flow.addConnection("sub_flow", "end");
```

不展开子工作流的可视化：

```java
byte[] png = flow.drawBytes("nested workflow", "png", 0);  // expandSubgraph=0
Files.write(Path.of("nested_no_expand.png"), png);
```

展开子工作流的可视化：

```java
byte[] png = flow.drawBytes("nested workflow", "png", 1);  // expandSubgraph=1
Files.write(Path.of("nested_expand.png"), png);
```

# 可视化多层嵌套工作流

创建二级嵌套工作流：

```java
// 创建二级子工作流
Workflow subFlow1 = new Workflow();
subFlow1.setStartComp("sub_start1", new Start(), Map.of("value", "${value}"), null);
subFlow1.addWorkflowComp("sub_a1", nodeA, Map.of("value", "${sub_start1.value}"), null);
subFlow1.setEndComp("sub_end1", new End(), Map.of("result", "${sub_a1.value}"), null);
subFlow1.addConnection("sub_start1", "sub_a1");
subFlow1.addConnection("sub_a1", "sub_end1");

// 创建一级子工作流
Workflow subFlow = new Workflow();
subFlow.setStartComp("sub_start", new Start(), Map.of("value", "${value}"), null);
subFlow.addWorkflowComp("sub_a", nodeA, Map.of("value", "${sub_start.value}"), null);
subFlow.addWorkflowComp("sub_flow1", new SubWorkflowComponentImpl(subFlow1), 
    Map.of("value", "${sub_a.value}"), null);
subFlow.setEndComp("sub_end", new End(), Map.of("result", "${sub_flow1.result}"), null);
subFlow.addConnection("sub_start", "sub_a");
subFlow.addConnection("sub_a", "sub_flow1");
subFlow.addConnection("sub_flow1", "sub_end");

// 主工作流
Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("value", "${value}"), null);
flow.addWorkflowComp("a", nodeA, Map.of("value", "${start.value}"), null);
flow.addWorkflowComp("sub_flow", new SubWorkflowComponentImpl(subFlow), 
    Map.of("value", "${a.value}"), null);
flow.setEndComp("end", new End(), Map.of("result", "${sub_flow.result}"), null);
flow.addConnection("start", "a");
flow.addConnection("a", "sub_flow");
flow.addConnection("sub_flow", "end");
```

展开不同层级的可视化：

```java
// 不展开
byte[] png0 = flow.drawBytes("multilayer nested", "png", 0);

// 展开一层
byte[] png1 = flow.drawBytes("multilayer nested", "png", 1);

// 展开两层
byte[] png2 = flow.drawBytes("multilayer nested", "png", 2);
```

# 可视化带循环的工作流

使用`LoopGroup`和`LoopComponentImpl`创建带循环的工作流：

```java
import com.openjiuwen.core.workflow.component.loop.LoopGroup;
import com.openjiuwen.core.workflow.component.loop.LoopComponentImpl;

// 创建循环体
LoopGroup loopGroup = new LoopGroup();
loopGroup.addWorkflowComp("node1", nodeA, Map.of("value", "${loop.item}"), null);
loopGroup.addWorkflowComp("node2", nodeA, Map.of("value", "${node1.value}"), null);
loopGroup.addWorkflowComp("node3", nodeA, Map.of("value", "${node2.value}"), null);
loopGroup.startComp("node1");
loopGroup.endComp("node3");
loopGroup.addConnection("node1", "node2");
loopGroup.addConnection("node2", "node3");

// 创建工作流
Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("items", "${items}"), null);
flow.addWorkflowComp("a", nodeA, Map.of("value", "${start.items}"), null);
flow.addWorkflowComp("loop", new LoopComponentImpl(loopGroup, Map.of()), 
    Map.of("loopType", "number", "loopNumber", 1), null);
flow.setEndComp("end", new End(), Map.of("result", "${loop.result}"), null);
flow.addConnection("start", "a");
flow.addConnection("a", "loop");
flow.addConnection("loop", "end");
```

不展开循环组件：

```java
byte[] png = flow.drawBytes("workflow with loop", "png", 0);
```

展开循环组件：

```java
byte[] png = flow.drawBytes("workflow with loop", "png", -1);  // -1表示全部展开
```

# Java可视化API说明

Java版提供了以下可视化方法：

| 方法 | 返回类型 | 说明 |
| --- | --- | --- |
| `draw()` | `String` | 返回Mermaid文本 |
| `draw(title, format, expandSubgraph, enableAnimation)` | `String` | 返回指定格式的Mermaid文本 |
| `drawBytes(title, format, expandSubgraph)` | `byte[]` | 返回PNG或SVG二进制数据 |

`expandSubgraph`参数说明：
- `0`：不展开子图
- 正整数：按层级展开
- `-1`或`true`：全部展开
