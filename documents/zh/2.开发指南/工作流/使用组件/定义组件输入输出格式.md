openJiuwen支持定义组件的输入输出格式。当把组件添加到工作流时，可配置组件的输入输出格式要求，也可对组件的输入输出进行格式化，确保工作流中数据传递的标准化。

openJiuwen提供了以下两种数据格式化方式：

- **配置schema**：通过Map来指定组件输入输出的key和value。添加组件到工作流时，可根据组件能力及与上游组件的连接方式，按需配置`inputsSchema`/`streamInputsSchema`；也可根据组件能力及与下游组件的连接方式，按需配置`outputsSchema`/`streamOutputsSchema`。适用于数据结构较为简单、明确的场景。

# 通过配置schema定义组件输入输出格式

schema是一种组件输入输出的结构描述：

- **输入**：
    - 若和前序组件为普通连接，可配置`inputsSchema`。
    - 若和前序组件为流式连接，可配置`streamInputsSchema`。
    - 若和前序组件既有普通连接又有流式连接，可同时配置`inputsSchema`和`streamInputsSchema`。
- **输出**： 
    - 若和后序组件为普通连接，可配置`outputsSchema`。
    - 若和后序组件为流式连接，可配置`streamOutputsSchema`。
    - 若和后序组件既有普通连接又有流式连接，可同时配置`outputsSchema`和`streamOutputsSchema`。

## 配置输入schema

以开始组件和结束组件之间的普通连接为例，结束组件可通过`${start.query}`的方式引用开始组件的`query`参数：

```java
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.Workflow;

Workflow workflow = new Workflow();
workflow.setEndComp("end", new End(), Map.of("query", "${start.query}"), null);
workflow.addConnection("start", "end");
```

若和前序组件是流式连接，以大模型组件和结束组件之间的流式连接为例：

```java
workflow.setEndComp("end_stream", new End(), 
    null, null, 
    Map.of("data", "${llm.output}"), null, null);
workflow.addStreamConnection("llm", "end_stream");
```

若和前序组件既有普通连接又有流式连接：

```java
Map<String, Object> endInputsSchema = Map.of("query", "${inputs.userInput}");
Map<String, Object> endStreamInputsSchema = Map.of("llmOutput", "${llm.output}");

workflow.setEndComp("end", new End(), 
    endInputsSchema, null,
    endStreamInputsSchema, null, null);
workflow.addConnection("start", "end");
workflow.addStreamConnection("llm", "end");
```

## 配置输出schema

若和后序组件是普通连接，组件a的invoke方法返回值`invokeValue`通过outputsSchema格式化为`invokeOutput`：

```java
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.ComponentAbility;

WorkflowComponent invokeNode = new WorkflowComponent() {
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (Map<String, Object>) inputs;
        Integer value = (Integer) inputMap.get("value");
        return Map.of("value", value * 2);
    }
};

Workflow workflow = new Workflow();
workflow.addWorkflowComp("a", invokeNode, true,
    Map.of("value", "${start.a}"), Map.of("invokeOutput", "${value}"),
    null, null,
    List.of(ComponentAbility.INVOKE));
```

若和后序组件是流式连接，组件a的stream方法返回值通过streamOutputsSchema格式化：

```java
WorkflowComponent streamNode = new WorkflowComponent() {
    @Override
    public Iterator<Object> stream(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (Map<String, Object>) inputs;
        Integer value = (Integer) inputMap.get("value");
        return List.of(Map.of("value", value), Map.of("value", value * 2)).iterator();
    }
};

workflow.addWorkflowComp("a", streamNode, true,
    Map.of("value", "${start.a}"), null,
    null, Map.of("streamOutput", "${value}"),
    List.of(ComponentAbility.STREAM));
```

若和后序组件既有普通连接又有流式连接：

```java
workflow.addWorkflowComp("a", streamNode, true,
    Map.of("value", "${start.a}"), Map.of("invokeOutput", "${value}"),
    null, Map.of("streamOutput", "${value}"),
    List.of(ComponentAbility.STREAM, ComponentAbility.INVOKE));
```
