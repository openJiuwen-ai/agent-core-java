# 开始组件

`Start`组件为openJiuwen工作流的内置开始组件，该组件定义了工作流的入口点，用于接收用户的输入。

定义工作流，并通过`setStartComp`方法将开始组件`start`添加到工作流中。其中`inputsSchema`用于明确规定开始组件`start`输入参数的来源，需要遵循key-value的配置规则，key来源于自定义的参数名，value可使用`${}`的方式引用工作流输入变量值：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;

Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), 
    Map.of("query", "${userInputs.query}", "tokens", "${userInputs.tokens}"), null);
```

通过`invoke`方法配置工作流输入，并运行工作流：

```java
import com.openjiuwen.core.workflow.WorkflowSessions;
import com.openjiuwen.core.workflow.WorkflowOutput;

WorkflowSessionApi session = WorkflowSessions.createWorkflowSession();
WorkflowOutput output = workflow.invoke(
    Map.of("userInputs", Map.of("query", "hello world", "tokens", List.of("a", "b"))), 
    session, null);
```

`Start`组件会基于用户的输入参数直接输出inputsSchema映射后的结果，此时输出的结果为：

```java
{
    "query": "hello world",
    "tokens": ["a", "b"]
}
```

要输出工作流的最终结果，需要配置`End`组件。以下是一个配置`Start`组件、`End`组件，并运行输出的完整示例：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.WorkflowSessions;
import com.openjiuwen.core.workflow.WorkflowOutput;

// 新建工作流
Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), 
    Map.of("query", "${userInputs.query}", "tokens", "${userInputs.tokens}"), null);

// 配置End组件，带模板
workflow.setEndComp("end", 
    new End(Map.of("responseTemplate", "Query:{{param1}}, Tokens:{{param3}}")),
    Map.of("param1", "${start.query}", "param3", "${start.tokens}"), null);

// 连接start和end节点
workflow.addConnection("start", "end");

// 输入并运行
Map<String, Object> inputs = Map.of(
    "userInputs", Map.of("query", "你好 openJiuwen", "tokens", List.of("a", "b"))
);
WorkflowSessionApi session = WorkflowSessions.createWorkflowSession();
WorkflowOutput output = workflow.invoke(inputs, session, null);
System.out.println(output.getResult());
```

上述代码中，`End`组件会对格式化后的输入参数进行模板渲染，并输出如下结果：

```java
{'response': "Query:你好 openJiuwen, Tokens:['a', 'b']"}
```

如果`End`组件未配置模板（即直接`new End()`），则输出为：

```java
{'output': {'param1': '你好 openJiuwen', 'param3': ['a', 'b']}}
```

# 结束组件

`End`组件是openJiuwen工作流的内置结束组件，该组件定义了工作流的输出点。将`End`组件添加到工作流时可根据inputsSchema格式化`End`组件的输入参数，创建`End`组件时可通过配置Map来设置响应模板，对工作流的输出信息进行渲染。`End`组件实现了组件的四种能力：`invoke`、`stream`、`transform`和`collect`，实现的原理是对不同的输入进行相应的格式化输出。`End`组件的模板采用标准语言规范，使用`{{}}`语法表示占位槽位，模板渲染的过程，根据`End`组件实际输入对这些槽位进行动态填充，最终生成完整的输出结果。

## invoke能力

**invoke**：同步执行组件，一次性返回最终结果，适合一次性获取完整结果的场景。当`End`组件配置了模板（配置中包含`responseTemplate`）时，返回结果中包含`response`字段，表示模板渲染后的结果；当`End`组件未配置模板时，返回结果中包含`output`字段，表示`End`组件的输出结果。

构造简单工作流，并添加`Start`组件到工作流：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;

Workflow flow = new Workflow();
// 增加Start节点
flow.setStartComp("start", new Start(), 
    Map.of("query", "${userInputs.query}", "content", "${userInputs.content}"), null);
```

创建不带模板的`End`组件并添加到工作流：

```java
import com.openjiuwen.core.workflow.component.End;

flow.setEndComp("end", new End(), 
    Map.of("param1", "${start.query}", "param2", "${start.content}"), null);
```

连接`Start`组件和`End`组件，并运行工作流：

```java
import com.openjiuwen.core.workflow.WorkflowSessions;
import com.openjiuwen.core.workflow.WorkflowOutput;

flow.addConnection("start", "end");
WorkflowSessionApi session = WorkflowSessions.createWorkflowSession();
WorkflowOutput result = flow.invoke(
    Map.of("userInputs", Map.of("query", "你好", "content", "杭州")), 
    session, null);
System.out.println(result.getResult());
```

输出结果如下：

```java
{'output': {'param1': '你好', 'param2': '杭州'}}
```

若创建带模板的`End`组件：

```java
flow.setEndComp("end", 
    new End(Map.of("responseTemplate", "渲染结果:{{param1}},{{param2}}")),
    Map.of("param1", "${start.query}", "param2", "${start.content}"), null);
```

则会对`End`组件输入进行模板渲染后输出到response字段，输出结果如下：

```java
{'response': '渲染结果:你好,杭州'}
```

## stream能力

**stream**：`End`组件将批结果格式化为多帧`OutputSchema`格式的流式数据，适合需要实时反馈的场景。

构造简单工作流并配置End组件的流式输出：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.WorkflowSessions;
import com.openjiuwen.core.session.stream.OutputSchema;
import com.openjiuwen.core.session.stream.StreamMode;
import com.openjiuwen.core.workflow.WorkflowChunk;

Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), 
    Map.of("query", "${userInputs.query}", "content", "${userInputs.content}"), null);

// 设置responseMode为streaming
flow.setEndComp("end", new End(), 
    null, null, 
    Map.of("param1", "${start.query}", "param2", "${start.content}"), 
    null, "streaming");

flow.addConnection("start", "end");

// 流式执行
Iterator<WorkflowChunk> chunks = flow.stream(
    Map.of("userInputs", Map.of("query", "你好", "content", "杭州")),
    WorkflowSessions.createWorkflowSession(),
    null, List.of(StreamMode.OUTPUT));

while (chunks.hasNext()) {
    WorkflowChunk chunk = chunks.next();
    if (chunk instanceof OutputSchema output) {
        System.out.println(output);
    }
}
```

`End`组件会遍历每个输入字段，分别作为流式数据的`payload`进行流式输出，输出结果如下：

```java
OutputSchema(type='end node stream', index=0, payload={'output': {'param1': '你好'}})
OutputSchema(type='end node stream', index=1, payload={'output': {'param2': '杭州'}})
```

## transform能力

**transform**：`End`组件将流式输入逐帧格式化为`OutputSchema`格式的流式数据。

创建一个mock节点用于流式输出，然后配置End组件的transform能力：

```java
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.component.ComponentAbility;

// 自定义流式组件
WorkflowComponent mockStream = new WorkflowComponent() {
    @Override
    public Iterator<Object> stream(Object inputs, NodeSessionApi session, ModelContext context) {
        return List.of(Map.of("param1", "你好"), Map.of("param2", "杭州")).iterator();
    }
};

Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), 
    Map.of("query", "${userInputs.query}"), null);

flow.addWorkflowComp("mock", mockStream, true,
    Map.of("query", "${start.query}"), null,
    null, null,
    List.of(ComponentAbility.STREAM));

// End组件使用streamInputsSchema接收流输入
flow.setEndComp("end", new End(), 
    null, null,
    Map.of("param1", "${mock.param1}", "param2", "${mock.param2}"), 
    null, "streaming");

flow.addConnection("start", "mock");
flow.addStreamConnection("mock", "end");
```

## collect能力

**collect**：`End`组件对流式数据进行汇聚并合并为一次完整的返回。

```java
import com.openjiuwen.core.workflow.WorkflowSessions;
import com.openjiuwen.core.workflow.WorkflowOutput;

WorkflowSessionApi session = WorkflowSessions.createWorkflowSession();
WorkflowOutput result = flow.invoke(
    Map.of("userInputs", Map.of("query", "你好")),
    session, null);
System.out.println(result);
```

输出为：

```java
WorkflowOutput(result={'collect_output': [{'param1': '你好'}, {'param2': '杭州'}]}, state=COMPLETED)
```

若创建带模板的`End`组件：

```java
flow.setEndComp("end", 
    new End(Map.of("responseTemplate", "渲染结果:{{param1}},{{param2}}")),
    null, null,
    Map.of("param1", "${start.query}", "param2", "${start.query}"),
    null, null);
```

最终结果：

```java
WorkflowOutput(result={'response': '渲染结果:你好,杭州'}, state=COMPLETED)
```

# 大模型组件

大模型组件通过调用大语言模型，并根据输入提示词生成输出内容，支持将用户自定义的输入变量填充到预定义的提示词模板中，并可选择是否启用对话历史记录，支持JSON、Markdown、Text等多种输出格式。

创建大模型组件的配置信息对象`LLMCompConfig`，指定组件调用的大模型的具体配置信息`modelClientConfig`、`modelConfig`、大模型提示词模板信息`templateContent`、输出格式信息`responseFormat`、输出参数信息`outputConfig`：

```java
import com.openjiuwen.core.foundation.llm.ModelClientConfig;
import com.openjiuwen.core.foundation.llm.ModelRequestConfig;
import com.openjiuwen.core.workflow.component.llm.LLMCompConfig;
import com.openjiuwen.core.workflow.component.llm.LLMComponent;

ModelClientConfig clientConfig = new ModelClientConfig();
clientConfig.setApiBase("https://api.openai.com/v1");
clientConfig.setApiKey("your-api-key");

ModelRequestConfig requestConfig = new ModelRequestConfig();
requestConfig.setModel("gpt-3.5-turbo");
requestConfig.setTemperature(0.7);
requestConfig.setTopP(0.9);
requestConfig.setTimeout(30);

LLMCompConfig config = new LLMCompConfig();
config.setModelClientConfig(clientConfig);
config.setModelConfig(requestConfig);
config.setTemplateContent(List.of(
    Map.of("role", "system", "content", "你是一个AI助手。"),
    Map.of("role", "user", "content", "{{query}}")
));
config.setResponseFormat(Map.of("type", "text"));
config.setOutputConfig(Map.of(
    "output", Map.of("type", "string", "description", "输出结果", "required", true)
));
config.setEnableHistory(false);

LLMComponent llmComponent = new LLMComponent(config);
```

创建大模型组件对象后，通过`Workflow`的`addWorkflowComp`方法将其添加到工作流中：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;

Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), Map.of("query", "${query}"), null);
flow.addWorkflowComp("llm", llmComponent, Map.of("query", "${start.query}"), null);
flow.setEndComp("end", new End(), Map.of("output", "${llm.output}"), null);
flow.addConnection("start", "llm");
flow.addConnection("llm", "end");
```

执行工作流：

```java
WorkflowSessionApi session = WorkflowSessions.createWorkflowSession();
WorkflowOutput output = flow.invoke(Map.of("query", "生成一句关于月亮的诗句"), session, null);
System.out.println(output.getResult());
```

输出结果示例：

```java
{'output': '月走随人远，风来带桂香'}
```

如果定义了json的输出格式：

```java
config.setResponseFormat(Map.of("type", "json"));
```

输入请求`query="提取《我爱北京天安门》歌名中的地点信息"`，输出结果：

```java
{'output': '北京'}
```

# 插件组件

插件组件可调用工具（包括外部API、本地函数），通过向工具输入参数、执行工具逻辑、最终输出工具的执行结果。

使用Java的`Tool`体系创建插件：

```java
import com.openjiuwen.core.foundation.tool.Tool;
import com.openjiuwen.core.foundation.tool.ToolCard;
import com.openjiuwen.core.workflow.component.tool.ToolComponent;
import com.openjiuwen.core.workflow.component.tool.ToolComponentConfig;

ToolCard weatherCard = ToolCard.builder()
    .name("WeatherReporter")
    .description("天气查询插件")
    .inputParams(Map.of(
        "type", "object",
        "properties", Map.of(
            "location", Map.of("type", "string", "description", "天气查询的地点"),
            "date", Map.of("type", "string", "description", "天气查询的时间，格式为YYYY-MM-DD")
        ),
        "required", List.of("location", "date")
    ))
    .build();

Tool weatherTool = new Tool(weatherCard);

ToolComponentConfig toolConfig = new ToolComponentConfig();
ToolComponent toolComponent = new ToolComponent(toolConfig);
toolComponent.bindTool(weatherTool);
```

将插件组件添加到工作流：

```java
Workflow flow = new Workflow();
flow.setStartComp("start", new Start(), 
    Map.of("location", "${location}", "date", "${date}"), null);
flow.addWorkflowComp("tool", toolComponent, 
    Map.of("location", "${start.location}", "date", "${start.date}"), null);
flow.setEndComp("end", new End(), Map.of("data", "${tool.data}"), null);
flow.addConnection("start", "tool");
flow.addConnection("tool", "end");
```

插件组件的输出定义包括执行错误码`errorCode`、错误信息`errorMessage`以及执行成功时的数据`data`。

若插件执行成功：

```java
{
    "errorCode": 0,
    "errorMessage": "",
    "data": "{'city': 'Shanghai', 'temperature': 29.21, 'weather': '多云'}"
}
```

若插件执行失败：

```java
{
    "errorCode": 10000,
    "errorMessage": "plugin service unavailable",
    "data": ""
}
```

# 意图识别组件

意图识别组件基于大语言模型服务对用户输入进行精准的意图识别与分类，并根据用户设置的下游分支路由规则，自动将任务流转至对应的工作流组件进行处理。

创建意图组件的配置对象`IntentDetectionCompConfig`：

```java
import com.openjiuwen.core.workflow.component.llm.IntentDetectionCompConfig;
import com.openjiuwen.core.workflow.component.llm.IntentDetectionComponentImpl;

IntentDetectionCompConfig config = new IntentDetectionCompConfig();
config.setModelClientConfig(clientConfig);
config.setModelConfig(requestConfig);
config.setUserPrompt("请判断用户意图");
config.setCategoryNameList(List.of("查询某地天气"));
config.setExampleContent(List.of("示例1：今天下雨吗？这是查询天气的意图"));
config.setEnableHistory(false);

IntentDetectionComponentImpl intentComponent = new IntentDetectionComponentImpl(config);
intentComponent.addBranch("${intent.classificationId} == 1", List.of("llm"), "查询天气分支");
intentComponent.addBranch("${intent.classificationId} == 0", List.of("end"), "默认分支");
```

将意图识别组件添加到工作流：

```java
Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), Map.of("query", "${query}"), null);
workflow.addWorkflowComp("intent", intentComponent, Map.of("query", "${start.query}"), null);
workflow.addWorkflowComp("llm", llmComponent, Map.of("query", "${start.query}"), null);
workflow.setEndComp("end", new End(), Map.of("response", "${llm.output}"), null);

// 条件连接
workflow.addConnection("start", "intent");
workflow.addConditionalConnection("intent", new BranchRouter());
workflow.addConnection("llm", "end");
```

意图识别组件的输出包含`classificationId`和`reason`：

```java
{
    "classificationId": 1,
    "reason": "用户问上海的天气怎么样，识别为查询天气的请求",
    "categoryName": "查询某地天气"
}
```

# 提问器组件

提问器组件支持配置预设问题、并基于预设问题主动向用户提问并收集反馈。同时，支持配置参数提取开关，一旦开启，系统将结合用户反馈和可选的对话历史，提取指定参数。

创建提问器组件的配置对象`QuestionerConfig`：

```java
import com.openjiuwen.core.workflow.component.llm.FieldInfo;
import com.openjiuwen.core.workflow.component.llm.QuestionerConfig;
import com.openjiuwen.core.workflow.component.llm.QuestionerComponent;

List<FieldInfo> keyFields = List.of(
    FieldInfo.builder()
        .fieldName("location")
        .description("地点")
        .required(true)
        .build(),
    FieldInfo.builder()
        .fieldName("date")
        .description("时间")
        .required(true)
        .defaultValue("today")
        .build()
);

QuestionerConfig config = new QuestionerConfig();
config.setModelClientConfig(clientConfig);
config.setModelConfig(requestConfig);
config.setQuestionContent("");
config.setExtractFieldsFromResponse(true);
config.setFieldNames(keyFields);
config.setWithChatHistory(false);
config.setMaxResponse(10);

QuestionerComponent questionerComponent = new QuestionerComponent(config);
```

将提问器组件添加到工作流：

```java
Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), Map.of("query", "${query}"), null);
workflow.addWorkflowComp("questioner", questionerComponent, Map.of("query", "${start.query}"), null);
workflow.setEndComp("end", new End(), 
    Map.of("responseTemplate", "地点:{{location}}, 时间:{{date}}"),
    Map.of("location", "${questioner.location}", "date", "${questioner.date}"), null);
workflow.addConnection("start", "questioner");
workflow.addConnection("questioner", "end");
```

执行工作流并处理`INPUT_REQUIRED`状态：

```java
import com.openjiuwen.core.workflow.WorkflowExecutionState;
import com.openjiuwen.core.session.interaction.InteractiveInput;

String sessionId = "test_questioner";
WorkflowSessionApi session = WorkflowSessions.createWorkflowSession(sessionId);
WorkflowOutput output = workflow.invoke(Map.of("query", "时间是2025年8月1日"), session, null);

if (WorkflowExecutionState.INPUT_REQUIRED.equals(output.getState())) {
    InteractiveInput reply = new InteractiveInput();
    reply.update("questioner", "地点是杭州");
    output = workflow.invoke(reply, session, null);
}

System.out.println(output.getResult());
```

提问器组件输出：

```java
{
    "question": "请您提供地点相关的信息",
    "userResponse": "地点是杭州",
    "location": "杭州",
    "date": "2025-08-01"
}
```

# 分支组件

分支组件用于根据当前数据状态来决定后续应走的流程分支。通过分支组件，工作流可被拆分为多个并行的分支路径。

创建分支组件实例：

```java
import com.openjiuwen.core.workflow.component.BranchComponent;
import com.openjiuwen.core.workflow.component.BranchRouter;

BranchComponent branchComp = new BranchComponent();

// 字符串表达式条件
branchComp.addBranch("${start.query} > 0", List.of("end"), "pos_branch");

// 条件对象
ExpressionCondition condition = new ExpressionCondition("${start.query} < 0");
branchComp.addBranch(condition, List.of("abs"), "neg_branch");

// Callable函数
branchComp.addBranch(() -> System.getenv("ALLOW_ZERO").equals("true"), List.of("abs"), "zero_branch");
```

将分支组件添加到工作流：

```java
Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), Map.of("query", "${userInputs.query}"), null);
workflow.addWorkflowComp("branch", branchComp);
workflow.setEndComp("end", new End(), Map.of("result", "${start.query}"), null);
workflow.addWorkflowComp("abs", absComponent, Map.of("num", "${start.query}"), null);

workflow.addConnection("start", "branch");
workflow.addConnection("abs", "end");
```

# 循环组件

循环组件通过`LoopGroup`定义循环体，支持四种循环场景：

| 场景类型 | loopType值 | 描述 |
| --- | --- | --- |
| 数组循环 | `array` | 遍历数组，以每个元素作为输入 |
| 指定次数循环 | `number` | 指定固定的循环次数 |
| 无限循环 | `always_true` | 实现无限循环，依赖break组件中止 |
| 表达式循环 | `expression` | 通过表达式控制循环条件 |

创建循环体：

```java
import com.openjiuwen.core.workflow.component.loop.LoopGroup;
import com.openjiuwen.core.workflow.component.loop.LoopComponentImpl;

LoopGroup loopGroup = new LoopGroup();
loopGroup.addWorkflowComp("node1", node1Component, Map.of("value", "${loop.item}"), null);
loopGroup.addWorkflowComp("node2", node2Component, Map.of("value", "${node1.output}"), null);
loopGroup.startComp("node1");
loopGroup.endComp("node2");
loopGroup.addConnection("node1", "node2");

LoopComponentImpl loopComponent = new LoopComponentImpl(loopGroup, Map.of("answers", "${sub.answer}"));
```

将循环组件添加到工作流：

```java
Workflow workflow = new Workflow();
workflow.setStartComp("start", new Start(), Map.of("items", "${items}"), null);
workflow.addWorkflowComp("loop", loopComponent, 
    Map.of("loopType", "array", "loopArray", "${start.items}"), null);
workflow.setEndComp("end", new End(), Map.of("results", "${loop.answers}"), null);
workflow.addConnection("start", "loop");
workflow.addConnection("loop", "end");
```

循环体内可通过`${loop.index}`访问当前循环索引，通过`${loop.item}`访问当前元素。
