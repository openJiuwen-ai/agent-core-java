# 外部工具

外部工具用于描述一种由 Agent 调用者执行、再把结果交回 Agent 的工具能力。它面向的典型场景是：模型需要调用浏览器、客户端、业务网关或其他不适合由 SDK 进程直接访问的能力，但仍希望模型视角中的工具调用链路与普通工具完全一致。

在 ReActAgent 中，外部工具对模型表现为标准 function calling 工具；区别只在执行阶段：Agent 不会本地调用该工具，而是进入 `external_tool_call_required` 状态，等待调用者一次性返回本轮所有外部工具结果。

## 功能定位

外部工具适合放在 Agent 运行边界之外执行。

常见例子包括：

- 浏览器前端读取页面输入框、当前选区或用户本地状态；
- App 客户端调用设备能力或用户授权后的本地接口；
- 业务服务在 SDK 进程之外完成审计、授权或隔离执行；
- HTTP 层沿用 OpenAI-compatible `tools` / `tool_calls` / `role=tool` 协议，再适配到 SDK 的 ReActAgent。

如果工具可以直接由 Java 进程执行，优先使用 [自定义工具](自定义工具.md) 中的 `LocalFunction`、`RestfulApi` 或 `McpTool`。

## 核心类型

| 类型 | 作用 |
| --- | --- |
| `ExternalTool` | 外部工具能力描述，包装 `ToolCard`，只负责把工具 schema 暴露给模型。 |
| `ExternalToolCallRequest` | Agent 挂起时返回给调用者的外部工具调用请求。 |
| `ExternalToolResult` | 调用者恢复会话时提交的外部工具结果。 |
| `ExternalToolPendingState` | ReActAgent 保存到 session 中的外部工具挂起状态。 |

`ExternalTool` 不是 `Tool` 子类，也没有本地 `invoke(...)` 能力。它的核心职责是让 `AbilityManager.listToolInfo(...)` 能把外部工具和普通工具一起暴露给模型。

## 注册外部工具

外部工具仍然使用 `ToolCard` 描述名字、描述和输入 Schema，再用 `ExternalTool` 包装后注册到 ReActAgent 的 `AbilityManager`。

```java
import com.openjiuwen.core.foundation.tool.ExternalTool;
import com.openjiuwen.core.foundation.tool.ToolCard;
import com.openjiuwen.core.singleagent.agents.ReActAgent;
import com.openjiuwen.core.singleagent.schema.AgentCard;

import java.util.List;
import java.util.Map;

ReActAgent agent = new ReActAgent(
        new AgentCard("browser-agent", "Browser Agent", "可以请求浏览器执行外部工具的 Agent")
);

ExternalTool readTextInput = new ExternalTool(ToolCard.builder()
        .id("external.frontend_read_text_input")
        .name("frontend_read_text_input")
        .description("读取浏览器页面中指定输入框的文本")
        .inputParams(Map.of(
                "type", "object",
                "properties", Map.of(
                        "field_id", Map.of(
                                "type", "string",
                                "enum", List.of("demo_external_text"),
                                "description", "允许读取的前端输入框 ID"
                        )
                ),
                "required", List.of("field_id")
        ))
        .build());

agent.getAbilityManager().add(readTextInput);
```

注册后，模型看到的 `frontend_read_text_input` 与普通工具没有区别。ReActAgent 只在模型真的返回这个工具调用时识别它是外部工具。

外部工具名不能与普通工具、MCP 工具、workflow、agent-as-tool 或已有外部工具重名。若存在重名，`AbilityManager.add(...)` 会失败，避免模型工具列表中出现无法解释的冲突。

## 首轮调用与挂起结果

当模型在某一轮返回的 `tool_calls` 中包含任意外部工具时，ReActAgent 会挂起整轮工具处理：

- 不执行该外部工具；
- 不执行同一轮中的普通工具；
- 保存 pending 状态到当前 `AgentSessionApi`；
- 返回 `result_type=external_tool_call_required`；
- `external_tool_calls` 只包含需要调用者执行的外部工具，不包含同轮普通工具。

```java
import com.openjiuwen.core.session.AgentSession;
import com.openjiuwen.core.session.AgentSessionApi;

AgentSessionApi session = new AgentSession("external-tool-session", null, agent.getCard());

Object firstResult = agent.invoke(
        Map.of("query", "请读取页面输入框里的文本，然后继续回答"),
        session
).toCompletableFuture().join();
```

典型返回结构如下：

```json
{
  "result_type": "external_tool_call_required",
  "external_tool_calls": [
    {
      "tool_call_id": "call_001",
      "tool_name": "frontend_read_text_input",
      "arguments": "{\"field_id\":\"demo_external_text\"}"
    }
  ]
}
```

此时调用者需要根据 `tool_name`、`tool_call_id` 和 `arguments` 执行真实外部工具，并记录原始 `tool_call_id`。恢复会话时必须使用同一个 session。

## 恢复会话

恢复时，调用者通过 `external_tool_results` 一次性提交本轮所有 pending 外部工具结果。

```java
Object resumedResult = agent.invoke(
        Map.of(
                "external_tool_results", List.of(Map.of(
                        "tool_call_id", "call_001",
                        "result", Map.of(
                                "field_id", "demo_external_text",
                                "text", "浏览器输入框文本",
                                "source", "browser"
                        )
                ))
        ),
        session
).toCompletableFuture().join();
```

恢复输入不需要 `query`。如果调用者为了兼容旧入口传入了 `query`，ReActAgent 也不会把它追加成新的 `UserMessage`；恢复的语义是补齐上一轮模型已经发出的工具调用，而不是开始新的用户轮次。

如果外部工具执行失败，可以提交 `error`：

```java
Object resumedResult = agent.invoke(
        Map.of(
                "external_tool_results", List.of(Map.of(
                        "tool_call_id", "call_001",
                        "error", "浏览器输入框不存在"
                ))
        ),
        session
).toCompletableFuture().join();
```

恢复成功后，ReActAgent 会按原始工具调用顺序写入标准 `ToolMessage`。如果同一轮中还有普通工具，这些普通工具会在外部工具结果写入后继续执行，并与外部工具结果一起进入下一轮模型调用。

## 一次性返回规则

`external_tool_results` 必须与 pending 状态中的外部工具调用完全匹配。

必须满足：

- 每个元素都有非空 `tool_call_id`；
- 每个元素至少包含 `result` 或 `error`；
- 必须覆盖本轮所有 pending 外部工具调用；
- 不能缺少、重复或额外提交未知 `tool_call_id`；
- 同一轮多个外部工具调用需要一次性全部返回，当前不支持分批恢复。

如果校验失败，ReActAgent 会返回错误结果，并保留 pending 状态。调用者需要修正 `external_tool_results` 后再次恢复；在 pending 状态未清除前，新的普通用户 `query` 不会被当作新问题继续执行。

## 流式输出

流式路径中，外部工具不会改变工具生命周期事件的含义。

首次挂起时，事件顺序通常是：

```text
llm_output / llm_reasoning
tool_call(call_001)
external_tool_call_required
```

恢复成功后，事件顺序通常是：

```text
tool_result(call_001)
llm_output / llm_reasoning
answer
```

如果同一轮里同时包含外部工具和普通工具，挂起前只会输出 `tool_call`，不会提前输出任何 `tool_result`。恢复后再按原始工具调用顺序输出所有工具结果。

## 流式调用示例

SDK 原生流式入口使用 `agent.stream(...)`。调用者需要把首轮流消费到结束，拿到 `external_tool_call_required` 后再执行外部工具，并用同一个 session 发起恢复流。

```java
import com.openjiuwen.core.session.stream.OutputSchema;

import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;
import java.util.Map;

Iterator<Object> firstStream = agent.stream(
        Map.of("query", "请读取页面输入框里的文本，然后继续回答"),
        session,
        List.of()
);

List<OutputSchema> firstOutputs = new ArrayList<>();
while (firstStream.hasNext()) {
    Object item = firstStream.next();
    if (item instanceof OutputSchema output) {
        firstOutputs.add(output);
        // 这里可以按需把 llm_output、tool_call 等事件转发给前端。
    }
}

OutputSchema pendingOutput = firstOutputs.stream()
        .filter(output -> "external_tool_call_required".equals(output.getType()))
        .findFirst()
        .orElseThrow();

@SuppressWarnings("unchecked")
Map<String, Object> pendingPayload = (Map<String, Object>) pendingOutput.getPayload();

@SuppressWarnings("unchecked")
List<Map<String, Object>> calls =
        (List<Map<String, Object>>) pendingPayload.get("external_tool_calls");
```

`external_tool_calls` 中的每个元素都包含：

- `tool_call_id`：恢复时必须原样带回；
- `tool_name`：调用者用于路由到真实外部能力；
- `arguments`：模型生成的工具入参，通常是 JSON 字符串。

外部工具执行完成后，需要一次性提交本轮所有外部工具结果，再消费恢复流：

```java
List<Map<String, Object>> externalResults = calls.stream()
        .map(call -> Map.of(
                "tool_call_id", call.get("tool_call_id"),
                "result", Map.of(
                        "text", "浏览器输入框文本",
                        "source", "browser"
                )
        ))
        .toList();

Iterator<Object> resumeStream = agent.stream(
        Map.of("external_tool_results", externalResults),
        session,
        List.of()
);

while (resumeStream.hasNext()) {
    Object item = resumeStream.next();
    if (item instanceof OutputSchema output) {
        // 恢复流中会继续输出 tool_result、llm_output / llm_reasoning、answer 等事件。
    }
}
```

流式接入时需要注意：

- `external_tool_call_required` 是挂起状态，不是最终答案；
- 首轮流需要自然消费结束后再开始恢复，避免在 session 收尾尚未完成时发起下一次调用；
- 恢复输入不需要 `query`，只需要 `external_tool_results`；
- `external_tool_results` 必须一次性覆盖本轮所有 pending 外部工具调用；
- 同轮如果还有普通工具，它们会在恢复后继续执行，并在恢复流中输出对应 `tool_result`。

## 与普通工具的关系

外部工具与普通工具共享模型可见的 `ToolInfo` 形态，但运行语义不同。

| 对比项 | 普通工具 | 外部工具 |
| --- | --- | --- |
| 模型可见形态 | `ToolInfo` | `ToolInfo` |
| SDK 是否本地执行 | 是 | 否 |
| 结果写回方式 | SDK 执行后写入 `ToolMessage` | 调用者提交结果后写入 `ToolMessage` |
| 同轮混用 | 立即按顺序执行 | 只要同轮存在外部工具，整轮先挂起 |
| 恢复输入 | 不需要 | 需要 `external_tool_results` |

这个规则牺牲了一点同轮并行便利性，换取更清晰的副作用边界：在外部工具结果返回前，同轮普通工具不会提前发生副作用。

## OpenAI-compatible HTTP 适配

SDK 原生入口使用 `ExternalTool` 和 `external_tool_results`。如果你的 HTTP 层需要兼容 OpenAI Chat Completions，可以像 Demo 工程一样做协议适配：

1. 首轮请求中的 OpenAI-compatible `tools` 被服务端转换为 SDK `ExternalTool`。
2. SDK 返回 `external_tool_call_required` 后，HTTP 层转换成 streamed assistant `delta.tool_calls`，并以 `finish_reason=tool_calls` 结束首轮响应。
3. 调用者执行工具后，用同一个 `conversation_id` 发送 `role=tool` 消息。
4. HTTP 层把 `role=tool` 消息转换为 SDK `external_tool_results`，再调用同一个 ReActAgent session 恢复。

下面是一个流式适配的核心代码示例。

前端首轮请求沿用 OpenAI-compatible `tools` 字段声明浏览器可执行工具：

```javascript
const payload = {
  model: "gpt-5.4",
  stream: true,
  conversation_id: conversationId,
  messages: [
    {
      role: "user",
      content: "请调用 frontend_read_text_input 读取 demo_external_text 输入框文本，然后复述读取到的结果。"
    }
  ],
  tools: [
    {
      type: "function",
      function: {
        name: "frontend_read_text_input",
        description: "Read the browser text input with id demo_external_text.",
        parameters: {
          type: "object",
          properties: {
            field_id: {
              type: "string",
              enum: ["demo_external_text"]
            }
          },
          required: ["field_id"]
        }
      }
    }
  ]
};

await streamChatPayload(payload);
```

HTTP 层收到请求后，把 `tools` 转成 SDK `ExternalTool`，再消费 `agent.stream(...)`。当 SDK 输出 `external_tool_call_required` 时，HTTP 层把它转换为 OpenAI-compatible 的 `delta.tool_calls` 和 `finish_reason=tool_calls`，最后等 SDK 流结束后发送 `[DONE]`。

```java
SseEmitter chatCompletions(ChatCompletionRequest request) {
    String conversationId = request.getConversationId();
    ChatCompletionAgentRequest agentRequest = mapper.map(request, conversationId);
    SseEmitter emitter = new SseEmitter(0L);

    Thread.ofVirtual().start(() -> {
        try {
            ReActAgent agent = scenario.agent();
            synchronized (agent) {
                List<ExternalTool> activeExternalTools = prepareRequestExternalTools(agent, agentRequest);
                AgentSessionApi session = new AgentSession(conversationId, null, agent.getCard());
                Iterator<Object> stream = agent.stream(resolveAgentInputs(agentRequest), session, List.of());

                writeOpenAiStream(emitter, stream, agentRequest, activeExternalTools);
                emitter.complete();
            }
        } catch (Exception ex) {
            emitter.completeWithError(ex);
        }
    });

    return emitter;
}

private Object resolveAgentInputs(ChatCompletionAgentRequest agentRequest) {
    if (agentRequest.isExternalToolResumeRequest()) {
        Map<String, Object> inputs = new LinkedHashMap<>();
        inputs.put("conversation_id", agentRequest.getConversationId());
        inputs.put("external_tool_results", agentRequest.getExternalToolResults());
        return inputs;
    }

    return Map.of(
            "query", agentRequest.toAgentContextQuery(),
            "conversation_id", agentRequest.getConversationId()
    );
}
```

`writeOpenAiStream(...)` 的关键逻辑如下：

```java
private void writeOpenAiStream(SseEmitter emitter,
                               Iterator<Object> stream,
                               ChatCompletionAgentRequest agentRequest,
                               List<ExternalTool> activeExternalTools) throws IOException {
    while (stream.hasNext()) {
        Object item = stream.next();
        if (!(item instanceof OutputSchema output)) {
            continue;
        }

        if (isExternalToolPendingOutput(output)) {
            rememberPendingExternalTools(agentRequest, activeExternalTools);

            List<Map<String, Object>> toolCalls = toOpenAiToolCalls(output.getPayload());
            sendFrame(emitter, toolCallDeltaChunk(agentRequest.getModel(), toolCalls));
            sendFrame(emitter, toolCallsFinishedChunk(agentRequest.getModel()));
            continue;
        }

        if ("llm_output".equals(output.getType())) {
            sendFrame(emitter, contentChunk(agentRequest.getModel(), output.getPayload()));
            continue;
        }

        if ("answer".equals(output.getType())) {
            sendFrame(emitter, terminalSuccessChunk(agentRequest.getModel()));
        }
    }

    sendFrame(emitter, done());
}

private List<Map<String, Object>> toOpenAiToolCalls(Object payload) {
    Map<?, ?> payloadMap = (Map<?, ?>) payload;
    List<?> externalCalls = (List<?>) payloadMap.get("external_tool_calls");
    List<Map<String, Object>> toolCalls = new ArrayList<>();

    for (Object externalCall : externalCalls) {
        Map<?, ?> call = (Map<?, ?>) externalCall;
        Map<String, Object> function = new LinkedHashMap<>();
        function.put("name", call.get("tool_name"));
        function.put("arguments", String.valueOf(call.get("arguments")));

        Map<String, Object> toolCall = new LinkedHashMap<>();
        toolCall.put("index", toolCalls.size());
        toolCall.put("id", call.get("tool_call_id"));
        toolCall.put("type", "function");
        toolCall.put("function", function);
        toolCalls.add(toolCall);
    }

    return toolCalls;
}
```

转换后的 SSE 事件形态类似：

```text
data: {"choices":[{"delta":{"tool_calls":[{"index":0,"id":"call_001","type":"function","function":{"name":"frontend_read_text_input","arguments":"{\"field_id\":\"demo_external_text\"}"}}]},"finish_reason":null}]}

data: {"choices":[{"delta":{},"finish_reason":"tool_calls"}]}

data: [DONE]
```

前端收到 `finish_reason=tool_calls` 后只记录待执行工具；收到 `[DONE]` 后再真正执行浏览器工具并发起恢复请求：

```javascript
async function consumeSseFrame(frame) {
  const data = readData(frame);
  if (data === "[DONE]") {
    if (pendingExternalToolCallsReady) {
      const toolCalls = pendingExternalToolCalls.splice(0);
      pendingExternalToolCallsReady = false;
      return await executePendingExternalToolCalls(toolCalls);
    }
    return;
  }

  const payload = JSON.parse(data);
  const choice = payload.choices?.[0] || {};
  const delta = choice.delta || {};

  if (Array.isArray(delta.tool_calls)) {
    captureDeltaToolCalls(delta.tool_calls);
  }

  if (choice.finish_reason === "tool_calls") {
    pendingExternalToolCallsReady = true;
    return;
  }
}

async function executePendingExternalToolCalls(toolCalls) {
  const toolResults = toolCalls.map((toolCall) => {
    const args = JSON.parse(toolCall.function.arguments || "{}");
    const text = document.getElementById(args.field_id).value;

    return {
      role: "tool",
      tool_call_id: toolCall.id,
      content: JSON.stringify({
        field_id: args.field_id,
        text,
        source: "browser"
      })
    };
  });

  return await streamChatPayload({
    model: "gpt-5.4",
    stream: true,
    conversation_id: conversationId,
    messages: toolResults
  });
}
```

恢复请求进入 HTTP 层后，不再读取 `query`，而是把尾部连续的 `role=tool` 消息转换为 SDK 的 `external_tool_results`：

```java
private List<Map<String, Object>> toExternalToolResults(List<ChatCompletionMessage> messages) {
    List<Map<String, Object>> results = new ArrayList<>();
    for (ChatCompletionMessage message : messages) {
        Map<String, Object> result = new LinkedHashMap<>();
        result.put("tool_call_id", message.getToolCallId());
        result.put("result", parseJsonOrText(message.getContent()));
        results.add(result);
    }
    return results;
}
```
