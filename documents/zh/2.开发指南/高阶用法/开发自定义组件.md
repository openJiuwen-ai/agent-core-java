openJiuwen提供了灵活而强大的组件开发能力。用户只需继承`WorkflowComponent`抽象类并实现其中的方法，即可快速构建自定义组件。自定义组件一般包含以下功能：

- 处理组件的输入数据，生成组件的输出数据，支持流数据和批数据的处理。
- 为组件定制配套分支的场景。
- 使用`Session`提供的能力，包括获取配置信息、更新或获取状态信息、记录trace信息、管理资源、交互中断能力，参考[Session](./Session/概述.md)。

# 实现自定义组件

openJiuwen支持两种实现自定义组件的方式：

- 同时继承`WorkflowComponent`和`ComponentExecutable`：直接在类中实现`ComponentExecutable`的方法，并在组件的`toExecutable`方法中返回`this`。适用于组件功能简单的场景，定义的组件本身就是运行态的实例。
- 继承`WorkflowComponent`：单独编写一个类继承`ComponentExecutable`，并在组件的`toExecutable`方法中返回该实例。适用于组件功能相对复杂，构造逻辑和运行逻辑分离的场景。

其中`ComponentExecutable`为执行器的抽象类，主要提供了`invoke`、`stream`、`collect`和`transform`业务处理接口，用户可根据业务需求实现不同的接口。若组件本身涉及到自定义连接配置（例如：意图识别组件、分支组件），需要实现`addComponent`方法将自定义组件的运行态`toExecutable`和必要的连接关系添加到`Graph`图执行引擎。

以下为通过两种方式实现自定义组件的具体示例，分别是计算节点组件`ComputeComponent`和二进制响应反序列化组件`ResponseHandlerComponent`。

## 同时继承WorkflowComponent和ComponentExecutable

`ResponseHandlerComponent`是用于响应反序列化的自定义组件，同时继承`WorkflowComponent`和`ComponentExecutable`。这种继承实现的方式下，`toExecutable`和`addComponent`的默认实现是为将组件自身作为`ComponentExecutable`类型的实例并添加到工作流的图执行引擎中。

`ResponseHandlerComponent`实现流式响应的内容进行逐帧反序列化，通过`transform`方法将反序列化的结果逐帧返回，通过`collect`方法对反序列化完的结果收集后批量返回。

```java
import com.fasterxml.jackson.databind.ObjectMapper;
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.HashMap;
import java.util.Iterator;
import java.util.Map;

public class ResponseHandlerComponent extends WorkflowComponent {

    private static final ObjectMapper MAPPER = new ObjectMapper();

    @Override
    public Iterator<Map<String, Object>> transform(Object inputs, NodeSessionApi session, ModelContext context) {
        // 处理流式输入，遍历所有输入，每次获取response内容，调用deserialize方法进行反序列化
        Iterator<?> responseIterator = (Iterator<?>) ((Map<?, ?>) inputs).get("response");
        return new Iterator<Map<String, Object>>() {
            @Override
            public boolean hasNext() {
                return responseIterator.hasNext();
            }

            @Override
            public Map<String, Object> next() {
                Object response = responseIterator.next();
                if (response != null) {
                    Map<?, ?> responseMap = (Map<?, ?>) response;
                    Object content = responseMap.get("content");
                    return Map.of("content", deserialize(content));
                }
                return Map.of("status", "finished");
            }
        };
    }

    @Override
    public Map<String, Object> collect(Object inputs, NodeSessionApi session, ModelContext context) {
        // 收集所有解析好的response消息，并批量返回
        java.util.List<Object> responses = new java.util.ArrayList<>();
        Iterator<?> responseIterator = (Iterator<?>) ((Map<?, ?>) inputs).get("response");

        while (responseIterator.hasNext()) {
            Object response = responseIterator.next();
            if (response != null) {
                Map<?, ?> responseMap = (Map<?, ?>) response;
                responses.add(deserialize(responseMap.get("content")));
            }
        }
        return Map.of("result", responses);
    }

    private Map<String, Object> deserialize(Object contentBytes) {
        if (contentBytes == null) {
            return new HashMap<>();
        }
        try {
            return MAPPER.readValue(contentBytes.toString(), Map.class);
        } catch (Exception e) {
            return new HashMap<>();
        }
    }
}
```

- 当工作流调用到`transform`接口，输出结果为多帧数据。

通过`workflow.addWorkflowComp`方法将自定义的`ResponseHandlerComponent`组件添加到工作流中，设置组件id为"handler"，并指定流输入的schema为`"${llm.response}"`：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.ComponentAbility;

Workflow workflow = new Workflow();
workflow.addWorkflowComp(
        "response_handler",
        new ResponseHandlerComponent(),
        null,  // inputs_schema
        null,  // outputs_schema
        true,  // wait_for_all (required for TRANSFORM)
        null,  // stream_inputs_schema
        null,  // stream_outputs_schema  
        java.util.List.of(ComponentAbility.TRANSFORM)
);
```

调用`workflow.stream(...)`方法执行工作流。工作流执行结果包含多帧输出。

- 当工作流调用到`collect`接口，输出结果为批数据。
通过`workflow.addWorkflowComp`方法将自定义的`ResponseHandlerComponent`组件添加到工作流中，设置组件id为"handler"，并指定组件的能力为`COLLECT`：

```java
workflow.addWorkflowComp(
        "response_handler",
        new ResponseHandlerComponent(),
        null,
        null,
        true,  // wait_for_all (required for COLLECT)
        null,
        null,
        java.util.List.of(ComponentAbility.COLLECT)
);
```

调用`workflow.invoke(...)`方法执行工作流。输出结果为批量数据。

```java
public class ResponseHandlerExample {

    private static final ObjectMapper MAPPER = new ObjectMapper();

    // Mock LLM组件，并流出多帧数据
    public static class MockLLMComponent extends WorkflowComponent {
        private final List<byte[]> mockLLMStreams = Arrays.asList(
                MAPPER.writeValueAsBytes(Map.of("url", "http://xxxxx", "description", "小女孩在公园")),
                MAPPER.writeValueAsBytes(Map.of("url", "http://xxxxx", "description", "上学的小女孩")),

                @Override

                @Override
                public Map<String, Object> next() {
                    return Map.of("response", Map.of("content", mockLLMStreams.get(index++)));
                }
            };
        }
    }

    // ResponseHandler组件
    public static class ResponseHandlerComponent extends WorkflowComponent {
        @Override
        public Iterator<Map<String, Object>> transform(Object inputs, NodeSessionApi session, ModelContext context) {
            Iterator<?> responseIterator = (Iterator<?>) ((Map<?, ?>) inputs).get("response");
            return new Iterator<Map<String, Object>>() {
                @Override
                public boolean hasNext() {
                    return responseIterator.hasNext();
                }

                @Override
                public Map<String, Object> next() {
                    Object response = responseIterator.next();
                    if (response != null) {
                        Map<?, ?> responseMap = (Map<?, ?>) response;
                        return Map.of("content", deserialize(responseMap.get("content")));
                    }
                    return Map.of("status", "finished");
                }
            };
        }

        @Override
        public Map<String, Object> collect(Object inputs, NodeSessionApi session, ModelContext context) {
            List<Object> responses = new ArrayList<>();
            Iterator<?> responseIterator = (Iterator<?>) ((Map<?, ?>) inputs).get("response");
            while (responseIterator.hasNext()) {
                Object response = responseIterator.next();
                if (response != null) {
                    Map<?, ?> responseMap = (Map<?, ?>) response;
                    responses.add(deserialize(responseMap.get("content")));
                }
            }
            return Map.of("result", responses);
        }

        private Map<String, Object> deserialize(Object contentBytes) {
            if (contentBytes == null) return new HashMap<>();
            try {
                return MAPPER.readValue((byte[]) contentBytes, Map.class);
            } catch (Exception e) {
                return new HashMap<>();
            }
        }
    }

    public static void main(String[] args) throws Exception {
        // 构建workflow
        WorkflowCard card = WorkflowCard.builder()
                .id("test_workflow")
                .name("响应处理示例")
                .version("1.0")
                .build();
        Workflow workflow = new Workflow(card);

        workflow.setStartComp("start", new Start(), Map.of("query", "${user_inputs}"), null);
        workflow.addWorkflowComp("llm", new MockLLMComponent(), 
                Map.of("query", "${start.query}"), null,
                true, null, null, List.of(ComponentAbility.STREAM));
        workflow.addWorkflowComp("response_handler", new ResponseHandlerComponent(),
                null, null,
                true, null, null, List.of(ComponentAbility.TRANSFORM));
        workflow.setEndComp("end", new End(Map.of("responseTemplate", "处理完成")),
                null, null);
        
        workflow.addConnection("start", "llm");
        workflow.addConnection("llm", "response_handler");
        workflow.addConnection("response_handler", "end");

        // 执行workflow
        WorkflowSessionApi session = new WorkflowSessionApi(null, "test_session", Map.of());
        Object result = workflow.invoke(Map.of("user_inputs", "帮我生成一张小女孩的图片"), session, null);
        System.out.println(result);
    }
}
```

## 继承WorkflowComponent

`ComputeExecutor`继承自`ComponentExecutable`，支持单次数学运算与多次数学的累加处理，通过`invoke`方法处理单次输入，执行指定类型的数学运算（加、减、乘、除），通过`stream`方法将输入的批量数据，分别进行指定的数学运算，每次的结果作为流式数据传递给下个组件，实现高效的数据处理与汇总。

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.graph.Executable;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.ComponentExecutable;

import java.util.Iterator;
import java.util.Map;

public class ComputeExecutor extends ComponentExecutable {

    @Override
    public Map<String, Object> invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 处理单个输入，调用calculate来执行具体的数学运算，并将结果返回
        Map<?, ?> inputMap = (Map<?, ?>) inputs;
        Map<?, ?> data = (Map<?, ?>) inputMap.get("data");
        return Map.of("result", calculate(data));
    }

    @Override
    public Iterator<Map<String, Object>> stream(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<?, ?> inputMap = (Map<?, ?>) inputs;
        Iterable<?> dataList = (Iterable<?>) inputMap.get("data");
        return new Iterator<Map<String, Object>>() {
            private Iterator<?> iterator = dataList.iterator();

            @Override
            public boolean hasNext() {
                return iterator.hasNext();
            }

            @Override
            public Map<String, Object> next() {
                return Map.of("result", calculate((Map<?, ?>) iterator.next()));
            }
        };
    }

    private double calculate(Map<?, ?> data) {
        // 根据输入指定的参数及运算符，执行具体的加、减、乘、除运算
        String operator = (String) data.get("op");
        Map<?, ?> operands = (Map<?, ?>) data.get("data");
        double a = operands.containsKey("a") ? ((Number) operands.get("a")).doubleValue() : 0;
        double b = operands.containsKey("b") ? ((Number) operands.get("b")).doubleValue() : 0;

        switch (operator) {
            case "add": return a + b;
            case "subtract": return a - b;
            case "multiply": return a * b;
            case "divide": return b != 0 ? a / b : 0;
            default: return 0;
        }
    }
}
```

`ComputeComponent`继承`ComponentComposable`，是用于数学运算的组件，实现`toExecutable`方法提供了实现计算逻辑的`ComputeExecutor`实例，实现`addComponent`方法将`ComputeComponent`节点添加到工作流中。

```java
import com.openjiuwen.core.graph.Graph;
import com.openjiuwen.core.graph.Executable;
import com.openjiuwen.core.workflow.ComponentComposable;

public class ComputeComponent implements ComponentComposable {

    @Override
    public void addComponent(Graph graph, String nodeId, boolean waitForAll) {
        // 将当前组件的ComputeExecutor添加到图中
        graph.addNode(nodeId, toExecutable(), waitForAll);
    }

    @Override
    public Executable<?, ?> toExecutable() {
        // 将当前对象转换为ComputeExecutor实例返回
        return new ComputeExecutor();
    }
}
```

通过`workflow.addWorkflowComp`方法将自定义的`ComputeComponent`组件添加到图中（此时工作流会调用自定义的`ComputeComponent`组件的`addComponent`方法，将组件自己增加到工作流中），设置组件id为`compute`，并指定输入schema为`Map.of("data", "${last_component.result}")`：

```java
import com.openjiuwen.core.workflow.Workflow;

Workflow workflow = new Workflow();
workflow.addWorkflowComp("compute", new ComputeComponent(), 
        Map.of("data", "${start.data}"), null);
```

调用`workflow.invoke`方法执行工作流，首次执行工作流时，工作流内部会先进行`compile`，此时会调用到自定义`ComputeComponent`组件的`toExecutable`方法生成`ComputeExecutor`的实例，后续工作流的执行都会调用`ComputeExecutor`实例的相关接口。

- 若`compute`组件前置节点`start`的输出为`Map.of("data", Map.of("op", "add", "data", Map.of("a", 1, "b", 2)))`，那么工作流会自动调用`ComputeExecutor`的`invoke`接口，输出为`Map.of("result", 3.0)`。
- 若`compute`的组件前置节点`start`的输出为：包含多个运算请求的列表，那么工作流会自动调用到`ComputeExecutor`的`stream`接口，输出结果为多帧数据。

```java
        Map<?, ?> operands = (Map<?, ?>) data.get("data");
        double a = operands.containsKey("a") ? ((Number) operands.get("a")).doubleValue() : 0;

                .version("1.0")

        workflow.setStartComp("start", new Start(),
```

# 定制组件分支

用户在组件的开发中，存在为组件定制配套分支的场景。例如openJiuwen内置意图识别组件`IntentDetectionComponent`，提供了`addBranch`接口，为意图识别的结果定制了相应的分支。

openJiuwen提供了三种为组件定制配套分支的方案：

- **连接BranchComponent**：构建工作流中，在自定义组件后连接分支组件`BranchComponent`，并通过分支组件的`addBranch`接口，将定制分支配置到分支组件中。
- **条件连接**：构建工作流中，在自定义组件后添加条件分支，为条件分支定制配套的`BranchRouter`。
- **组件集成BranchRouter**：将`BranchRouter`集成在自定义组件中，并暴露出`addBranch`接口，例如openJiuwen内置意图识别组件`IntentDetectionComponent`的实现。

首先，开发用于旅游意图识别的组件`CustomComponent`，模拟意图识别筛选过程，意图种类有"出行"和"餐饮"两种，具体实现如下：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;
import java.util.Random;

public class CustomComponent extends WorkflowComponent {
    private final String[] intents = {"餐饮", "出行"};
    private final Random random = new Random();

    @Override
    public Map<String, Object> invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 模拟意图识别筛选过程
        return Map.of("result", intents[random.nextInt(intents.length)]);
    }
}
```

以下以为自定义组件`CustomComponent`的两种意图定制不同的分支为例，介绍三种方案实现的具体方式。

- 若`result == '餐饮'`，分支匹配到用于处理餐饮意图的工作流处理组件"A"中。
- 若`result == '出行'`，分支匹配到用于处理出行意图的工作流处理组件"B"中。

## 连接BranchComponent

在构建工作流时，在自定义组件后连接`BranchComponent`，并定制自定义的分支。工作流的结构如下图所示。

构建工作流代码如下：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.component.BranchComponent;
import com.openjiuwen.core.workflow.component.SubWorkflowComponent;

Workflow workflow = new Workflow();
Workflow workflowA = new Workflow();
Workflow workflowB = new Workflow();

// 增加自定义节点"custom"，用于意图识别
workflow.addWorkflowComp("custom", new CustomComponent(), null, null);
workflow.addWorkflowComp("A", new SubWorkflowComponent(workflowA), null, null);
workflow.addWorkflowComp("B", new SubWorkflowComponent(workflowB), null, null);

// 增加分支节点"branch"，并创建分支
BranchComponent branchComp = new BranchComponent();
branchComp.addBranch("${custom.result} == '出行'", List.of("A"));
branchComp.addBranch("${custom.result} == '餐饮'", List.of("B"));

// 将branch组件加到工作流中
workflow.addWorkflowComp("branch", branchComp, null, null);

// 连接自定义节点和分支节点
workflow.addConnection("custom", "branch");
```

## 条件连接

为自定义节点添加条件边，并提供BranchRouter。实现方案如下：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.BranchRouter;
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.component.SubWorkflowComponent;
import com.openjiuwen.core.workflow.Workflow;

import java.util.Map;
import java.util.Random;

public class CustomComponent extends WorkflowComponent {
    private final String[] intents = {"餐饮", "出行"};
    private final Random random = new Random();

    @Override
    public Map<String, Object> invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 模拟意图识别筛选过程
        return Map.of("result", intents[random.nextInt(intents.length)]);
    }
}

// 构建工作流
Workflow workflow = new Workflow();
Workflow workflowA = new Workflow();
Workflow workflowB = new Workflow();

workflow.addWorkflowComp("custom", new CustomComponent(), null, null);
workflow.addWorkflowComp("A", new SubWorkflowComponent(workflowA), null, null);
workflow.addWorkflowComp("B", new SubWorkflowComponent(workflowB), null, null);

BranchRouter branchRouter = new BranchRouter();

branchRouter.addBranch("${custom.result} == '餐饮'", List.of("B"), "id2");

```

## 组件集成BranchRouter

将`BranchRouter`集成在自定义组件中，并暴露出`addBranch`接口。该方案需要重新实现`addComponent`接口，并将router添加到graph中。

自定义组件重新实现：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.graph.Graph;
import com.openjiuwen.core.graph.Executable;
```

完整示例：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.graph.Graph;
import com.openjiuwen.core.graph.Executable;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.workflow.BranchRouter;
import com.openjiuwen.core.workflow.ComponentExecutable;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.WorkflowComponent;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.SubWorkflowComponent;

import java.util.Map;
import java.util.Random;
import java.util.List;

public class BranchComponentExample {

    public static class CustomComponent extends WorkflowComponent {
        private final String[] intents = {"餐饮", "出行"};
        private final Random random = new Random();
        private final BranchRouter router = new BranchRouter();

        @Override
        public Map<String, Object> invoke(Object inputs, NodeSessionApi session, ModelContext context) {
            return Map.of("result", intents[random.nextInt(intents.length)]);
        }

        @Override
        public Executable<?, ?> toExecutable() {
            return this;
        }

        @Override
        public void addComponent(Graph graph, String nodeId, boolean waitForAll) {
            graph.addNode(nodeId, toExecutable(), waitForAll);
            graph.addConditionalEdges(nodeId, router);
        }

        public void addBranch(String condition, List<String> target, String branchId) {
            router.addBranch(condition, target, branchId);
        }
    }

    public static void main(String[] args) {
        // 示例：为不同意图配置分支并装配到工作流
        WorkflowCard card = WorkflowCard.builder()
                .id("branch_workflow")
                .name("分支示例")
                .version("1.0")
                .build();
        Workflow workflow = new Workflow(card);
        Workflow workflowA = new Workflow();  // 餐饮处理工作流
        Workflow workflowB = new Workflow();  // 出行处理工作流

        CustomComponent custom = new CustomComponent();
        custom.addBranch("${custom.result} == '出行'", List.of("A"), "branch_id1");
        custom.addBranch("${custom.result} == '餐饮'", List.of("B"), "branch_id2");

        workflow.setStartComp("start", new Start(), Map.of("query", "${user_query}"), null);
        workflow.addWorkflowComp("custom", custom, Map.of("query", "${start.query}"), null);
        workflow.addWorkflowComp("A", new SubWorkflowComponent(workflowA), null, null);
        workflow.addWorkflowComp("B", new SubWorkflowComponent(workflowB), null, null);
        workflow.setEndComp("end", new End(Map.of("responseTemplate", "处理完成")), null, null);

        workflow.addConnection("start", "custom");
        workflow.addConnection("A", "end");
        workflow.addConnection("B", "end");

        WorkflowSessionApi session = new WorkflowSessionApi(null, "branch_session", Map.of());
        Object result = workflow.invoke(Map.of("user_query", "帮我规划行程"), session, null);
        System.out.println(result);
    }
}
```
