# 状态管理

对话执行过程中通过`Session`统一访问状态数据，支持跨组件共享机制，有效降低属性传递的复杂度。所有状态数据集中存储于`Session`，可通过标准化接口进行读写操作，主要分为两类：

- **全局状态数据**：所有的组件都可读取和更新的数据，如会话历史数据，可通过调用`getGlobalState`方法获取全局状态数据，`updateGlobalState`方法更新全局状态数据。
- **组件状态数据**：工作流组件自己的状态数据，如组件的执行次数、计算中间数据，可调用`getState`方法获取组件状态数据，`updateState`方法更新组件状态数据。该数据只有当前组件可见，其他组件获取不到。

组件开发的过程中，根据需求选择将新增的状态数据记录到全局状态中或组件状态中，推荐根据状态的可见性来选择，若状态仅需在本组件可见，首选将状态数据记录到组件状态。

## 全局状态数据

全局状态是所有组件共享的数据空间，适用于记录执行轨迹等场景。

以在工作流中更新状态数据为例，增加全局状态信息`debug_messages`，用于记录工作流中执行过程中的运行信息，工作流的任何组件都可通过`getGlobalState`方法获取。

创建自定义组件`NodeDemo`，用于获取和更新当前的状态数据`debug_messages`：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

public class NodeDemo extends WorkflowComponent {
    private final String nodeId;

    public NodeDemo(String nodeId) {
        this.nodeId = nodeId;
    }

    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 获取当前debug_messages的状态数据
        Object debugMessages = session.getGlobalState("debug_messages");
        System.out.println(nodeId + ": debug_messages=" + debugMessages);

        // 更新状态数据
        List<Map<String, Object>> newDebugMessages = new ArrayList<>();
        if (debugMessages instanceof List<?> list) {
            newDebugMessages.addAll((List<Map<String, Object>>) list);
        }
        newDebugMessages.add(Map.of(nodeId, Map.of("inputs", inputs)));
        session.updateGlobalState(Map.of("debug_messages", newDebugMessages));

        // 打印更新完的状态数据
        System.out.println(nodeId + ": after update debug_messages=" + session.getGlobalState("debug_messages"));
        
        return Map.of("output", inputs);
    }
}
```

创建简单工作流，并执行：

```java
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.WorkflowOutput;

import java.util.Map;

public class GlobalStateExample {

    public static void main(String[] args) {
        WorkflowCard card = WorkflowCard.builder()
                .id("state_workflow")
                .name("状态管理工作流")
                .build();

        Workflow workflow = new Workflow(card);
        workflow.setStartComp("start", new NodeDemo("start"), Map.of("a", "${user_inputs.a}"), null);
        workflow.addWorkflowComp("node", new NodeDemo("node"), Map.of("a", "${start.output.a}"), null);
        workflow.setEndComp("end", new NodeDemo("end"), Map.of("a", "${node.output.a}"), null);
        workflow.addConnection("start", "node");
        workflow.addConnection("node", "end");

        // 执行工作流
        WorkflowOutput output = workflow.invoke(
                Map.of("user_inputs", Map.of("a", 1)),
                new WorkflowSessionApi(null, "state_session", Map.of()),
                null
        );
        System.out.println(output);
    }
}
```

运行结果如下，可看出工作流的状态数据更新的生效时间是在本组件执行完成：

```text
start: debug_messages=null
start: after update debug_messages=null
node: debug_messages=[{start={inputs={a=1}}}]
node: after update debug_messages=[{start={inputs={a=1}}}]
end: debug_messages=[{start={inputs={a=1}}}, {node={inputs={a=1}}}]
end: after update debug_messages=[{start={inputs={a=1}}}, {node={inputs={a=1}}}]
result={output={a=1}} state=COMPLETED
```

## 组件状态数据

组件状态数据是自定义组件的私有数据空间，用于存储组件专属信息（如执行次数、中间结果等）。

以两个自定义组件为例，创建自定义组件`AddTenComponent`，该组件通过`call_times`记录了当前组件的执行次数。并创建第二个自定义组件`CustomEnd`去尝试读取`call_times`。

`AddTenComponent`是一个在工作流中反复执行的自定义组件，用于对全局数值进行累加（每次 +10），同时维护自身私有的执行次数状态`call_times`。该组件通过**组件状态数据**（`updateState`）记录自身执行次数，确保状态仅在本组件内部可见；同时通过**全局状态数据**（`updateGlobalState`）更新共享的累加值`num`，供其他组件读取：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;

public class AddTenComponent extends WorkflowComponent {
    private final String nodeId;

    public AddTenComponent(String nodeId) {
        this.nodeId = nodeId;
    }

    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 获取当前组件私有状态：执行次数
        Object callTimesObj = session.getState("call_times");
        int callTimes = callTimesObj instanceof Number number ? number.intValue() : 0;
        
        // 获取全局共享状态：累加数值
        Object numObj = session.getGlobalState("num");
        int num = numObj instanceof Number number ? number.intValue() : 0;

        // 更新组件私有状态：执行次数 +1
        callTimes += 1;
        session.updateState(Map.of("call_times", callTimes));

        // 执行运算：num += 10
        num += 10;
        session.updateGlobalState(Map.of("num", num));

        // 打印调试信息
        System.out.println("[a] 执行第 " + callTimes + " 次，num = " + (num - 10) + " → " + num);

        return inputs;
    }
}
```

`CustomEnd`是一个用于验证**组件状态隔离性**的终端组件。它尝试读取`AddTenComponent`维护的私有状态`call_times`，并获取全局状态`num`，以演示**组件状态仅限本组件可见**的特性：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;

public class CustomEnd extends WorkflowComponent {
    private final String nodeId;

    public CustomEnd(String nodeId) {
        this.nodeId = nodeId;
    }

    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        // 尝试读取其他组件的私有状态（预期不可见）
        Object callTimes = session.getState("call_times");
        System.out.println("->[CustomEnd] 获取 call_times = " + callTimes);  // 输出: null

        // 读取全局共享状态（预期可见）
        Object num = session.getGlobalState("num");
        System.out.println("->[CustomEnd] 获取 num = " + num);

        return inputs;
    }
}
```

创建工作流，并添加分支组件：

```java
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.BranchComponent;

public class ComponentStateExample {

    public static void main(String[] args) {
        // 创建工作流
        WorkflowCard card = WorkflowCard.builder()
                .id("component_state_workflow")
                .name("组件状态工作流")
                .build();

        Workflow workflow = new Workflow(card);
        workflow.setStartComp("start", new Start(), Map.of(), null);
        workflow.setEndComp("end", new CustomEnd("end"), Map.of(), null);
        workflow.addWorkflowComp("a", new AddTenComponent("a"), Map.of(), null);

        // 增加分支组件，触发AddTenComponent的多次调用
        BranchComponent sw = new BranchComponent();
        sw.addBranch("${num} <= 30", List.of("a"), "1");
        sw.addBranch("${num} > 30", List.of("end"), "2");

        workflow.addWorkflowComp("sw", sw, Map.of(), null);
        workflow.addConnection("start", "a");
        workflow.addConnection("a", "sw");

        // 调用工作流
        workflow.invoke(Map.of(), new WorkflowSessionApi(null, "comp_state_session", Map.of()), null);
    }
}
```

执行结果如下，可发现，`AddTenComponent`每次执行都可获取到最新的状态`call_times`，此外，由于`call_times`是`AddTenComponent`组件私有的状态，因此`CustomEnd`获取不到该状态：

```text
[a] 执行第 1 次，num = 0 → 10
[a] 执行第 2 次，num = 10 → 20
[a] 执行第 3 次，num = 20 → 30
[a] 执行第 4 次，num = 30 → 40
->[CustomEnd] 获取 call_times = null
->[CustomEnd] 获取 num = 40
```

## Agent状态管理

Agent侧状态管理主要通过`AgentSessionApi`：

```java
import com.openjiuwen.core.session.AgentSessionApi;

// 获取全局状态
Object globalState = agentSession.getState("global_state_key");

// 更新全局状态
agentSession.updateState(Map.of("global_state_key", "global_state_value"));
```

Agent侧状态结构比workflow更简单，主要是：

- `global_state`：Agent全局共享状态
- `agent_state`：Agent私有状态
