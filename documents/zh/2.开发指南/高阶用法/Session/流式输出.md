在openJiuwen框架中，工作流、Agent运行时由`Session`核心类实现，该类提供了实时将数据流式输出到工作流或Agent外的能力，使得工作流和Agent场景能够实现高效、实时的数据处理和传递，从而满足高性能和高实时性的应用需求。`Session`支持以下两种流式输出场景：

* **工作流流式输出**：在工作流中，大模型组件的token生成和提问器组件的交互过程均支持实时流式输出，且组件运行时的调试与异常信息也可通过流式方式呈现，实现全链路实时监控与问题处理。
* **Agent流式输出**：在Agent中，Agent的思考、规划、执行过程均可通过流式数据实时反馈给用户，利用异步数据传输机制和结构化输出接口，让用户能够实时监控和了解Agent的执行状态和处理逻辑。

工作流和Agent可通过`Session`提供的流式输出接口，将实时生成的数据异步放入消息队列中，并通过工作流和Agent的`stream`接口实时消费和处理这些数据，同时支持openJiuwen标准格式`OutputSchema`和用户自定义数据格式`CustomSchema`的结构化输出。

# 工作流流式输出

在工作流场景下，流式输出的实现通常依赖于各组件调用`Session`提供的流式输出接口，通过异步生产-消费数据架构来逐步传递实时数据。以下将介绍如何利用`Session`的流式输出接口，设计并实现具备流式输出功能的工作流。

自定义组件`CustomComponent`，组件输入是思考模式标识，`True`表示开启思考模式，输出标准格式的流式数据；`False`表示关闭思考模式，输出自定义格式的流式数据。

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.session.stream.OutputSchema;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;

public class CustomComponent extends WorkflowComponent {
    private final String componentId;

    public CustomComponent(String componentId) {
        this.componentId = componentId;
    }

    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (Map<String, Object>) inputs;
        boolean thinkMode = Boolean.TRUE.equals(inputMap.get("think_mode"));

        if (thinkMode) {
            // 标准格式流式输出，数据类型为 OutputSchema
            session.writeStream(OutputSchema.builder()
                    .type("answer")
                    .index(0)
                    .payload(Map.of(
                            "component", componentId,
                            "content", "I am " + componentId + ", please waiting thinking."
                    ))
                    .build());
        } else {
            // 自定义格式流式输出，数据类型为 Map
            session.writeCustomStream(Map.of("answer", "I will generate a picture for you."));
        }
        return Map.of();
    }
}
```

搭建基础工作流，将开始组件`start`、自定义组件`stream_out_comp`、结束组件`end`添加到工作流中，并建立三个组件之间的拓扑关系。将流式输出模式设置为标准格式和自定义格式，并在两种场景（思考模式开启、关闭）下执行该工作流：

```java
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.session.stream.StreamMode;
import com.openjiuwen.core.session.stream.OutputSchema;
import com.openjiuwen.core.session.stream.CustomSchema;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;

import java.util.Iterator;
import java.util.List;
import java.util.Map;

public class WorkflowStreamingExample {

    public static void main(String[] args) {
        // 场景1：think_mode为True
        runWorkflow(true);

        // 场景2：think_mode为False
        runWorkflow(false);
    }

    private static void runWorkflow(boolean thinkMode) {
        // 初始化工作流
        WorkflowCard card = WorkflowCard.builder()
                .id("stream_workflow")
                .name("流式输出工作流")
                .build();

        Workflow workflow = new Workflow(card);

        // 添加开始、结束组件到工作流
        workflow.setStartComp("start", new Start(), Map.of("query", "${user_inputs.query}"), null);
        workflow.setEndComp("end", new End(),
                Map.of("query", "${start.query}", "answer", "${stream_out_comp.answer}"),
                null);

        // 添加实现直接流式输出的自定义组件
        workflow.addWorkflowComp("stream_out_comp", new CustomComponent("stream_out_comp"),
                Map.of("think_mode", "${user_inputs.think_mode}"),
                null);

        // 定义组件连接
        workflow.addConnection("start", "stream_out_comp");
        workflow.addConnection("stream_out_comp", "end");

        // 构造输入
        Map<String, Object> inputs = Map.of(
                "user_inputs", Map.of(
                        "query", "Help me generate a picture of West Lake.",
                        "think_mode", thinkMode
                )
        );

        WorkflowSessionApi session = new WorkflowSessionApi(null, "stream_session", Map.of());

        // 设置流式输出模式为标准格式和自定义格式
        System.out.println("\n==================== think_mode is " + thinkMode + ", begin to run workflow ====================\n");

        Iterator<Object> stream = workflow.stream(
                inputs,
                session,
                List.of(StreamMode.OUTPUT, StreamMode.CUSTOM)
        );

        while (stream.hasNext()) {
            Object chunk = stream.next();
            if (chunk instanceof OutputSchema output) {
                System.out.println("Receive stream chunk (OutputSchema): " + output);
            } else if (chunk instanceof CustomSchema custom) {
                System.out.println("Receive stream chunk (CustomSchema): " + custom);
            } else {
                System.out.println("Receive stream chunk: " + chunk);
            }
        }

        System.out.println("\n==================== think_mode is " + thinkMode + ", end to run workflow ====================\n");
    }
}
```

输出结果为：

```text
==================== think_mode is true, begin to run workflow ====================

Receive stream chunk (OutputSchema): type='answer' index=0 payload={component=stream_out_comp, content=I am stream_out_comp, please waiting thinking.}
Receive stream chunk (OutputSchema): type='workflow_final' index=0 payload={output={query=Help me generate a picture of West Lake.}}
==================== think_mode is true, end to run workflow ====================

==================== think_mode is false, begin to run workflow ====================

Receive stream chunk (CustomSchema): answer=I will generate a picture for you.
Receive stream chunk (OutputSchema): type='workflow_final' index=0 payload={output={query=Help me generate a picture of West Lake.}}
==================== think_mode is false, end to run workflow ====================
```

从工作流执行结果可看出：

* 当用户输入`think_mode`为`True`时，自定义组件`stream_out_comp`输出流式数据类型为`OutputSchema`，数据内容为`type='answer' index=0 payload={component=stream_out_comp, content='I am stream_out_comp, please waiting thinking.'}`。
* 当用户输入`think_mode`为`False`时，自定义组件`stream_out_comp`输出流式数据类型为`CustomSchema`，数据内容为`answer='I will generate a picture for you.'`。
* 上述两个场景下，工作流均会输出最终执行结果的流式数据，该流式数据类型为`OutputSchema`，数据内容为`type='workflow_final' index=0 payload={output={query='Help me generate a picture of West Lake.'}}`。

# Agent流式输出

在Agent场景下，流式输出的实现通常依赖于Agent的技能模块（如大模型服务、工作流等），通过调用`Session`提供的流式输出接口，实现数据的实时、高效传输和处理。

使用`Runner.runAgentStreaming`方法执行Agent流式输出：

```java
import com.openjiuwen.core.runner.Runner;
import com.openjiuwen.core.session.stream.StreamMode;
import com.openjiuwen.core.session.stream.OutputSchema;
import com.openjiuwen.core.singleagent.ReActAgent;
import com.openjiuwen.core.singleagent.agents.ReActAgentConfig;
import com.openjiuwen.core.singleagent.schema.AgentCard;

import java.util.Iterator;
import java.util.List;
import java.util.Map;

public class AgentStreamingExample {

    public static void main(String[] args) {
        // 创建Agent
        AgentCard agentCard = AgentCard.builder()
                .id("stream_agent")
                .name("流式输出Agent")
                .build();

        ReActAgent agent = new ReActAgent(agentCard);
        ReActAgentConfig config = ReActAgentConfig.builder()
                .maxIterations(5)
                .build()
                .configureModelClient(
                        modelProvider,
                        apiKey,
                        apiBase,
                        modelName,
                        sslVerify
                );
        agent.configure(config);

        // 执行Agent流式输出
        String conversationId = "stream_conversation";

        System.out.println("\n==================== begin to run agent streaming ====================\n");

        Iterator<Object> stream = Runner.runAgentStreaming(
                agent,
                Map.of("query", "帮我查询北京的天气", "conversation_id", conversationId),
                null,
                null,
                List.of(StreamMode.OUTPUT)
        );

        while (stream.hasNext()) {
            Object chunk = stream.next();
            if (chunk instanceof OutputSchema output) {
                System.out.println("Receive stream chunk: type=" + output.getType() + ", payload=" + output.getPayload());
            } else {
                System.out.println("Receive stream chunk: " + chunk);
            }
        }

        System.out.println("\n==================== end to run agent streaming ====================\n");

        // 清理资源
        Runner.release(conversationId);
        Runner.stop();
    }
}
```

输出结果为：

```text
==================== begin to run agent streaming ====================

Receive stream chunk: type=answer, payload={content=北京今天的天气...}
Receive stream chunk: type=answer, payload={content=气温约为25°C...}
Receive stream chunk: type=answer, payload={content=建议穿着...}
==================== end to run agent streaming ====================
```

# 流式输出模式

`StreamMode`定义三种流式输出模式：

| Mode | 典型chunk | 适用场景 |
| --- | --- | --- |
| `OUTPUT` | `OutputSchema` | 标准答案块、`workflow_final`、交互提示等框架标准输出。 |
| `TRACE` | `TraceSchema` | workflow/agent执行观测、组件开始/结束、错误与自定义trace数据。 |
| `CUSTOM` | `CustomSchema` | 业务方自定义结构化流数据。 |

# Chunk数据结构

## OutputSchema

`OutputSchema`是框架标准输出chunk，核心字段：

- `type`：业务含义标签（如`answer`、`workflow_final`、`__interaction__`）
- `index`：块索引
- `payload`：实际数据内容

```java
OutputSchema output = OutputSchema.builder()
        .type("answer")
        .index(0)
        .payload(Map.of("content", "回答内容"))
        .build();
```

## TraceSchema

`TraceSchema`用于执行观测数据：

- `type`：trace类型
- `payload`：trace数据

```java
TraceSchema trace = TraceSchema.builder()
        .type("component_start")
        .payload(Map.of("component_id", "node1"))
        .build();
```

## CustomSchema

`CustomSchema`用于自定义业务数据：

```java
CustomSchema custom = CustomSchema.builder()
        .data(Map.of("custom_field", "custom_value"))
        .build();
```

# Session流式接口

在组件内部，可通过`NodeSessionApi`的流式接口写入数据：

```java
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.session.stream.OutputSchema;

// 标准格式流式输出
session.writeStream(OutputSchema.builder()
        .type("answer")
        .index(0)
        .payload(Map.of("content", "回答内容"))
        .build());

// 自定义格式流式输出
session.writeCustomStream(Map.of("custom_data", "自定义内容"));

// Trace格式流式输出
session.writeTraceStream(Map.of("trace_type", "debug", "message", "调试信息"));
```
