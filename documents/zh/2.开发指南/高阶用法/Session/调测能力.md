Session提供的调测模块，方便用户进行调测。该模块在Workflow的执行过程中自动化的采集事件信息，并以**流式消息**的形式实时的发送给用户，将系统内部状态透明化地呈现给用户。也支持用户注入自定义的调测信息。openJiuwen提供了以下两种调测能力：

* **基础调测能力**： Session的调测在Workflow模式下，记录了整个工作流的执行开始和最终完成的状态。并且对Workflow整个执行过程中进行更加细致的事件采集，包括：
  
  * **组件执行**：追踪每个组件的开始、结束与执行状态。
  * **复杂逻辑增强**：针对**循环、条件分支**等复杂结构，进行增强式采集。
  * **执行异常**：Workflow在执行过程中抛出的错误会被自动捕获。
* **自定义调测能力**：Session还提供了标准调测信息收集接口，允许开发者注入并收集**自定义调测信息**。

# 基础调测能力

调测字段参考API接口文档[TraceSchema](../../API文档/com.openjiuwen.core/session/stream/TraceSchema.md)。

以下将从典型调测场景出发，介绍基础工作流调测的关键字段与输出示例。

## 基础工作流场景

以搭建一个基础工作流为例介绍基础调测信息。

自定义组件`CustomComponent`，将输入直接作为输出返回：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;

// 定义一个自定义组件
public class CustomComponent extends WorkflowComponent {
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        return inputs;
    }
}
```

搭建基础工作流，流程定义为start -> a -> end：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;

// 搭建基础工作流
// start -> a -> end
WorkflowCard card = WorkflowCard.builder()
        .id("trace_workflow")
        .name("调测工作流")
        .build();

Workflow workflow = new Workflow(card);
// 设置start组件
workflow.setStartComp("start", new Start(), Map.of("num", "${num}"), null);
// 设置自定义组件a
workflow.addWorkflowComp("a", new CustomComponent(), Map.of("a_num", "${start.num}"), null);
// 设置结束组件end
workflow.setEndComp("end", new End(Map.of("responseTemplate", "hello:{{result}}")),
        Map.of("result", "${a.a_num}"),
        null);
// 连接组件：start -> a -> end
workflow.addConnection("start", "a");
workflow.addConnection("a", "end");
```

通过`workflow.stream`方法执行工作流，并指定`StreamMode.TRACE`，获取基础工作流的流输出调测信息：

```java
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.session.stream.StreamMode;
import com.openjiuwen.core.session.stream.TraceSchema;

import java.util.Iterator;
import java.util.List;
import java.util.Map;

public class BasicTraceExample {

    public static void main(String[] args) {
        Iterator<Object> stream = workflow.stream(
                Map.of("num", 1),
                new WorkflowSessionApi(null, "trace_session", Map.of()),
                List.of(StreamMode.TRACE)
        );

        while (stream.hasNext()) {
            Object chunk = stream.next();
            if (chunk instanceof TraceSchema trace) {
                System.out.println("Trace chunk: " + trace);
            } else {
                System.out.println("Stream chunk: " + chunk);
            }
        }
    }
}
```

# 自定义调测能力

为了方便开发者调试自定义的组件，Session 专门提供了接口，允许开发者向组件中注入自定义的调试信息。

创建自定义组件`AddComponent`，用来做加法运算，并调用Session的`trace`和`traceError`能力来记录自定义的调测信息：

```java
import com.openjiuwen.core.context.ModelContext;
import com.openjiuwen.core.session.NodeSessionApi;
import com.openjiuwen.core.workflow.WorkflowComponent;

import java.util.Map;

public class AddComponent extends WorkflowComponent {
    @Override
    public Object invoke(Object inputs, NodeSessionApi session, ModelContext context) {
        Map<String, Object> inputMap = (Map<String, Object>) inputs;
        Object a = inputMap.get("a");
        Object b = inputMap.get("b");

        if (a == null) {
            RuntimeException error = new RuntimeException("a is not exist");
            session.traceError(error);
            throw error;
        }
        if (b == null) {
            RuntimeException error = new RuntimeException("b is not exist");
            session.traceError(error);
            throw error;
        }

        long startTime = System.currentTimeMillis();
        int result = ((Number) a).intValue() + ((Number) b).intValue();
        long cost = System.currentTimeMillis() - startTime;

        // 记录自定义调测信息
        session.trace(Map.of("a", a, "b", b, "cost", cost));

        return Map.of("output", result);
    }
}
```

构建简单工作流，将自定义的`AddComponent`添加到工作流中：

```java
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;

WorkflowCard card = WorkflowCard.builder()
        .id("custom_trace_workflow")
        .name("自定义调测工作流")
        .build();

Workflow workflow = new Workflow(card);
workflow.setStartComp("start", new Start(), Map.of(), null);
workflow.addWorkflowComp("add", new AddComponent(),
        Map.of("a", "${inputs.a}", "b", "${inputs.b}"),
        null);
workflow.setEndComp("end", new End(), Map.of("result", "${add.output}"), null);
workflow.addConnection("start", "add");
workflow.addConnection("add", "end");
```

调用工作流的`stream`接口，打印trace信息：

```java
Iterator<Object> stream = workflow.stream(
        Map.of("inputs", Map.of("a", 1, "b", 2)),
        new WorkflowSessionApi(null, "custom_trace_session", Map.of()),
        List.of(StreamMode.TRACE)
);

while (stream.hasNext()) {
    Object chunk = stream.next();
    System.out.println(chunk);
}
```

输出结果如下，其中自定义trace信息出现在组件执行过程中：

# 如何让外部真正看到trace

如果外部消费的是streaming接口，需要显式把`TRACE` mode打开：

```java
import com.openjiuwen.core.session.stream.StreamMode;
import java.util.List;

// workflow流式执行，开启TRACE
Iterator<Object> stream = workflow.stream(
        inputs,
        session,
        List.of(StreamMode.OUTPUT, StreamMode.TRACE)
);

// Runner流式执行，开启TRACE
Iterator<Object> stream = Runner.runAgentStreaming(
        agent,
        inputs,
        null,
        null,
        List.of(StreamMode.OUTPUT, StreamMode.TRACE)
);
```

**注意**：workflow的公开默认流式行为是`OUTPUT`，不是自动包含`TRACE`。如果没有显式请求`TRACE`，调用方不会收到trace chunk。
