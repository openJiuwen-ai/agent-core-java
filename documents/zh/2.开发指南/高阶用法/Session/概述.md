Session是智能体（Agent）与工作流（Workflow）的核心执行引擎与管理框架，它为执行任务提供了一个隔离、稳定的运行时环境。通过抽象底层基础设施的复杂性，Session实现了对任务全生命周期的统一调度与治理。

Session的核心优势包括：

* **有状态会话管理**：维护任务执行过程中的完整运行时与中间状态，支持事务性操作与断点续传，确保了复杂任务的一致性与可靠性。
* **结构化消息流**：原生支持流式文本与结构化中间结果（如推理步骤、工具调用事件）的实时推送，为前端提供沉浸式交互体验。
* **受控执行流程**：提供标准化的中断、暂停、回滚与继续执行机制，赋予开发者和系统对长周期任务前所未有的精细控制力。
* **深度可观测性**：自动追踪并记录从推理链、工具调用到API请求的全链路遥测数据，为性能剖析、成本审计与根因分析提供唯一可信源。

## 基本功能

* **状态管理**：Session负责管理执行状态数据。在Agent或Workflow运行过程中，可通过Session提供的接口进行数据读写操作。

```java
import com.openjiuwen.core.session.AgentSessionApi;
import com.openjiuwen.core.session.WorkflowSessionApi;
import java.util.Map;

// Agent Session 状态管理
AgentSessionApi agentSession = new AgentSessionApi("session_id", Map.of());

// 更新状态
agentSession.updateState(Map.of("key", "value"));

// 获取状态
Object value = agentSession.getState("key");

// 更新全局状态
agentSession.updateGlobalState(Map.of("global_key", "global_value"));

// Workflow Session 状态管理
WorkflowSessionApi workflowSession = new WorkflowSessionApi(
        null, "session_id", Map.of());

workflowSession.updateState(Map.of("workflow_state", "data"));
```

* **调测能力**：Session内置了全链路的调测模块，为Workflow的执行过程提供了实时的、层次化的运行洞察。该模块通过自动化的细粒度事件采集与开放的扩展接口，将系统内部状态透明化地呈现给开发者。

```java
import com.openjiuwen.core.session.NodeSessionApi;
import java.util.Map;

// 在组件中使用 trace
NodeSessionApi nodeSession = ...;

// 记录 trace 信息
nodeSession.trace(Map.of("step", "processing", "data", inputs));

// 记录错误 trace
nodeSession.traceError(Map.of("error", exception.getMessage()));
```

* **流式输出**：Session内置了高性能的结构化流式输出模块，该模块实现了将数据实时流式输出到工作流或Agent外的功能，为工作流和Agent执行过程提供了高效、实时的数据处理和传递能力。

```java
import com.openjiuwen.core.session.stream.StreamMode;
import com.openjiuwen.core.runner.Runner;
import java.util.Iterator;
import java.util.List;

// 流式执行 Agent
Iterator<Object> stream = Runner.runAgentStreaming(
        agent,
        Map.of("query", "test", "conversation_id", "conv_id"),
        null,
        null,
        List.of(StreamMode.OUTPUT, StreamMode.TRACE)
);

while (stream.hasNext()) {
    Object chunk = stream.next();
    // 处理流式输出
    System.out.println(chunk);
}
```

* **中断恢复**：Session内置了中断恢复能力，当需要恢复执行时，系统会自动加载保存的快照数据，实现无缝续跑。在执行过程中，如果发生中断或异常，Session 会立即采取以下措施：首先，对当前状态进行快照保存；其次，通过流式消息实时通知用户。

```java
import com.openjiuwen.core.session.interaction.InteractiveInput;
import com.openjiuwen.core.workflow.WorkflowOutput;
import com.openjiuwen.core.workflow.WorkflowExecutionState;

// 首次执行
WorkflowOutput output = workflow.invoke(inputs, session, null);

// 检查是否需要交互
if (WorkflowExecutionState.INPUT_REQUIRED.equals(output.getState())) {
    // 构造交互输入
    InteractiveInput userInput = new InteractiveInput();
    userInput.update("node_id", "user_answer");

    // 使用同一个 sessionId 恢复执行
    WorkflowOutput resumedOutput = workflow.invoke(userInput, session, null);
}
```

## Session 类型

Java 版 Session 主要有以下类型：

| 类型 | 角色 | 使用场景 |
| --- | --- | --- |
| `AgentSessionApi` | Agent 会话门面 | Agent 执行入口，提供状态、流输出、交互能力 |
| `WorkflowSessionApi` | Workflow 会话门面 | Workflow 执行入口，携带父级 session 和环境变量 |
| `NodeSessionApi` | 组件节点会话 | Workflow 组件内部使用，提供 trace、状态、交互接口 |

## sessionId 的重要性

在 Java 版实现中，`sessionId` 决定了至少三件事：

- 状态写到哪个会话范围
- 交互输入恢复时去哪里查旧状态
- Checkpointer 释放时清理哪一批 Agent/Workflow/Graph 数据

```java
// 使用明确的 sessionId 创建会话
String sessionId = UUID.randomUUID().toString();
AgentSessionApi session = new AgentSessionApi(sessionId, Map.of());

// 多轮执行使用同一个 sessionId
// 第一轮
Runner.runAgent(agent, Map.of("query", "query1", "conversation_id", sessionId), null, null);

// 第二轮（使用同一个 sessionId 恢复）
Runner.runAgent(agent, Map.of("query", "query2", "conversation_id", sessionId), null, null);

// 清理会话
Runner.release(sessionId);
```

## 完整示例

```java
import com.openjiuwen.core.session.AgentSessionApi;
import com.openjiuwen.core.session.WorkflowSessionApi;
import com.openjiuwen.core.session.interaction.InteractiveInput;
import com.openjiuwen.core.workflow.Workflow;
import com.openjiuwen.core.workflow.WorkflowCard;
import com.openjiuwen.core.workflow.WorkflowOutput;
import com.openjiuwen.core.workflow.WorkflowExecutionState;
import com.openjiuwen.core.workflow.component.Start;
import com.openjiuwen.core.workflow.component.End;
import com.openjiuwen.core.runner.Runner;
import com.openjiuwen.core.runner.RunnerConfig;

import java.util.Map;
import java.util.UUID;

public class SessionExample {

    public static void main(String[] args) throws Exception {
        // 配置 Runner
        RunnerConfig config = RunnerConfig.builder()
                .distributedMode(false)
                .checkpointerConfig(Map.of("type", "in_memory", "conf", Map.of()))
                .build();
        Runner.setConfig(config);
        Runner.start();

        // 创建 sessionId
        String sessionId = UUID.randomUUID().toString().substring(0, 8);

        // 创建 Workflow
        WorkflowCard card = WorkflowCard.builder()
                .id("test_workflow")
                .name("测试工作流")
                .version("1.0")
                .build();
        Workflow workflow = new Workflow(card);
        workflow.setStartComp("start", new Start(), Map.of("query", "${query}"), null);
        workflow.setEndComp("end", new End(Map.of("responseTemplate", "结果: {{result}}")),
                Map.of("result", "${start.query}"), null);
        workflow.addConnection("start", "end");

        // 创建 WorkflowSessionApi
        WorkflowSessionApi session = new WorkflowSessionApi(null, sessionId, Map.of());

        // 执行 Workflow
        WorkflowOutput output = workflow.invoke(
                Map.of("query", "测试输入"),
                session,
                null
        );

        System.out.println("输出: " + output.getResult());
        System.out.println("状态: " + output.getState());

        // 状态管理示例
        session.updateState(Map.of("custom_state", "value"));
        Object state = session.getState("custom_state");
        System.out.println("自定义状态: " + state);

        // 清理
        Runner.release(sessionId);
        Runner.stop();

        System.out.println("Session 示例完成");
    }
}
```

```

状态: COMPLETED
自定义状态: value
Session 示例完成
```
