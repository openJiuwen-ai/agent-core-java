# 知识检索

知识检索（Retrieval）是openJiuwen框架的核心组件，主要负责知识库的管理和文档检索。它提供了对文档解析、分块、索引构建、向量检索等标准化管理能力，帮助开发者在构建Agent时更高效地处理知识内容。

在智能对话场景中，用户需要从大量文档中快速准确地检索相关信息。知识检索通过向量化、索引化等方式管理这些信息，能够帮助Agent更好地理解上下文，提供准确的答案。

知识检索的开发流程分为以下两步：

1. 创建知识库实例：以`SimpleKnowledgeBase`为例创建知识库实例，支持自定义配置包括向量存储、嵌入模型、文档解析器、文本分块器等，实现知识库功能的初始化。
2. 使用知识库实例：支持添加文档、构建索引、检索文档等主要操作，帮助智能体更好地利用知识内容。

> **参考实现**：基于 `SimpleKnowledgeBase` 的示例项目。该项目实现了一个持续更新的知识库，用于为代码的审视与修复提供风格与规范层面的专业建议。

# 创建知识库实例

通过`SimpleKnowledgeBase`创建知识库实例，需要传入相应的配置参数。配置包括知识库ID、索引类型（vector/bm25/hybrid）等。另外知识库中的数据存放涉及向量存储、嵌入模型、索引管理器等，也需要初始化的时候进行配置。在`com.openjiuwen.core.retrieval`下提供了默认实现，也可以自定义实现。

下面以使用默认的`MilvusVectorStore`、`APIEmbedding`和`MilvusIndexer`为例，说明如何创建知识库实例。

```java
import com.openjiuwen.core.retrieval.SimpleKnowledgeBase;
import com.openjiuwen.core.retrieval.GraphKnowledgeBase;
import com.openjiuwen.core.retrieval.common.KnowledgeBaseConfig;
import com.openjiuwen.core.retrieval.common.RetrievalConfig;
import com.openjiuwen.core.retrieval.common.VectorStoreConfig;
import com.openjiuwen.core.retrieval.common.EmbeddingConfig;
import com.openjiuwen.core.retrieval.embedding.APIEmbedding;
import com.openjiuwen.core.retrieval.vector_store.MilvusVectorStore;
import com.openjiuwen.core.retrieval.indexing.indexer.MilvusIndexer;
import com.openjiuwen.core.retrieval.indexing.processor.chunker.TextChunker;
import com.openjiuwen.core.retrieval.indexing.processor.parser.AutoFileParser;

import java.util.Map;

public class KnowledgeBaseExample {

    public static SimpleKnowledgeBase createKb() throws Exception {
        // 定义知识库配置
        KnowledgeBaseConfig kbConfig = KnowledgeBaseConfig.builder()
                .kbId("test_kb_001")
                .indexType("hybrid")  // 支持 vector、bm25、hybrid
                .useGraph(false)
                .chunkSize(512)
                .chunkOverlap(50)
                .build();

        // 创建向量存储
        VectorStoreConfig vectorStoreConfig = VectorStoreConfig.builder()
                .collectionName("kb_" + kbConfig.getKbId() + "_chunks")
                .distanceMetric("cosine")
                .build();
        
        String milvusUri = "http://localhost:19530";
        String milvusToken = "";
        MilvusVectorStore vectorStore = new MilvusVectorStore(
                vectorStoreConfig,
                milvusUri,
                milvusToken
        );

        // 创建嵌入模型
        EmbeddingConfig embeddingConfig = EmbeddingConfig.builder()
                .modelName("text-embedding-3-small")
                .apiKey("sk-xxxxx")
                .baseUrl("https://api.openai.com/v1")
                .build();
        
        APIEmbedding embedModel = new APIEmbedding(embeddingConfig, 3, 60, 128);

        // 创建索引管理器（与向量存储共用 VectorStoreConfig）
        MilvusIndexer indexer = new MilvusIndexer(
                vectorStoreConfig,
                milvusUri,
                milvusToken
        );

        // 创建文档解析器（自动识别文件格式）
        AutoFileParser parser = new AutoFileParser();

        // 创建文本分块器
        TextChunker chunker = new TextChunker(
                kbConfig.getChunkSize(),
                kbConfig.getChunkOverlap(),
                "token"  // 支持 char 或 token
        );

        // 创建知识库实例
        SimpleKnowledgeBase knowledgeBase = new SimpleKnowledgeBase(
                kbConfig,
                vectorStore,
                embedModel,
                parser,
                chunker,
                indexer,
                null,  // BaseModelClient
                null   // Retriever
        );

        return knowledgeBase;
    }
}
```

# 使用知识库实例

知识库支持添加文档、检索文档、删除文档、更新文档等主要操作。

## 添加文档

通过`parseFiles`和`addDocuments`方法可以添加文档到知识库，知识库会自动进行文档解析、分块、索引构建等处理。

```java
import com.openjiuwen.core.retrieval.indexing.processor.parser.Document;
import java.util.List;
import java.util.ArrayList;

public class AddDocumentsExample {

    public static void addDocuments(SimpleKnowledgeBase knowledgeBase) throws Exception {
        // 准备文档文件路径
        List<String> filePaths = new ArrayList<>();
        filePaths.add("./documents/doc1.pdf");
        filePaths.add("./documents/doc2.txt");
        filePaths.add("./documents/doc3.md");

        // 解析文件为Document对象列表
        List<Document> documents = knowledgeBase.parseFiles(filePaths);

        // 添加doc id
        for (int i = 0; i < documents.size(); i++) {
            documents.get(i).setId("doc_id_" + (i + 1));
        }

        // 添加文档到知识库（自动分块和构建索引）
        List<String> docIds = knowledgeBase.addDocuments(documents);
        System.out.println("成功添加 " + docIds.size() + " 个文档，文档ID: " + docIds);
    }
}
```

## 检索文档

通过`retrieve`方法可以检索相关文档，支持向量检索、稀疏检索和混合检索。

```java
import com.openjiuwen.core.retrieval.common.RetrievalConfig;
import com.openjiuwen.core.retrieval.RetrievalResult;
import java.util.List;

public class RetrievalExample {

    public static void retrieval(SimpleKnowledgeBase knowledgeBase) {
        // 配置检索参数
        RetrievalConfig retrievalConfig = RetrievalConfig.builder()
                .topK(3)          // 返回前3个结果
                .scoreThreshold(0.3)  // 相似度阈值
                .build();

        // 执行检索
        String query = "什么是人工智能？";
        List<RetrievalResult> results = knowledgeBase.retrieve(query, retrievalConfig);

        // 打印检索结果
        for (int i = 0; i < results.size(); i++) {
            RetrievalResult result = results.get(i);
            System.out.println("\n结果 " + (i + 1) + ":");
            System.out.println("  文本: " + result.getText().substring(0, Math.min(100, result.getText().length())) + "...");
            System.out.println("  相似度: " + String.format("%.4f", result.getScore()));
            System.out.println("  文档ID: " + result.getDocId());
            System.out.println("  块ID: " + result.getChunkId());
        }
    }
}
```

## 删除文档

通过`deleteDocuments`方法可以删除知识库中的文档。

```java
public class DeleteDocumentsExample {

    public static void deleteDocuments(SimpleKnowledgeBase knowledgeBase) {
        List<String> docIdsToDelete = List.of("doc_id_1", "doc_id_2");
        boolean success = knowledgeBase.deleteDocuments(docIdsToDelete);
        System.out.println("删除结果: " + success);
    }
}
```

## 多知识库联合检索

`SimpleKnowledgeBase` 还提供了多知识库联合检索的辅助方法，适合在一个请求中同时查询多个 `KnowledgeBase`：

- `retrieveMultiKb(List<KnowledgeBase> kbs, String query, RetrievalConfig config, int topK)`
- `retrieveMultiKbWithSource(List<KnowledgeBase> kbs, String query, RetrievalConfig config, int topK)`

示例：

```java
import com.openjiuwen.core.retrieval.SimpleKnowledgeBase;
import com.openjiuwen.core.retrieval.KnowledgeBase;
import java.util.List;

public class MultiKbExample {

    public static void searchAcrossKbs(List<SimpleKnowledgeBase> kbs) {
        String query = "什么是向量检索？";
        RetrievalConfig config = RetrievalConfig.builder().topK(5).build();

        // 仅返回去重后的文本结果
        List<String> texts = SimpleKnowledgeBase.retrieveMultiKb(kbs, query, config, 5);
        for (int i = 0; i < texts.size(); i++) {
            System.out.println((i + 1) + ". " + texts.get(i));
        }

        // 返回包含来源信息的结果
        List<Map<String, Object>> results = SimpleKnowledgeBase.retrieveMultiKbWithSource(kbs, query, config, 5);
        for (Map<String, Object> item : results) {
            System.out.println("text=" + item.get("text") + 
                               ", score=" + item.get("score") + 
                               ", kbIds=" + item.get("kb_ids"));
        }
    }
}
```

```java
        System.out.println("索引类型: " + stats.get("index_type"));
        System.out.println("索引信息: " + stats.get("index_info"));
        System.out.println("组件状态: " + stats);
    }
}
```

# 完整的使用知识库代码示例

```java
import com.openjiuwen.core.retrieval.SimpleKnowledgeBase;
import com.openjiuwen.core.retrieval.common.KnowledgeBaseConfig;
import com.openjiuwen.core.retrieval.common.RetrievalConfig;
import com.openjiuwen.core.retrieval.common.VectorStoreConfig;
import com.openjiuwen.core.retrieval.common.EmbeddingConfig;
import com.openjiuwen.core.retrieval.embedding.APIEmbedding;
import com.openjiuwen.core.retrieval.vector_store.MilvusVectorStore;
import com.openjiuwen.core.retrieval.indexing.indexer.MilvusIndexer;
import com.openjiuwen.core.retrieval.indexing.processor.chunker.TextChunker;
import com.openjiuwen.core.retrieval.indexing.processor.parser.AutoFileParser;
import com.openjiuwen.core.retrieval.indexing.processor.parser.Document;
import com.openjiuwen.core.retrieval.RetrievalResult;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

public class KnowledgeBaseFullExample {

    public static SimpleKnowledgeBase createKb() throws Exception {
        KnowledgeBaseConfig kbConfig = KnowledgeBaseConfig.builder()
                .kbId("test_kb_001")
                .indexType("hybrid")
                .useGraph(false)
                .chunkSize(512)
                .chunkOverlap(50)
                .build();

        VectorStoreConfig vectorStoreConfig = VectorStoreConfig.builder()
                .collectionName("kb_" + kbConfig.getKbId() + "_chunks")
                .distanceMetric("cosine")
                .build();

        MilvusVectorStore vectorStore = new MilvusVectorStore(
                vectorStoreConfig, "http://localhost:19530", "");

        EmbeddingConfig embeddingConfig = EmbeddingConfig.builder()
                .modelName("text-embedding-3-small")
                .apiKey("sk-xxxxx")
                .baseUrl("https://api.openai.com/v1")
                .build();

        APIEmbedding embedModel = new APIEmbedding(embeddingConfig, 3, 60, 128);
        MilvusIndexer indexer = new MilvusIndexer(vectorStoreConfig, "http://localhost:19530", "");
        AutoFileParser parser = new AutoFileParser();
        TextChunker chunker = new TextChunker(kbConfig.getChunkSize(), kbConfig.getChunkOverlap(), "token");

        return new SimpleKnowledgeBase(kbConfig, vectorStore, embedModel, parser, chunker, indexer, null, null);
    }

    public static void addDocuments(SimpleKnowledgeBase knowledgeBase) throws Exception {
        List<String> filePaths = new ArrayList<>();
        filePaths.add("./documents/doc1.pdf");
        filePaths.add("./documents/doc2.txt");
        filePaths.add("./documents/doc3.md");

        List<Document> documents = knowledgeBase.parseFiles(filePaths);
        for (int i = 0; i < documents.size(); i++) {
            documents.get(i).setId("doc_id_" + (i + 1));
        }

        List<String> docIds = knowledgeBase.addDocuments(documents);
        System.out.println("成功添加 " + docIds.size() + " 个文档，文档ID: " + docIds);
    }

    public static void retrieval(SimpleKnowledgeBase knowledgeBase) {
        RetrievalConfig retrievalConfig = RetrievalConfig.builder().topK(3).build();

        String query = "什么是人工智能？";
        List<RetrievalResult> results = knowledgeBase.retrieve(query, retrievalConfig);

        for (int i = 0; i < results.size(); i++) {
            RetrievalResult result = results.get(i);
            System.out.println("\n结果 " + (i + 1) + ":");
            System.out.println("  文本: " + result.getText().substring(0, Math.min(100, result.getText().length())) + "...");
            System.out.println("  相似度: " + String.format("%.4f", result.getScore()));
            System.out.println("  文档ID: " + result.getDocId());
            System.out.println("  块ID: " + result.getChunkId());
            System.out.println("  元数据: " + result.getMetadata());
        }
    }

    public static void deleteDocuments(SimpleKnowledgeBase knowledgeBase) {
        List<String> docIdsToDelete = List.of("doc_id_1", "doc_id_2");
        boolean success = knowledgeBase.deleteDocuments(docIdsToDelete);
        System.out.println("删除结果: " + success);
    }

    public static void main(String[] args) throws Exception {
        SimpleKnowledgeBase kb = createKb();
        addDocuments(kb);
        retrieval(kb);
        deleteDocuments(kb);
    }
}
```

# GraphKnowledgeBase

对于需要图索引的场景，可以使用 `GraphKnowledgeBase`。它增加三元组抽取、图索引和图扩展检索能力：

```java
import com.openjiuwen.core.retrieval.GraphKnowledgeBase;
import com.openjiuwen.core.retrieval.common.KnowledgeBaseConfig;

public class GraphKbExample {

    public static GraphKnowledgeBase createGraphKb() throws Exception {
        KnowledgeBaseConfig kbConfig = KnowledgeBaseConfig.builder()
                .kbId("graph_kb_001")
                .indexType("hybrid")
                .useGraph(true)  // 启用图索引
                .chunkSize(512)
                .chunkOverlap(50)
                .build();

        // 其他组件配置同 SimpleKnowledgeBase
        GraphKnowledgeBase graphKb = new GraphKnowledgeBase(
                kbConfig,
                vectorStore,
                embedModel,
                parser,
                chunker,
                indexer,
                llmClient,  // 可选，用于三元组抽取
                null
        );

        return graphKb;
    }
}
```

`GraphKnowledgeBase` 在 `useGraph = true` 时会维护额外的 triple 索引，适合实体关系比较重要的场景。
