# 技能与系统操作（Skills）

Skills（技能）和系统操作（SysOperation）是 openJiuwen 在当前版本中新增的一组能力，用于把**磁盘上的技能知识 + 受控系统能力**安全地开放给 Agent 使用。

本章节基于源码 `com.openjiuwen.core.singleagent.skills` 与 `com.openjiuwen.core.sysop`，介绍如何：

- 通过 `registerSkill` 为 Agent 注册技能目录；
- 自动为 Agent 挂载查看文件、执行代码、执行命令等内置工具；
- 将技能信息注入到 Agent 的提示词中。

> 说明：下面示例只使用已经在源码中真实存在的类/方法（例如 `agent.registerSkill`、`Runner.resourceMgr().addSysOperation` 等），不再使用旧版已删除的接口。

---

## 1. 能力总览

### 1.1 Skills 模块的角色

源码入口：`com.openjiuwen.core.singleagent.skills`，对外主要导出：

- `SkillManager`：维护技能注册表，负责扫描技能目录、解析 `Skill.md` 元数据。
- `SkillUtil`：面向业务的一站式封装，生成技能提示词。
- `BaseAgent.registerSkill(...)`：注册本地技能目录。
- `BaseAgent.registerRemoteSkills(...)`：从 GitHub 下载并注册远程技能。

在高阶用法中，大部分场景只需要直接使用 `ReActAgent` 的 `registerSkill` 方法即可。

### 1.2 SysOperation 的作用

源码入口：`com.openjiuwen.core.sysop`，对外导出：

- `OperationMode`：运行模式枚举（如 LOCAL / SANDBOX）。
- `LocalWorkConfig`：本地模式下的配置。
- `SysOperationCard`：描述一个 SysOperation 实例的卡片。
- `SysOperation`：实际对接文件系统、代码执行、Shell 的入口类。

Skills 模块不会直接访问操作系统，而是全部通过 SysOperation 的三类子接口完成：

- `fs()`：读写文件、列目录等；
- `code()`：执行代码，如 Python 代码块；
- `shell()`：执行 Shell 命令。

> 在实际工程项目中，SysOperation 实例通常由 Runner 的资源管理器在启动时统一注册，并分配一个约定好的 `sysOperationId`（例如 `"default_sys_op"`）。Skills 相关代码只需要拿到这个 id 即可，无需关心具体注册细节。

## 2. 准备技能目录（Skill.md）

Skills 通过扫描磁盘目录来发现技能。一个典型的技能目录结构如下：

```text
skills_root/
  ├─ data_analysis/
  │    ├─ Skill.md
  │    └─ examples/ ...
  └─ sql_knowledge/
       ├─ Skill.md
       └─ cheatsheet.sql
```

每个子目录中必须包含一个 `Skill.md` 文件。

在源码中，`SkillManager` 只依赖 `Skill.md` 的 YAML front matter 中的 `description` 字段，用于生成技能描述，其余内容由业务自由定义，例如：

```markdown
---
name: sql_knowledge
description: 为 Agent 提供常用 SQL 语法、优化技巧等知识
---

这里是技能的详细说明，可以包含示例、最佳实践等。
```

要点：

- 技能名称默认取自目录名（如 `sql_knowledge`）。
- `description` 会被展示在技能提示词中，建议写成简明但信息量足够的中文说明。

## 3. 为 Agent 挂载技能与系统操作

### 3.1 创建 Agent 并注册 SysOperation

首先创建 `ReActAgent`，并注册一个 `SysOperationCard`：

```java
import com.openjiuwen.core.runner.Runner;
import com.openjiuwen.core.singleagent.ReActAgent;
import com.openjiuwen.core.singleagent.agents.ReActAgentConfig;
import com.openjiuwen.core.singleagent.schema.AgentCard;
import com.openjiuwen.core.sysop.OperationMode;
import com.openjiuwen.core.sysop.SysOperationCard;
import com.openjiuwen.core.sysop.config.LocalWorkConfig;

// 创建 AgentCard
AgentCard agentCard = AgentCard.builder()
        .id("skill_agent")
        .name("技能助手")
        .description("具备技能和系统操作能力的Agent")
        .build();

// 创建 ReActAgent
ReActAgent agent = new ReActAgent(agentCard);

// 创建 SysOperationCard（本地模式）
SysOperationCard sysOpCard = SysOperationCard.builder()
        .mode(OperationMode.LOCAL)
        .workConfig(LocalWorkConfig.builder().workDir(null).build())
        .build();

// 注册 SysOperation 到资源管理器
Runner.resourceMgr().addSysOperation(sysOpCard, null);

// 配置 Agent
String systemPrompt = "你是一个智能助手。\n"
        + "你可以使用技能和系统工具完成任务。\n";

ReActAgentConfig config = ReActAgentConfig.builder()
        .promptTemplate(List.of(Map.of("role", "system", "content", systemPrompt)))
        .maxIterations(20)
        .build()
        .configureModelClient(
                modelProvider,
                apiKey,
                apiBase,
                modelName,
                sslVerify
        );

// 设置 SysOperation ID
config.setSysOperationId(sysOpCard.getId());
agent.configure(config);
```

### 3.2 挂载系统操作工具

为 Agent 显式挂载需要的 sysop 工具卡片：

```java
String sysOperationId = config.getSysOperationId();

// 挂载文件读取工具
addSysOpTool(agent, sysOperationId, "fs", "readFile");

// 挂载代码执行工具
addSysOpTool(agent, sysOperationId, "code", "executeCode");

// 挂载命令执行工具
addSysOpTool(agent, sysOperationId, "shell", "executeCmd");

private static void addSysOpTool(ReActAgent agent, String sysOperationId, 
        String operationName, String toolName) {
    Object toolCard = Runner.resourceMgr().getSysOpToolCards(
            sysOperationId, operationName, toolName);
    if (toolCard != null) {
        agent.getAbilityManager().add(toolCard);
    }
}
```

### 3.3 注册技能目录

将本地技能目录注册到 Agent：

```java
// 注册本地技能
Path skillsDir = Path.of("/path/to/skills_root");
agent.registerSkill(skillsDir.toString());
```

也可以从 GitHub 下载并注册远程技能：

```java
import com.openjiuwen.core.singleagent.skills.GitHubTree;

// 从 GitHub 下载远程技能
agent.registerRemoteSkills(
        skillsDir.toString(),
        new GitHubTree(
                "owner",
                "repo",
                "HEAD",
                "skills/image_resizer"  // 远程目录路径
        ),
        System.getenv("GITHUB_TOKEN")  // 可选的 GitHub Token
);
```

### 3.4 内置工具一览

当前 sysop 提供三类系统操作工具：

- `readFile`：查看文本文件内容。
  - 对应内部工具：`fs.readFile`。
  - 主要入参：`file_path: str`、`encoding: str`。
- `executeCode`：执行一段代码。
  - 对应内部工具：`code.executeCode`。
  - 主要入参：`code_block: str`、`language: str`。
  - 支持 Python 等语言执行，并返回 stdout / stderr。
- `executeCmd`：执行 Shell 命令。
  - 对应内部工具：`shell.executeCmd`。
  - 主要入参：`bash_command: str`。

> 这些工具会自动注册到 Runner 的资源管理器中，同时其 `ToolCard` 会被挂到 Agent 的 `abilityManager` 上。

## 4. 在 ReAct Agent 中结合 Skills 使用

Skills 本身只负责"提供技能元数据 + 提供技能提示词"，与具体 Agent 类型解耦。一个常见模式是：

```java
import com.openjiuwen.core.runner.Runner;
import java.nio.file.Path;

// 创建 Agent
ReActAgent agent = createAgent(filesBaseDir, outputDir, maxIterations);
ReActAgentConfig agentConfig = (ReActAgentConfig) agent.getConfig();
String sysOperationId = agentConfig.getSysOperationId();

// 挂载系统操作工具
addSysOpTool(agent, sysOperationId, "fs", "readFile");
addSysOpTool(agent, sysOperationId, "code", "executeCode");
addSysOpTool(agent, sysOperationId, "shell", "executeCmd");

// 注册技能
Path skillsDir = Path.of("examples/skill_use/skills");
agent.registerSkill(skillsDir.toString());

// 执行任务
Map<String, Object> result = (Map<String, Object>) Runner.runAgent(
        agent,
        Map.of(
                "query", "使用技能完成任务",
                "conversation_id", "session_001"
        ),
        null,
        null
);

System.out.println(result);

// 清理资源
Runner.release("session_001");
Runner.stop();
```

## 5. 完整示例代码

以下完整示例展示了技能与系统操作的协同使用：

```java
import com.openjiuwen.core.runner.Runner;
import com.openjiuwen.core.singleagent.ReActAgent;
import com.openjiuwen.core.singleagent.agents.ReActAgentConfig;
import com.openjiuwen.core.singleagent.schema.AgentCard;
import com.openjiuwen.core.singleagent.skills.GitHubTree;
import com.openjiuwen.core.sysop.OperationMode;
import com.openjiuwen.core.sysop.SysOperationCard;
import com.openjiuwen.core.sysop.config.LocalWorkConfig;

import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.Map;

public class SkillUseExample {

    public static void main(String[] args) throws Exception {
        Path filesBaseDir = Path.of("examples/skill_use/data");
        Path outputDir = Path.of("examples/skill_use/output");
        Path skillsDir = Path.of("examples/skill_use/skills");
        int maxIterations = 40;

        Files.createDirectories(filesBaseDir);
        Files.createDirectories(outputDir);
        Files.createDirectories(skillsDir);

        // 创建 Agent
        ReActAgent agent = createAgent(filesBaseDir, outputDir, maxIterations);
        ReActAgentConfig agentConfig = (ReActAgentConfig) agent.getConfig();
        String sysOperationId = agentConfig.getSysOperationId();

        // 挂载系统操作工具
        addSysOpTool(agent, sysOperationId, "fs", "readFile");
        addSysOpTool(agent, sysOperationId, "code", "executeCode");
        addSysOpTool(agent, sysOperationId, "shell", "executeCmd");

        // 注册技能（可选从 GitHub 下载）
        try {
            agent.registerRemoteSkills(
                    skillsDir.toString(),
                    new GitHubTree(
                            "dreamofapsychiccat",
                            "remote-skills-test",
                            "HEAD",
                            "skills/image_resizer"
                    ),
                    System.getenv("GITHUB_TOKEN")
            );
        } catch (RuntimeException ex) {
            System.out.println("Remote skill registration skipped: " + ex.getMessage());
        }

        agent.registerSkill(skillsDir.toString());

        // 执行任务
        String query = args.length == 0
                ? "Downscale the provided image inside the " + filesBaseDir + " directory by 2x."
                : String.join(" ", args);

        try {
            Map<String, Object> result = (Map<String, Object>) Runner.runAgent(
                    agent,
                    Map.of(
                            "query", query,
                            "conversation_id", "492"
                    ),
                    null,
                    null
            );

            System.out.println("Skill use result:");
            System.out.println(result);
        } finally {
            Runner.release("492");
            Runner.stop();
        }
    }

    private static ReActAgent createAgent(Path filesBaseDir, Path outputDir, int maxIterations) {
        AgentCard agentCard = AgentCard.builder()
                .id("skill_use_agent")
                .name("Skill Use Agent")
                .description("具备技能和系统操作能力的Agent")
                .build();

        ReActAgent agent = new ReActAgent(agentCard);

        SysOperationCard sysOpCard = SysOperationCard.builder()
                .mode(OperationMode.LOCAL)
                .workConfig(LocalWorkConfig.builder().workDir(null).build())
                .build();
        Runner.resourceMgr().addSysOperation(sysOpCard, null);

        String systemPrompt = "You are an intelligent assistant.\n"
                + "All user-provided files are located at '" + filesBaseDir + "'\n"
                + "Put all generated files into " + outputDir + "\n"
                + "You may use tools when necessary.\n";

        ReActAgentConfig config = ReActAgentConfig.builder()
                .promptTemplate(List.of(Map.of("role", "system", "content", systemPrompt)))
                .maxIterations(maxIterations)
                .build()
                .configureModelClient(
                        System.getenv("MODEL_PROVIDER"),
                        System.getenv("API_KEY"),
                        System.getenv("API_BASE"),
                        System.getenv("MODEL_NAME"),
                        false
                );

        config.setSysOperationId(sysOpCard.getId());
        agent.configure(config);
        return agent;
    }

    private static void addSysOpTool(ReActAgent agent, String sysOperationId,
            String operationName, String toolName) {
        Object toolCard = Runner.resourceMgr().getSysOpToolCards(
                sysOperationId, operationName, toolName);
        if (toolCard != null) {
            agent.getAbilityManager().add(toolCard);
        }
    }
}
```

## 6. 与记忆、检索等模块的协同

在一个完整的智能体应用中，Skills 往往会与记忆引擎、知识检索等模块协同工作：

- 通过记忆引擎（`LongTermMemory`）管理用户画像和变量；
- 通过知识检索（`SimpleKnowledgeBase` 等）管理外部文档知识；
- 通过 Skills 扩展"操作能力"，如：
  - 查看项目中的配置文件或代码片段；
  - 在安全环境中执行少量调试代码；
  - 执行受控的 Shell 命令（例如 `ls` 或 `cat`）。

这些模块在源码中彼此独立、接口清晰，可以按需组合。
