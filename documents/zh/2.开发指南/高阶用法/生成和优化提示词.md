openJiuwen框架支持多维度提示词智能优化方法。在智能对话系统中，提示词的质量直接影响大模型输出结果的准确性、相关性与稳定性。为系统性提升提示词效能，openJiuwen提供一套循序渐进的提示词优化机制，涵盖以下三个核心环节：

* 生成提示词：基于用户的原始提示词，自动生成结构化、语义清晰的提示词。实现从"模糊意图"到"结构化指令"的转化。
* 基于反馈优化提示词：基于用户提供的反馈，对原始提示词进行定向优化，提升提示词质量。
* 基于错误案例优化提示词：基于典型错误用例生成针对性改进策略，对原始提示词进行针对性优化，提升模型在边缘场景的表现。

# 生成提示词

提示词生成模块旨在将用户的初始输入转化为结构化的提示词框架。该模块通过调用大语言模型，将简单的原始输入（例如"你是一个人名提取助手"）扩展为结构清晰的包含明确角色定义、任务目标和输出规范的完整提示词，从而降低提示词编写门槛，提供标准化的起始模板，打破"不知道怎么写"的启动障碍。

通过`MetaTemplateBuilder.build`函数生成初始提示词

```java
import com.openjiuwen.core.foundation.llm.schema.ModelClientConfig;
import com.openjiuwen.core.foundation.llm.schema.ModelRequestConfig;
import com.openjiuwen.dev_tools.prompt_builder.builder.MetaTemplateBuilder;

import java.util.List;

// 大模型配置（从环境变量或配置文件读取）
String apiBase = "https://api.openai.com/v1";
String apiKey = System.getenv("OPENAI_API_KEY");
String modelName = "gpt-4o-mini";
String modelProvider = "OpenAI";

// 1. 创建模型配置
ModelRequestConfig modelConfig = ModelRequestConfig.builder()
        .modelName(modelName)
        .build();

ModelClientConfig clientConfig = ModelClientConfig.builder()
        .clientProvider(modelProvider)
        .apiKey(apiKey)
        .apiBase(apiBase)
        .verifySsl(true)
        .build();

// 2. 创建MetaTemplateBuilder对象
MetaTemplateBuilder builder = new MetaTemplateBuilder(modelConfig, clientConfig);

// 3. 执行提示词生成（build 返回 CompletableFuture）
String generatedPrompt = builder.build(
        "你是一个人名信息提取助手",
        List.of(),          // tools
        "general",          // templateType
        null,               // customTemplateId
        "zh-CN"             // language
).join();

System.out.println(generatedPrompt);
```

预期返回

```text
## 人设
你是一个人名信息提取助手  
你的专业技能包括：  
- 从文本中准确识别和提取人名  
- 区分真实姓名与昵称、职位、头衔等  
- 支持多种语言的人名识别（如中文、英文等）  
- 识别并处理复杂语境中的人名信息  

## 任务描述
你的任务是从用户提供的文本中提取出所有出现的人名信息，并以清晰的方式呈现出来。这将帮助用户快速获取文本中涉及的人员信息，便于后续分析或整理。  

## 约束条件
1. 按照<输出格式>输出  
2. 按照<执行步骤>一步一步执行  
3. 仅提取明确的人名，不包括职位、头衔、公司名等  
4. 如果文本中没有可提取的人名，输出"未发现人名信息"  

## 执行步骤
1. 通读用户提供的文本，理解整体语境  
2. 识别文本中所有可能的人名，包括中文、英文等  
3. 排除非人名信息（如职位、公司名、昵称等）  
4. 按照<输出格式>整理并输出提取结果  

## 输出格式
- 输出一个无序列表，每个条目为一个提取出的人名  
- 人名使用中文或英文原样呈现，不进行翻译或修改  
- 示例格式：  
  - 张三  
  - John Smith
```

# 基于反馈优化提示词

初始生成的提示词往往无法完全满足实际应用需求。反馈优化模块通过收集用户反馈和测试结果，对提示词进行迭代改进。

通过`FeedbackPromptBuilder.build`函数进行提示词反馈优化

```java
import com.openjiuwen.dev_tools.prompt_builder.builder.FeedbackPromptBuilder;

// 1. 创建模型配置（使用上一节的配置）
ModelRequestConfig modelConfig = ModelRequestConfig.builder()
        .modelName(modelName)
        .build();

ModelClientConfig clientConfig = ModelClientConfig.builder()
        .clientProvider(modelProvider)
        .apiKey(apiKey)
        .apiBase(apiBase)
        .verifySsl(true)
        .build();

// 2. 创建FeedbackPromptBuilder对象
FeedbackPromptBuilder feedbackBuilder = new FeedbackPromptBuilder(modelConfig, clientConfig);

// 上一步生成的提示词
String prompt = "## 人设定义你将扮演的角色或身份：人名提取助手列举角色的...";

// 3. 执行提示词反馈优化（build 返回 CompletableFuture）
String optimizedPrompt = feedbackBuilder.build(
        prompt,
        "不要提取真实历史中不存在的人物"
).join();

System.out.println(optimizedPrompt);
```

预期返回

```text
## 人设定义你将扮演的角色或身份：人名提取助手，仅列举真实存在的人物角色...
```

FeedbackPromptBuilder支持三种模式：

| 模式 | 调用方式 | 适用场景 | 返回内容 |
| --- | --- | --- | --- |
| `general` | `build(prompt, feedback)` | 对整篇prompt做整体微调 | 完整prompt |
| `select` | `build(prompt, feedback, "select", startPos, endPos, language)` | 只改指定片段 | 优化后的片段 |
| `insert` | `build(prompt, feedback, "insert", startPos, language)` | 在指定位置补一段新内容 | 待插入片段 |

# 基于错误案例优化提示词

错误案例优化模块专注于处理边界情况和异常场景。通过分析失败案例，识别提示词的薄弱环节并进行针对性改进。

通过`BadCasePromptBuilder.build`函数执行提示词错误案例优化

```java
import com.openjiuwen.dev_tools.prompt_builder.builder.BadCasePromptBuilder;
import com.openjiuwen.dev_tools.tune.Case;
import com.openjiuwen.dev_tools.tune.EvaluatedCase;

import java.util.List;
import java.util.Map;

// 1. 创建模型配置（使用上一节的配置）
ModelRequestConfig modelConfig = ModelRequestConfig.builder()
        .modelName(modelName)
        .build();

ModelClientConfig clientConfig = ModelClientConfig.builder()
        .clientProvider(modelProvider)
        .apiKey(apiKey)
        .apiBase(apiBase)
        .verifySsl(true)
        .build();

// 2. 创建BadCasePromptBuilder对象
BadCasePromptBuilder badcaseBuilder = new BadCasePromptBuilder(modelConfig, clientConfig);

// 准备错误案例
List<EvaluatedCase> badCases = List.of(
        EvaluatedCase.builder()
                .caseData(Case.builder()
                        .inputs(Map.of("query", "潘之恒（约1536—1621）字景升，号鸾啸生，冰华生，安徽歙县、岩寺人，侨寓金陵（今江苏南京）"))
                        .label(Map.of("output", "[潘之恒]"))
                        .build())
                .answer(Map.of("output", "[潘之恒, 冰华生]"))
                .reason("误将别号「冰华生」识别为人名")
                .build(),
        EvaluatedCase.builder()
                .caseData(Case.builder()
                        .inputs(Map.of("query", "郭造卿（1532—1593），字建初，号海岳，福建福清县化南里人（今福清市人），郭遇卿之弟"))
                        .label(Map.of("output", "[郭造卿, 郭遇卿]"))
                        .build())
                .answer(Map.of("output", "[郭造卿, 郭遇卿, 吴越]"))
                .reason("误将地名「吴越」识别为人名")
                .build()
);

// 3. 执行提示词错误案例优化（build 返回 CompletableFuture）
String optimizedByBadCases = badcaseBuilder.build(
        "你是一个专业的人名信息提取助手",
        badCases,
        "zh-CN"
).join();

System.out.println(optimizedByBadCases);
```

预期结果

```text
你是一个专业的人名信息提取助手。请从文本中提取所有真实人物的本名，并以列表形式返回。人名指的是真实存在的个人的正式姓名，不包括别号、笔名、地名、地区名、组织名或其他非人名实体。请确保只提取明确指代真实人物的本名。
```

# 自定义模板

当内置的`general`/`plan`模板不够贴近你的领域时，可以先注册自己的模板，再通过调用：

```java
import com.openjiuwen.core.foundation.prompt.PromptTemplate;

// 注册自定义模板
builder.registerMetaTemplate(
        "ticket",
        PromptTemplate.builder()
                .content("""
## 角色
你是一个工单分类助手

## 任务
{{instruction}}

## 可用工具
{{tools}}
""")
                .build()
);

// 使用自定义模板生成提示词
String customPrompt = builder.build(
        "根据用户报障内容输出工单分类和优先级",
        List.of(),
        "other",
        "ticket",
        "zh-CN"
).join();
```

# 与运行时模板的关系

builder产出的结果，通常还会回到运行时模板层继续使用。最常见的落法有两种：

1. 直接把builder输出的字符串保存成新的system/user prompt文本
2. 把builder输出转成`PromptTemplate`，再进入后续`format(...)`流程

```java
import com.openjiuwen.core.foundation.prompt.PromptTemplate;

// 把生成结果保存为运行时模板
PromptTemplate runtimeTemplate = PromptTemplate.builder()
        .content(optimizedPrompt)
        .build();

// 运行时使用 format 填充变量
PromptTemplate filledTemplate = runtimeTemplate.format(Map.of("query", userInput));
```

一个典型链路可以写成：

1. 用`MetaTemplateBuilder`生成初稿
2. 用`FeedbackPromptBuilder`或`BadCasePromptBuilder`改到满意
3. 把结果保存成`PromptTemplate`
4. 运行时继续用`PromptTemplate.format(...)`装配变量
