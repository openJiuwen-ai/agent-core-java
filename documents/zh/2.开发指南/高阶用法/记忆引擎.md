# 记忆引擎（LongTermMemory）

记忆引擎（`LongTermMemory`）是 openJiuwen 在当前版本中提供的统一记忆管理组件，负责管理用户的对话消息、变量记忆和长期用户画像。

和旧版文档中的 `MemoryEngine/SysMemConfig/MemoryConfig` 不同，**当前版本记忆能力完全由 `LongTermMemory + MemoryEngineConfig + MemoryScopeConfig + AgentMemoryConfig` 这套接口负责**，并以 `scopeId` 区分不同的业务/Agent 场景。

本章节将严格基于源码 `com.openjiuwen.core.memory` 下的对外接口进行说明。

## 核心概念与配置类

记忆引擎的核心类型定义在 `com.openjiuwen.core.memory` 与 `com.openjiuwen.core.memory.config` 模块中：

- **`LongTermMemory`**（记忆引擎本体）  
  - 负责注册底层存储（KV Store / Vector Store / DB）、设置全局引擎配置、管理各个 `scope` 的记忆配置以及读写用户记忆。
  - 采用单例模式，通过 `LongTermMemory.getInstance()` 获取实例。

- **`MemoryEngineConfig`**（全局引擎配置）  
  定义引擎级别的通用配置：
  - `defaultModelCfg: ModelRequestConfig`：默认用于生成记忆的大模型请求参数（模型名、温度等）。
  - `defaultModelClientCfg: ModelClientConfig`：默认的大模型客户端配置（`clientProvider`、`apiBase`、`apiKey`、`verifySsl` 等）。
  - `inputMsgMaxLen: int`：输入消息最大长度（默认 8192）。
  - `cryptoKey: byte[]`：用于加密存储中敏感字段的 AES 密钥（长度必须为 32 字节；为空表示不加密）。

- **`MemoryScopeConfig`**（作用域级配置）  
  用于为不同 `scopeId` 定义独立的模型 / 向量配置：
  - `modelCfg: ModelRequestConfig`：该 scope 下使用的大模型请求配置。
  - `modelClientCfg: ModelClientConfig`：该 scope 下使用的大模型客户端配置。
  - `embeddingCfg: EmbeddingConfig`：该 scope 下使用的嵌入模型配置（`modelName`、`baseUrl`、`apiKey`）。

- **`AgentMemoryConfig`**（Agent 级记忆策略配置）  
  描述某个智能体希望提取和管理哪些"变量记忆"和"长期记忆"：
  - `memVariables: List<Param>`：变量记忆配置列表（每个 `Param` 定义一个变量名、说明、类型、是否必填等）。
  - `enableLongTermMem: boolean`：是否开启长期记忆（默认 `true`）。
  - `enableFragmentMemory: boolean`：是否开启片段记忆。
  - `enableSummaryMemory: boolean`：是否开启摘要记忆。

> 这些类在源码中分别定义于：  
> `com.openjiuwen.core.memory.config` 与 `com.openjiuwen.core.memory`，可以通过 `import com.openjiuwen.core.memory.*` 直接导入。

## 创建记忆引擎实例

下面示例演示如何基于 `LongTermMemory` 创建一个完整可用的记忆引擎，包括：

1. 注册 KV 存储、向量存储、关系型数据库存储；
2. 配置全局引擎参数；
3. 创建并返回可复用的 `LongTermMemory` 实例。

```java
import com.openjiuwen.core.memory.LongTermMemory;
import com.openjiuwen.core.memory.config.MemoryEngineConfig;
import com.openjiuwen.core.memory.config.MemoryScopeConfig;
import com.openjiuwen.core.memory.config.AgentMemoryConfig;
import com.openjiuwen.core.foundation.llm.schema.ModelClientConfig;
import com.openjiuwen.core.foundation.llm.schema.ModelRequestConfig;
import com.openjiuwen.core.retrieval.embedding.APIEmbedding;
import com.openjiuwen.core.retrieval.embedding.EmbeddingConfig;
import com.openjiuwen.spi.store.InMemoryKVStore;
import com.openjiuwen.spi.store.DefaultDbStore;

import java.util.Map;

public class MemoryEngineExample {

    public static LongTermMemory createMemoryEngine() throws Exception {
        LongTermMemory engine = LongTermMemory.getInstance();

        // 1. 创建底层存储
        InMemoryKVStore kvStore = new InMemoryKVStore();
        // 向量存储示例（实际使用 Milvus 等）
        VectorStore vectorStore = createVectorStore();
        // 关系型数据库存储
        DefaultDbStore dbStore = createDbStore();
        // 嵌入模型
        APIEmbedding embedding = new APIEmbedding(EmbeddingConfig.builder()
                .modelName("text-embedding-3-small")
                .apiKey("sk-xxxxx")
                .baseUrl("https://api.openai.com/v1")
                .build());

        // 注册存储
        engine.registerStore(kvStore, vectorStore, dbStore, embedding);

        // 2. 设置全局引擎配置（默认大模型 + 加密配置）
        ModelRequestConfig defaultModelCfg = ModelRequestConfig.builder()
                .modelName("gpt-4")
                .temperature(0.0)
                .build();

        ModelClientConfig defaultModelClientCfg = ModelClientConfig.builder()
                .clientProvider("OpenAI")
                .apiKey("sk-xxxxx")
                .apiBase("https://api.openai.com/v1")
                .verifySsl(false)
                .build();

        // cryptoKey 必须是 32 字节；为空则不启用加密
        byte[] cryptoKey = new byte[32]; // 实际应从安全配置获取

        MemoryEngineConfig engineConfig = MemoryEngineConfig.builder()
                .defaultModelCfg(defaultModelCfg)
                .defaultModelClientCfg(defaultModelClientCfg)
                .cryptoKey(cryptoKey)
                .inputMsgMaxLen(8192)
                .singleTurnHistorySummaryMaxToken(128)
                .build();

        engine.setConfig(engineConfig);

        return engine;
    }
}
```

> 注意：`LongTermMemory` 的初始化分为两步：  
> 1）`registerStore(...)` 注册存储；  
> 2）`setConfig(MemoryEngineConfig)` 设置全局配置。

## 配置作用域（scope）与 Agent 记忆策略

记忆引擎通过 `scopeId` 将不同业务/Agent 的记忆隔离开来。每个 `scopeId` 对应一套 `MemoryScopeConfig` 和若干 `AgentMemoryConfig`。

### 配置 MemoryScopeConfig（作用域级模型与向量配置）

```java
import com.openjiuwen.core.memory.config.MemoryScopeConfig;
import com.openjiuwen.core.retrieval.embedding.EmbeddingConfig;

public class ScopeConfigExample {

    public static void configureScope(LongTermMemory engine) {
        String scopeId = "app_demo_scope";

        ModelRequestConfig scopeModelCfg = ModelRequestConfig.builder()
                .modelName("gpt-4")
                .temperature(0.1)
                .build();

        ModelClientConfig scopeModelClientCfg = ModelClientConfig.builder()
                .clientProvider("OpenAI")
                .apiKey("sk-xxxxx")
                .apiBase("https://api.openai.com/v1")
                .verifySsl(false)
                .build();

        EmbeddingConfig embedCfg = EmbeddingConfig.builder()
                .modelName("text-embedding-3-small")
                .apiKey("sk-embed-xxx")
                .baseUrl("https://api.openai.com/v1/embeddings")
                .build();

        MemoryScopeConfig scopeCfg = MemoryScopeConfig.builder()
                .modelCfg(scopeModelCfg)
                .modelClientCfg(scopeModelClientCfg)
                .embeddingCfg(embedCfg)
                .build();

        boolean ok = engine.setScopeConfig(scopeId, scopeCfg);
        if (!ok) {
            throw new RuntimeException("设置 MemoryScopeConfig 失败");
        }
    }
}
```

> `setScopeConfig(scopeId, MemoryScopeConfig)` 会自动把配置加密后写入 KV 存储，并缓存到内存中；后续 `addMessages`、`searchUserMem` 等会基于该 scope 的配置选择对应的大模型和嵌入模型。

### 配置 AgentMemoryConfig（变量记忆字段）

```java
import com.openjiuwen.core.memory.config.AgentMemoryConfig;
import com.openjiuwen.core.common.schema.Param;

AgentMemoryConfig agentMemCfg = AgentMemoryConfig.builder()
        .enableLongTermMem(true)
        .enableFragmentMemory(true)
        .enableSummaryMemory(true)
        .memVariables(java.util.List.of(
                Param.string("姓名", "用户姓名", false),
                Param.string("职业", "用户职业", false),
                Param.string("居住地", "用户居住地", false),
                Param.string("爱好", "用户爱好", false),
                Param.string("年龄", "用户年龄", false)
        ))
        .build();
```

`AgentMemoryConfig` 会在调用 `addMessages` 时传入，用于指导记忆引擎从对话中抽取哪些变量和长期记忆。

## 写入消息并生成记忆（addMessages）

记忆引擎通过 `LongTermMemory.addMessages` 完成"写入消息 + 抽取记忆"：

```java
import com.openjiuwen.core.foundation.llm.schema.BaseMessage;
import com.openjiuwen.core.foundation.llm.schema.UserMessage;
import com.openjiuwen.core.foundation.llm.schema.AssistantMessage;
import java.time.OffsetDateTime;

public class AddMessagesExample {

    public static void addConversation(LongTermMemory engine, AgentMemoryConfig agentMemCfg) {
        String userId = "user1";
        String scopeId = "app_demo_scope";
        String sessionId = "session_001";

        java.util.List<BaseMessage> messages = java.util.List.of(
                new UserMessage("我叫张三，我喜欢打羽毛球"),
                new AssistantMessage("你好张三，很高兴认识你"),
                new UserMessage("我是一名软件工程师，住在杭州")
        );

        OffsetDateTime timestamp = OffsetDateTime.now();

        engine.addMessages(
                messages,
                agentMemCfg,
                userId,
                scopeId,
                sessionId,
                timestamp,
                true,                  // genMem: 是否生成长期记忆
                5                      // genMemWithHistoryMsgNum: 生成记忆时使用多少条历史消息
        );
    }
}
```

> 内部会自动：  
> - 把消息写入消息表；  
> - 结合历史消息与 `AgentMemoryConfig`，调用大模型进行变量/用户画像抽取；  
> - 把抽取出的长期记忆写入向量存储和 DB。

## 查询变量记忆（getVariables）

使用 `getVariables` 可以按 `userId + scopeId` 查询当前已提取的变量记忆：

```java
import java.util.Map;

Map<String, String> variables = engine.getVariables(
        java.util.List.of("姓名", "职业"),  // names: 可选，查询特定变量
        "user1",
        "app_demo_scope"
);
System.out.println(variables);
// 可能输出：{"姓名": "张三", "职业": "软件工程师"}
```

如果只想读取所有变量，可以不传 `names` 参数：

```java
Map<String, String> allVariables = engine.getVariables(null, "user1", "app_demo_scope");
```

## 分页查看长期记忆（getUserMemByPage）

对长期记忆（如用户画像）可以通过分页接口查看：

```java
import com.openjiuwen.core.memory.MemInfo;
import com.openjiuwen.core.memory.manage.mem_model.MemoryType;

java.util.List<MemInfo> memList = engine.getUserMemByPage(
        "user1",
        "app_demo_scope",
        10,    // pageSize
        0,     // pageIdx
        MemoryType.USER_PROFILE  // memoryType: 只看用户画像类记忆
);

for (MemInfo mem : memList) {
    System.out.println(mem.getMemId() + ", " + mem.getType() + ", " + mem.getContent());
}
```

## 语义检索记忆（searchUserMem）

`searchUserMem` 提供基于向量相似度的记忆检索能力：

```java
import com.openjiuwen.core.memory.MemResult;

java.util.List<MemResult> searchResults = engine.searchUserMem(
        "用户的职业是什么？",  // query
        5,                    // num: 返回数量
        "user1",
        "app_demo_scope",
        0.3                   // threshold: 过滤低于阈值的结果
);

for (MemResult item : searchResults) {
    MemInfo mem = item.getMemInfo();
    System.out.println("memId=" + mem.getMemId() + ", type=" + mem.getType() + 
                       ", score=" + item.getScore() + ", content=" + mem.getContent());
}
```

返回值是若干 `MemResult`，每个包含：
- `memInfo: MemInfo`：包括 `memId`、`content`、`type`；
- `score: double`：相似度得分。

## 更新与删除记忆

### 更新变量记忆（updateVariables）

```java
engine.updateVariables(
        Map.of("爱好", "篮球"),
        "user1",
        "app_demo_scope"
);
```

### 删除变量记忆（deleteVariables）

```java
engine.deleteVariables(
        java.util.List.of("爱好"),
        "user1",
        "app_demo_scope"
);
```

### 按记忆 ID 删除长期记忆（deleteMemById）

```java
// 假设已经通过 searchUserMem 或 getUserMemByPage 得到了某个 memId
engine.deleteMemById(
        "mem_123",
        "user1",
        "app_demo_scope"
);
```

### 按用户或作用域删除全部记忆

```java
// 删除某个用户在某个 scope 下的所有记忆
engine.deleteMemByUserId("user1", "app_demo_scope");

// 删除整个 scope 下所有用户的记忆（以及 scope 配置）
engine.deleteMemByScope("app_demo_scope");
engine.deleteScopeConfig("app_demo_scope");
```

## 统计与辅助查询

- **获取统计信息**：通过 `getUserMemByPage`、`userMemTotalNum` 可以统计某个用户在某个 scope 下的记忆条数。
- **获取最近消息**：`getRecentMessages(userId, scopeId, sessionId, num)` 返回最近若干条 `BaseMessage`。
- **按消息 ID 查询**：`getMessageById(msgId)` 返回对应的消息及时间戳。

## 完整示例

```java
import com.openjiuwen.core.memory.LongTermMemory;
import com.openjiuwen.core.memory.config.MemoryEngineConfig;
import com.openjiuwen.core.memory.config.MemoryScopeConfig;
import com.openjiuwen.core.memory.config.AgentMemoryConfig;
import com.openjiuwen.core.memory.MemInfo;
import com.openjiuwen.core.memory.MemResult;
import com.openjiuwen.core.foundation.llm.schema.BaseMessage;
import com.openjiuwen.core.foundation.llm.schema.UserMessage;
import com.openjiuwen.core.foundation.llm.schema.AssistantMessage;
import com.openjiuwen.core.foundation.llm.schema.ModelClientConfig;
import com.openjiuwen.core.foundation.llm.schema.ModelRequestConfig;
import com.openjiuwen.core.retrieval.embedding.APIEmbedding;
import com.openjiuwen.core.retrieval.embedding.EmbeddingConfig;
import com.openjiuwen.core.common.schema.Param;
import com.openjiuwen.spi.store.InMemoryKVStore;

import java.time.OffsetDateTime;
import java.util.List;
import java.util.Map;

public class LongTermMemoryExample {

    public static void main(String[] args) throws Exception {
        // 1. 创建记忆引擎
        LongTermMemory engine = LongTermMemory.getInstance();
        InMemoryKVStore kvStore = new InMemoryKVStore();
        
        APIEmbedding embedding = new APIEmbedding(EmbeddingConfig.builder()
                .modelName("text-embedding-3-small")
                .apiKey("sk-xxxxx")
                .baseUrl("https://api.openai.com/v1")
                .build());
        
        engine.registerStore(kvStore, null, null, embedding);
        
        MemoryEngineConfig engineConfig = MemoryEngineConfig.builder()
                .defaultModelCfg(ModelRequestConfig.builder()
                        .modelName("gpt-4")
                        .temperature(0.0)
                        .build())
                .defaultModelClientCfg(ModelClientConfig.builder()
                        .clientProvider("OpenAI")
                        .apiKey("sk-xxxxx")
                        .apiBase("https://api.openai.com/v1")
                        .verifySsl(false)
                        .build())
                .inputMsgMaxLen(8192)
                .build();
        engine.setConfig(engineConfig);

        // 2. 配置 scope
        MemoryScopeConfig scopeCfg = MemoryScopeConfig.builder()
                .modelCfg(ModelRequestConfig.builder().modelName("gpt-4").temperature(0.1).build())
                .modelClientCfg(ModelClientConfig.builder()
                        .clientProvider("OpenAI")
                        .apiKey("sk-xxxxx")
                        .apiBase("https://api.openai.com/v1")
                        .build())
                .embeddingCfg(EmbeddingConfig.builder()
                        .modelName("text-embedding-3-small")
                        .apiKey("sk-xxxxx")
                        .build())
                .build();
        engine.setScopeConfig("demo_scope", scopeCfg);

        // 3. 配置 AgentMemoryConfig
        AgentMemoryConfig agentMemCfg = AgentMemoryConfig.builder()
                .enableLongTermMem(true)
                .memVariables(List.of(
                        Param.string("姓名", "用户姓名", false),
                        Param.string("职业", "用户职业", false)
                ))
                .build();

        // 4. 写入消息
        List<BaseMessage> messages = List.of(
                new UserMessage("我叫张三，我喜欢打羽毛球"),
                new AssistantMessage("你好张三"),
                new UserMessage("我是一名软件工程师")
        );
        engine.addMessages(messages, agentMemCfg, "user1", "demo_scope", "session1", 
                OffsetDateTime.now(), true, 5);

        // 5. 查询变量
        Map<String, String> variables = engine.getVariables(null, "user1", "demo_scope");
        System.out.println("变量记忆: " + variables);

        // 6. 语义检索
        List<MemResult> results = engine.searchUserMem("用户职业", 3, "user1", "demo_scope", 0.3);
        System.out.println("检索结果数量: " + results.size());

        // 7. 清理
        engine.deleteMemByUserId("user1", "demo_scope");
        engine.deleteScopeConfig("demo_scope");

        System.out.println("记忆引擎示例完成");
    }
}
```

输出示例：

```
变量记忆: {姓名=张三, 职业=软件工程师}
检索结果数量: 1
记忆引擎示例完成
```

这些接口在源码中定义于 `com.openjiuwen.core.memory.LongTermMemory`，文档中的命名与签名已经全部与源码保持一致。
