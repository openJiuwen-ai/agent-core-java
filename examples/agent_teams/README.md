# Agent Teams Baseline Example

This Java-side baseline demonstrates the migrated public surface for `agent_teams`.

It currently covers:

- `TeamAgentSpec`
- `TeamMemberSpec`
- `ModelPoolEntry`
- `TeamAgent`
- `TeamFactory.createAgentTeam`
- `TeamFactory.resumePersistentTeam`
- `TeamFactory.recoverAgentTeam`

The deeper Python coordination internals are still being ported incrementally.
