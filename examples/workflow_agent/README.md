# Workflow Agent Java Example（已移除）

本目录原先的 `WorkflowAgentExample` / `MultiWorkflowAgentDemo` 示例已不在当前代码树中：
`WorkflowAgentExample.java`、`WorkflowAgentExampleSupport.java`、
`multi_workflow_agent_demo/MultiWorkflowAgentDemo.java` 以及 `examples/SharedExampleApiConfigLoader.java`
均已随代码整理删除，因此本文不再提供编译与运行命令。

当前可运行的示例：

- [examples/agent_builder](../agent_builder/)：最小的 Agent 示例。
- [examples/agent_teams](../agent_teams/)：多智能体团队示例。

需要 `WorkflowAgent` 的完整讲解（工作流卡片、组件注册、`QuestionerComponent` 中断与
`InteractiveInput` 恢复）时，见
[执行器Runner.md](../../documents/zh/2.开发指南/高阶用法/执行器Runner.md)。
